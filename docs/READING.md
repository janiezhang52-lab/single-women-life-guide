# 阅读前说明

[返回项目首页](../README.md) · [在线目录](CONTENTS.md)

这本指南写给需要自己安排生活的成年女性。你可能一直单身，也可能在离异、丧偶或关系变化后重新出发；可能独居、合住、与家人生活，也可能正在养育孩子。单身、独居和有无孩子是不同的信息，请选择符合自己处境的内容。

全书沿着住房、收入、就医、身体照顾、做饭、工作权益、关系、未来照护和日常生活展开。每章从实际场景开始，给出准备材料、行动步骤、判断方法、费用示例、沟通话术与受阻后的下一步。无需按顺序读完，先找到眼前最需要解决的一件事。

### 怎样使用这本书

准备签租约，先看“住得安心”；收入可能中断，先算付款日期和现金缺口；准备检查或手术，先核对医疗要求、陪护与返程。没有紧急事项时，可以从做一顿愿意重复吃的饭、整理联系人或给自己留一段时间开始。

目录可点击进入章节，PDF书签与Word导航可以定位小节。附录提供八份可复制填写的工具；填写前先阅读相应章节中的示例和使用条件。目录数字与PDF页序一致，封面不印页码。

### 事实  示例和个人决定

本书以中国大陆一般生活环境为主。法律和办事资格要结合地区、合同与个人情况；健康内容帮助准备就医和提出问题，不替代诊断或治疗。国外医学和食品安全资料在来源中标明机构，不能直接当作中国的办事政策。

人物、金额、日期和时间表如无另行注明，均为教学假设或编者安排，不是市场报价、真实案例或对结果的保证。食谱营养按食材数据估算，烹调时间尚未经过厨房实测；份量不是每个人的食量上限。

来源编号对应书末资料，逐条注明核实日期。住房篇与部分食物成分记录保留2026年10月8日的核验日期，新增章节主要核验于2026年10月17日。具体办理或治疗前，仍须按实际变化确认。

### 把个人资料留在自己手里

对外分享表格时，只提供对方完成协助所需的信息。完整证件、账户、密码与验证码另行妥善保管。联系人、陪护、受托人、监护人和继承人各有不同作用，一张生活记录表不能代替正式法律或医疗文件。
