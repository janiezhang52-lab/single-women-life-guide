# 02 收入撑得住生活

[← 上一章：住得安心](01-housing.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：生病时有安排 →](03-medical.md)

<a id="introduction"></a>

钱带来的踏实，常常始于很具体的几件事：知道下次收入前够不够交房租，生病时能先拿出多少钱，换工作后第一笔工资什么时候到账。这里从一张真实账单开始，把正常生活、收入中断和意外支出连起来。收入不高、有债务、带孩子或需要照护家人，都可以使用这套方法；不以是否达到某个存款数字判断一个人是否独立。

本章所有金额、人物和日期安排均为教学假设，不是收入水平、市场报价、保险产品报价或统一生活标准。预算步骤是编者提供的组织方法；社保、保险、借贷等规则分别标注来源。涉及个人合同和地方政策时，用自己的材料完成核实，再作决定。

## 2.1 把每个月真正需要的钱算出来

先打开最近三个月的银行卡、支付工具和信用卡账单，挑一个没有重大意外的月份，再用另外两个月检查遗漏。刚开始记账时，只分住房、吃饭、交通、医疗、照护、债务和其他几类就够了。自己的账户之间转账只算资金移动，消费统计记购买，付款日历记实际还款，同一张汇总表里不要重复扣两次；退款也要与原消费对上。

<a id="money01-sub-01"></a>

### 先留下正常生活所需，再讨论可以调整的部分

必要支出包括能持续吃好、获得治疗、去上班和履行照护责任的钱。它不等于在极限情况下还能勉强活着的最低数字。把支出旁边标成“本月必须付”“能改日期或方式”“可以暂停”，比把所有娱乐都归为不该花更有用。接孩子的交通、长期处方药和工作所需通信，不能为了套用网上比例直接删掉。

| 假设月度项目 | 金额（元） | 依据与处理 |
| --- | --- | --- |
| 住房及固定费用 | 2500 | 按租约和近三个月账单估计 |
| 正常吃饭 | 1400 | 买菜、外食一起算，保留蛋白质食物 |
| 交通和通信 | 400 | 工作与必要出行 |
| 医疗及照护 | 500 | 常用药及固定照护责任 |
| 既有分期本息 | 600 | 不含已计入消费的信用卡当月还款 |
| 不按月发生的必要费用预留 | 300 | 全年预计 3600 元，除以 12 |
| 必要支出合计 | 5700 | 以上各项相加 |

这个例子的 5700 元只是月度规划数。假设实际到账收入 7200 元，先减必要支出，剩下 1500 元；若本月自选消费计划 700 元，理论上还剩 800 元。需要再核对有没有漏掉年费、探亲、维修和欠款，才能决定 800 元怎么安排。收入里还没发的奖金不能先拿来解释账为什么能平。

<a id="money01-sub-02"></a>

### 年付和季付的钱，记两次不同的事情

假设全年保险、必要维修和其他周期费用合计预计 3600 元，平均每月预留 300 元有助于规划；但实际某月一次要付 2400 元，付款日仍需要完整的 2400 元。建立“已预留余额”，每月转入或记账 300 元，付款时从该余额扣除。不要因为表上每月只写了 300 元，就忘了银行卡当天要有多少。

过去三个月波动很大时，不强行求一个平均值了事。例如冬夏电费不同，先写普通月与高支出月两个数字；医疗费用难估，就保留已确定项目和未知项目。月底只找最大的两项差异：是漏记、估计偏低，还是生活条件变了。下月调整表，没必要每天用半小时追责自己。若账单涉及其他人的隐私，自己保管即可，不必交给任何人证明你会过日子。

<a id="money02"></a>

## 2.2 存款有多少，与下周能用多少，是两回事

先列“今天可用”的现金和账户余额，再列暂时不能动的钱：房租押金、未结算报销、别人欠你的借款、尚未到账的项目款、赎回或变现需要时间的资产。信用卡和消费贷额度单独放在负债工具栏，不能加入存款总额。自己有权决定动用、能按时取出，并且不属于别人或另有用途的钱，才进入眼前现金安排。

<a id="money02-sub-01"></a>

### 用日期找缺口，而不只看月底总数

| 假设时间与事项 | 收支（元） | 可用余额（元） |
| --- | --- | --- |
| 月初已有余额 | 3200 | 3200 |
| 5 日交房租 | −2500 | 700 |
| 8 日账单应还 | −900 | −200 |
| 15 日工资到账 | +7200 | 7000 |

这张表故意没有列吃饭交通等其他支出：即便只看已列项目，8 日也已经缺 200 元，实际缺口只会更大。15 日有工资，不能解决 8 日的付款。应在到期前核实其他可用资金，了解能否依法依约调整付款安排，并计算新增费用；未经对方同意，不能把自己修改的日期当成已经延期。

<a id="money02-sub-02"></a>

### 把应急准备做成几个可达到的台阶

假设你的必要支出为每月 5000 元，另有一笔已知的搬家费 2000 元。先准备下一次工资前的账单；再考虑一个月必要支出 5000 元；三个月无收入情景是 15000 元，六个月是 30000 元。若希望这段时间也能搬家，应另加 2000 元，不把同一笔钱同时承诺给房租和搬家。这些月数是压力情景，不是每个人必须完成的储蓄指标。

目标要结合工作稳定性、再就业需要多久、照护责任和已有保障。每月只有 200 元余量时，可以先形成 600 元的小缓冲；它已经能减少一次小故障带来的临时借钱。有高成本债务时，把必要现金与还债成本一起比较，不机械地先存满六个月再处理债务。不要用不吃饭、不买药来完成目标。

<a id="money02-sub-03"></a>

### 存放方式要能服务于实际用途

检查能否及时支取、是否有本金损失风险、到账时间和提前取用条件。确属被保险存款时，同一人在同一家投保机构的所有被保险存款本息合并计算，最高偿付限额为 50 万元；这不表示在银行购买的理财或基金也受同样保护。[\[MONEY01\]](../SOURCES.md#source-money01) 不懂产品性质时，先通过机构官方渠道问清“这是不是存款，合同哪里写着”。

用过应急钱后，先记录用于什么、剩多少、下一笔刚性支出在哪里，再按恢复的收入补回。它被用于真实需要，正是它原本的用途。每月检查一次通常比每天盯余额更实用；遇到搬家、停工、孩子照护变化时，再主动重算。

<a id="money03"></a>

## 2.3 收入忽高忽低时，先把接单和生活账分开

自由职业、销售提成、季节工作和小生意的难点，往往是收入与账单的日期对不上。先把“已到账”“有明确合同和付款日但未到账”“尚在谈”分开。客户说下周结算，可以写在应收栏，日常生活安排仍要考虑延迟；不要因为开了发票就认为钱已在账户里。

<a id="money03-sub-01"></a>

### 营业额不能直接当作个人工资

假设某月项目到账 18000 元，其中材料及外包 4000 元、经营固定费用 1500 元，你根据自己的税费和社保情况另预留 2500 元，则可用于个人生活和经营储备的是 10000 元。2500 元只是这一教学案例中的自行预留数，绝不是通用税率或缴费标准；实际应向税务、社保机构核实。退单义务、售后成本和下一期采购也应另留。

先记录过去六个月每月能真正用于生活的钱，不用最好月份决定长期房租。可以自定一个较低的基础生活转入额，例如每月先安排 5000 元，多出来的部分进入淡月储备；该数字必须低于你通常可持续提供的金额。连续几个月不足时，说明需要改生活成本、接单方式或收入来源，而不是继续假定下月一定会补回来。

<a id="money03-sub-02"></a>

### 项目开始前，把收款节点谈清楚

| 要写清的事情 | 能实际使用的表达 |
| --- | --- |
| 交付范围 | 包含哪些文件、尺寸、次数；哪些算新增工作 |
| 验收与反馈 | 谁确认，多久集中提出反馈，怎样记录修改 |
| 付款节点 | 启动、阶段交付、尾款各多少钱，何时到期 |
| 变化与暂停 | 对方延迟材料或扩大范围，工期和费用怎样调整 |

例如可以提出：“本次报价包含两轮集中修改；新增内容请先确认费用和交付时间，再开始做。”这不是所有行业通用的合同条款，而是一种把工作量说清楚的办法。对方不愿签完整合同，也至少保留双方确认的服务内容、金额、付款主体和交付节点；涉及重大项目，应让专业人员审核合同。

<a id="money03-sub-03"></a>

### 回款延期时，不要只重复问什么时候付

发一条能核对的消息：“项目\_\_\_\_已于\_\_\_\_交付，按双方确认的安排，\_\_\_\_元应于\_\_\_\_支付。请确认验收状态及实际付款日期；如对交付有异议，请逐项列明。”附已经确认的材料，留存发送记录。对方要求继续增加工作，先评估停止、缩减或追加的合同后果，再书面商量，不在缺钱时无上限垫付。

把应收款按约定日期排序，每次跟进写下一次联系日。未收回之前不预先用于新的长期支出。若已经影响生活，先启动本章的收入中断安排，同时整理合同、工作版本、验收和收款证据，咨询适用的纠纷处理路径。催款可以坚定，不能用公开泄露客户资料或替自己编造验收记录来施压。

<a id="money04"></a>

## 2.4 收入中断的第一周，先完成四件具体的事

刚被裁员、离职、暂停营业或不得不休息时，不需要当天就把整个未来决定好。先拿一张纸写本周必须处理的四件事：确认原收入结算、知道下次账单缺口、核对社保医保、确定可用的求职或帮扶渠道。工作侵权证据和离职文件另见“工作中的权益”，不要因为急着拿一笔钱，签下自己不理解的放弃权利或全额结清说明。

<a id="money04-sub-01"></a>

### 把口头结算变成逐项确认

向原单位询问最后工资覆盖哪段期间、奖金或报销是否仍待结、已确认的补偿何时支付、离职证明和社保停缴记录怎样取得。分别写明金额、日期、对接人及仍有争议的部分。“公司会处理”不能填进到账日期。工资、补偿和失业保险是不同款项，不能因为其中一笔正在处理，就忽略其他应办事项。

现金表改成以周为单位。保留吃饭、住房、必要治疗、通信、求职交通和照护支出，暂停尚未承诺的大额非必要计划；已签合同的服务先查取消或退费条件。不要为了快速减少支出，直接退掉尚未理解后果的保险，或以新借款支付不必要的培训和所谓就业保证金。

<a id="money04-sub-02"></a>

### 失业保险是否可领，要对照自己的事实

法定领取条件包括失业前单位和本人缴纳失业保险费满一年、非本人意愿中断就业、已经办理失业登记并有求职要求。领取失业保险金期间，职工基本医保费按规定由失业保险基金支付，个人不缴纳该项基本医保费。[\[MONEY02\]](../SOURCES.md#source-money02) 是否符合、可领多久和标准是多少，由经办机构结合记录确认，不能只凭“离职”两个字判断。

准备身份证明、参保记录、解除或终止劳动关系材料等已有文件，通过当地人社官方渠道查看具体要求。不要为了迎合申请条件修改事实，也不要仅因离职证明写了某种表述就放弃询问。若单位停保原因或材料与实际不符，保留证据并申请核对。获批之前，预算里的待遇金额先写“待确认”，获批后仍核对实际发放。

<a id="money04-sub-03"></a>

### 给恢复收入安排一个能执行的节奏

先写你本周能做的动作，例如整理两段项目经历、联系一个已知招聘方、完成一次求职登记；同时限定求职时段，保留吃饭和睡眠。照护或健康状况暂不允许全职工作时，如实列出可工作时段及限制，再寻找匹配安排。不要用每天投多少份简历代替职位、薪资和通勤的筛选。

如果基本生活已经难以维持，可以向所在地社区、民政或公共就业服务机构说明家庭实际收入、资产、照护与就业情况，询问可申请的临时救助或就业服务及材料；是否符合由当地规则认定。求助时带一页情况说明和现有证明，记录受理机构、还需补什么、何时反馈。没有得到即时答复时，按回执继续跟进，不把一次无结果理解成所有渠道都已用完。

<a id="money05"></a>

## 2.5 离职后的医保，按自己的转换路径问清楚

先查询自己当前参加的是职工医保还是居民医保、参保地和最后实际缴费月份。向单位问到“缴至某月”之后，还要在当地医保官方渠道核对记录和待遇状态。银行卡扣款、参保登记成功、医保可以报销，是三个需要分别确认的结果；不要把其中一个截图当成全部办妥。

<a id="money05-sub-01"></a>

### 同城换单位、转自由职业和换城市，问题不同

| 自己的变化 | 优先核对 |
| --- | --- |
| 新单位即将接续 | 新旧单位分别缴至哪个月，是否存在空档 |
| 暂无单位，符合失业金条件 | 待遇审批及基金支付职工医保如何衔接 |
| 暂无单位，不走失业金路径 | 能否参加当地灵活就业职工医保或居民医保 |
| 跨城市工作或长期居住 | 参保转换、关系转移、待遇生效和异地就医安排 |

向经办机构说明完整情况：“我原在\_\_\_\_参加\_\_\_\_医保，实际缴至\_\_\_\_月，预计\_\_\_\_开始新工作／暂时没有单位。想确认从现在到\_\_\_\_的待遇怎样衔接。”然后逐项问：可以选择哪条办理路径；缴费标准及截止日；何时开始待遇；已有空档能否补缴、是否追溯。记录回答的适用地区、业务名称、日期和所需材料。

<a id="money05-sub-02"></a>

### 居民医保等待期不能凭经验忽略

国家政策自 2025 年起对未在集中参保期内参保或未连续参保的部分居民医保参保人员设置待遇等待期，并有特殊群体及修复等规则，具体标准由各省份确定。[\[MONEY03\]](../SOURCES.md#source-money03) 因此，不要把“以前交上就能用”当作这次转换的依据；也不要把居民医保规则直接套到职工医保中断后接续。

若客服说法不一致，把自己的险种、最后缴费月和拟办理日期写成同一段，再通过经办窗口或官方书面渠道确认。可以问：“请问这个答复对应哪份本地规定，适用于从职工医保转居民医保吗？”保留回执，按业务状态继续查；需要补正材料就写下完成日期，不只把咨询电话当作办理完成。

<a id="money05-sub-03"></a>

### 正在治疗时，把费用和办理同步安排

如有近期检查、住院或长期用药计划，先向经办机构和医院医保窗口确认该次就医的结算路径。不要为了等保障生效延误急需治疗，也不要向你推销商业保险的人询问基本医保能否追溯这种政策问题。已经自费的费用，保存完整票据和病历，询问能否依法按规则申请报销，不预先承诺一定能补回来。

把社保医保成本加入断薪预算。养老保险的记录、续缴和转移也要核对，但“暂时没缴”与“以前缴费全部作废”不是同一回事；具体资格条件另向人社确认。不要为省事付钱给不明机构虚构劳动关系挂靠。最后在接续表上填：原险种、停缴月、新路径、缴费凭证、待遇起始日、尚待处理事项。只有最后一项已明确，才能从待办中划掉。

<a id="money06"></a>

## 2.6 换工作时，用到手的钱和第一笔工资比较

“月薪涨了”值得高兴，也需要核对它由什么组成。先索取书面录用信息，列固定工资、绩效、试用期工资、发薪日期、工作地点、工时、福利与社保安排。奖金写“最高”“可达”或取决于考核的，不进入保守收入栏。书面录用信息也不能保证所有变化不发生，因此要把关键条件带入后续正式劳动合同核对。

<a id="money06-sub-01"></a>

### 先用同一口径比较两份工作

| 教学假设，每月金额 | 原工作 A | 拟换工作 B |
| --- | --- | --- |
| 预计实际到手收入 | 7500 元 | 8400 元 |
| 通勤支出 | 300 元 | 700 元 |
| 因工作新增餐费 | 200 元 | 500 元 |
| 因工时新增照护费 | 0 元 | 600 元 |
| 减去上述工作相关支出后 | 7000 元 | 6600 元 |

表中到手数是假设已按本人情况估算后的结果，不能把税前工资直接填在这一行。B 的到账收入多 900 元，但列出的工作相关支出多 1300 元，剩余反而少 400 元。这个结果不自动否定 B：技能、发展、环境和休息也可能值得；只是你需要知道自己实际是在交换什么，而不是只看一个月薪数字。

<a id="money06-sub-02"></a>

### 再算交接期，不要等入职后才发现两个月没发钱

假设旧工作 10 月底结束，新工作 11 月入职，而第一笔新工资在 12 月支付。向双方分别确认最后一笔和第一笔工资覆盖期间、到账日期、试用期算法，把 11 月每一项必付款排进现金日历。12 月会发工资，不能拿来支付 11 月已经到期的房租。搬家、体检、设备等费用也应注明由谁承担，避免入职后才补预算。

一般离职、试用期离职、协商解除和因单位违法解除，不是同一条路径；通知、补偿和证明的处理见“工作中的权益”。不要把上网查到的某个通知天数套在所有情形上。存在威胁或严重侵害时，先保障自身安全并求助，不以维持漂亮履历作为必须忍受的理由。

<a id="money06-sub-03"></a>

### 条件突然变更时，把差异写明再决定

可回复：“此前确认固定工资为\_\_\_\_，现文本为\_\_\_\_；工作地点也从\_\_\_\_变成\_\_\_\_。请确认最终条件及生效时间，我需要据此评估入职安排。”保留原消息、合同版本和回复。若对方只承诺“转正一定补回来”，请说明具体标准、由谁审批、哪一条写入文件；仍不明确的部分按未确定处理。

跨城机会还要核对住宿押金、返程、社保和生活支持；不熟悉的新行业可先询问实际工作任务和考核样例。对要求求职者先借款培训、代收业务款或交出银行账户的安排，暂停并独立核实。决定后写一个保底方案：若入职延后两周、岗位取消或不适应，你有哪些现实可用的现金与住处选择。保底方案是帮助行动，不是要求所有风险都消失后才换工作。

<a id="money07"></a>

## 2.7 债务多起来时，先看完整账，再谈怎么还

把每笔债务放到同一页：债权人、合同、剩余本金、到期日期、本期应付、年化利率及其他费用、抵押或保证、目前是否逾期、官方联系方式。不要只抄平台首页的“剩余额度”；它不是你已经欠的钱。对账后如有不认可的金额，标为待核实，保留合同和流水，不用反复借新钱让所有页面暂时显示正常。

<a id="money07-sub-01"></a>

### 先保住基本生活，再具体评估违约后果与成本

例如某人本月收入扣除必要生活后只能拿出 1800 元，三笔合同合计本期应付 2400 元，缺口就是 600 元。这个数字意味着需要提前沟通，不是把三笔各还一点就自动都算按时履约。房屋等担保财产风险、法定或合同到期要求、逾期费用、信用影响和剩余本金，都应分别了解。复杂债务或已有诉讼时，带齐资料咨询法律专业人员。

如果所有本期应付已能覆盖，才比较额外的钱用于提前还哪一笔：通常要比较综合成本、提前还款费用、利息计算方式和必要现金。不能只看日利率很小就觉得便宜。人民银行要求贷款产品明示年化利率，贷款成本计算包含利息及与贷款直接相关的费用；分期还本还要考虑实际占用本金。[\[MONEY04\]](../SOURCES.md#source-money04) 本章不提供一个适用于所有债务的固定排序。

<a id="money07-sub-02"></a>

### 直接找债权机构提出自己做得到的方案

通过合同或官方渠道联系，说明：“我因\_\_\_\_导致收入在\_\_\_\_期间减少。现有余额\_\_\_\_，每月扣除必要生活后约可偿还\_\_\_\_。请告知能否调整还款日期、分期安排或其他方案，需哪些真实材料，调整后总费用和信用记录如何处理。”不许诺自己明知做不到的金额，也不隐瞒会影响方案的其他债务。

对方提出方案时，逐项核对新的每期金额、期限、利息费用、原逾期怎样处理、提前结清条件、是否有新的授权或担保。要求通过可核实的正式方式确认，确认前仍按原合同理解义务；电话里“帮你登记”不等于已经同意减免或暂停。谈不成时保存沟通记录，询问正式投诉、调解或法律途径，而不是买所谓内部通道。

<a id="money07-sub-03"></a>

### 把债务协商与不法催收分开处理

遭遇威胁、泄露个人信息或其他侵害，保存时间、号码、原始信息和具体行为，向机构官方投诉；现实人身危险及时报警。对方有债权，不代表任何催收方式都被允许；同时，投诉也不自动免除真实债务。2026 年金融监管风险提示明确提醒防范“征信洗白”“强制停息挂账”等第三方保证，建议通过金融机构官方渠道沟通。[\[MONEY05\]](../SOURCES.md#source-money05)

不向中介交出银行卡、电话卡、验证码或空白授权，不伪造失业与病历材料。协商完成后，把新计划放入付款日历，首次付款核对收款方及凭证；每次付清一笔，取得相应结清证明并复核账户状态。收入再次变化时尽早联系，不等到多期违约才重新解释。

<a id="money08"></a>

## 2.8 买保险前读得懂，出险后才能找得到

先写自己想解决的损失：一次医疗费用、疾病期间收入中断、意外伤残，还是自己身故后仍需负担的债务和照护责任。已有基本医保与单位保障先列出来，再考虑商业保险填补什么。不要因为单身就被默认什么都不需要，也不要因害怕未来而一次买下长期交不起的保费。产品名称和“最高赔多少”都不能代替条款。

| 看合同的顺序 | 至少要找到的内容 |
| --- | --- |
| 保什么人、保多久 | 投保人与被保险人、保险期间、责任开始时间 |
| 什么情况赔 | 保险责任、疾病或事故定义、给付条件 |
| 哪些不赔或有限制 | 责任免除、等待期、既往情况、医院及地域限制 |
| 自己先承担多少 | 免赔额、赔付比例、限额、是否要求先用医保结算 |
| 以后怎样继续 | 续保条件、费率调整约定、缴费与退保后果 |

把不懂的条款发给保险公司官方客服，要求指出相应页码和适用情形。健康问询如实按问题作答，拿不准既往诊断、检查异常等是否涉及，就说明具体事实并取得可留存的答复；不要接受“别写，出险再说”。保险法对如实告知、免责条款提示说明和理赔材料有相应规定。[\[MONEY06\]](../SOURCES.md#source-money06) 保留问询原题、本人回答、核保结论、保单和付款记录。

<a id="money08-sub-01"></a>

### 用一个简化例子看懂“保额高”不等于这次全赔

假设某次符合合同范围的费用为 20000 元，合同约定本次尚需自行承担的免赔额为 10000 元，其余按 80% 支付，且没有其他扣除和上限影响，则示范计算为（20000−10000）×80%=8000 元。这只演示算法，真实合同对医保扣除、累计免赔、费用范围和比例顺序可能不同，必须按自己的条款算，不能把此例当作任何产品承诺。

“今年可以继续买”不等于合同保证未来续保。监管对短期健康险要求明确披露保险责任、等待期、免赔额等，并明确不保证续保；保险期间一年也不能单凭名称判断具体属性。[\[MONEY07\]](../SOURCES.md#source-money07) 若打算换产品，先核对新产品承保结论、等待期和旧合同终止后果，再决定，避免新旧都没接好。

<a id="money08-sub-02"></a>

### 想退保，先拿到拟办理当天的计算结果

通过保险公司官方渠道索取按拟退保日期计算的可退金额、计算依据、相关费用、保障终止时间和预计到账安排。已交保费不等于现在能退的钱；保险法对人身保险解除合同后的现金价值退还有规定，财产保险另有规则，具体还要核对险种、条款及是否适用犹豫期等约定。[\[MONEY06\]](../SOURCES.md#source-money06) 不把试算当作已提交退保申请，也不把账户显示的保险金额当作可退金额。若同时换产品，将新承保结论、等待期与新旧保障交接一起核对，再决定办理顺序。正式办完后保存申请回执、解除确认和到账凭证，逐项核对金额；不符时要求说明依据，再走官方投诉等处理渠道。

<a id="money08-sub-03"></a>

### 真的发生事故，先按官方渠道报案并索取材料清单

先处理就医和安全；能处理时查看保单报案要求，向保险公司说明事件时间、就医或事故情况，问清案件号、提交入口、材料清单和补交方式。按原件、提交副本、回执三个文件夹保存病历、费用明细、票据、医保结算单及其他被要求的材料，不为理赔修改事实。不同险种可能需要不同材料，不必一次向所有陌生联系人发送完整病历。

资料补充要求请对方明确列出。结果出来后，核对认定范围、免赔和赔付比例；拒赔或金额有异议，要求书面理由与条款依据，再带完整文件通过官方投诉、调解或法律途径处理。不要把“报案成功”当作已认可赔付，也不要相信收费中介能保证全额退保或理赔。档案留一页索引：公司、保单号、保障期限、官方电话、材料所在位置，密码另行保管。

<a id="money09"></a>

## 2.9 有人催你转账、借名或担保时，把操作停下来

对方可能是陌生客服，也可能是认识很久的人。判断时先看对方要求你做什么：转到新账户、开屏幕共享、下载不明软件、借出银行卡、用你的名字借款、为别人的债务签字。这些动作各有后果，不能用“他不会骗我”合并成一次信任测试。暂停操作不需要先证明对方有罪。

<a id="money09-sub-01"></a>

### 先切断催促，再独立核实

可以说：“我现在不转账，我会用原来保存的联系方式或官方渠道核实。”声称单位、医院、警方或亲友有急事时，回拨你原本可信的号码，核对真实事项和收款主体；不只点击对方发来的证明或转接。视频、声音和知道个人信息都不能单独证明身份。购物退款、账户异常等事项，从自己打开的官方应用或网站进入。

如果对方以投资、恋爱或工作为由，让你先试一小笔再追加，不用首次能提现证明整个安排可靠。向个人或陌生账户支付“解冻费”“追回款手续费”，或要求你代收再转走的钱，都应先停下。你可以请可信任的人只帮忙复核材料，无须把全部财务账户开放给他。

<a id="money09-sub-02"></a>

### 借钱与担保，要看最坏情况下自己承担什么

假设有人借 5000 元，而你可用现金只有 8000 元、下月必要支出 5500 元，即使对方真诚，你也没有 5000 元不影响生活的余地。可以明确回复：“这笔钱会影响我的房租和生活，我不能借。我可以陪你联系正规机构了解办法。”愿意借时，明确借款还是赠与、付款人与收款人、金额、用途及还款安排，保留双方确认和转账，复杂情形请专业人员审核。

“只签个名”“先用你的信用，之后再换回来”不能消除责任。保证合同可能使保证人在约定范围内承担他人债务责任，方式、范围、期间等影响重大；以你名义借款和替人保证也不是同一回事。[\[MONEY08\]](../SOURCES.md#source-money08) 不签空白或未理解的借款、保证和授权文件，不提供验证码让别人替你完成。已经签了又后悔，不能只发一句“我退出”就认为责任消失，应尽快取得合同并咨询。

<a id="money09-sub-03"></a>

### 已经转出去的钱，先争取止损再复盘

发现疑似诈骗立即停止继续转账，拨打 110，尽量提供时间、金额、收款账户、转账凭证和对方联系方式；按警方指引补交材料。如泄露银行密码、验证码或发生不明扣款，立即通过银行或支付机构官方渠道处理账户风险。[\[MONEY09\]](../SOURCES.md#source-money09) 不等把所有截图排版完成才报警，也不向自称黑客或追款团队再付钱。

没有立即追回，不代表报警没有意义；追回也不保证。记录报案或受理信息、承办联系渠道和后续材料要求，按通知补充。受到欺骗是实施诈骗者的责任。后续可以请信任的人陪着整理账和生活安排，但无需在公开社交平台披露完整流水、证件或隐私来换取理解。

<a id="money10"></a>

## 2.10 给自己留一张每月能继续使用的财务页

把前面几种表合并成一页摘要，原始账单和合同另存。目的不是把每一笔都展示得漂亮，而是在忙、累或突然停工时，十分钟内知道最先处理哪件事。纸、手机备忘录或表格都可以；工具复杂到让你不愿打开，就减到最少字段。

| 字段 | 填写示例（假设） |
| --- | --- |
| 本次核对日期 | 11 月 1 日 |
| 今天可用余额 | 9000 元；不包含 2500 元租房押金 |
| 未来 30 天确认到账 | 7200 元工资，15 日；项目款仍待确认 |
| 未来 30 天实际必付款 | 6000 元，已经包括本月应付年费 |
| 规划中的每月必要支出 | 5700 元；它是规划数，不重复加到实际账单 |
| 尚需核实 | 医保待遇起始日、一个项目尾款日期 |
| 本周动作 | 核对保险账单；联系客户确认验收 |
| 下次检查 | 收到工资后核对一次，月底再更新 |

按这个假设，30 天内总可用资金 9000+7200=16200 元，扣已列必付款 6000 元，剩 10200 元；但它仍不是“随便花的余额”，因为表未包含所有自选消费、之后月份的房租和应急目标。继续按日期检查中间是否会出现低余额。必要支出规划值 5700 元和本月实际账单 6000 元是两种观察口径，不能再相加扣一次。

<a id="money10-sub-01"></a>

### 每次只做四个核对

第一，到账是否与预期一致，未到账款移回待确认栏。第二，实际支出与计划最大的差异是什么，是否需要提高下一月预留。第三，未来三十天有没有保险年费、季付房租、孩子费用等不常发生的账。第四，债务、医保或理赔是否还有需要主动跟进的事项。每项写一个下一步和日期，不留下“以后注意”这种无法执行的待办。

如果当月超支，先判断原因：偶发的维修可用应急钱；持续的房租、照护或医疗支出上涨，需要重做必要支出；一时兴起的消费可以调整下月计划，但不必把所有正常快乐都删掉。若连续出现入不敷出，把收入与固定支出拿出来处理，单靠更细的记账通常不会填补结构性缺口。

<a id="money10-sub-02"></a>

### 重要材料与账户安全分开存

文件可按“收入与社保”“借款与还款”“保险与理赔”“月度账单”分类，文件名带日期和事项。摘要只写账号尾号与材料位置，不放完整密码、支付码和身份证照片。需要别人帮忙时，可提供与问题相关的删减版；委托处理应另核实授权范围，不因为对方帮你记过一次账就默认可以替你转钱。

最后为下一月写一句具体安排，例如“工资到账后先留足 5 日房租，并每月为年费预留 300 元”，而不是“下个月一定少花钱”。没有足够余量时，也可以写“本周完成医保咨询和债务方案核对”。这张页的作用是使生活接得上，不是把你变成永远不能犯错的财务管理员。
