# 01 住得安心

[总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：收入撑得住生活 →](02-money.md)

<a id="introduction"></a>

找房、签约、入住、居住和退租是相互连着的事情。本章沿着这条顺序，写清每一步需要核对的材料、发现问题后的处理办法，以及可以修改使用的话术。

主要适用于中国大陆城镇市场租房。独居、合住、带孩子、照护家人、养宠物或行动不便的读者，可以把自己的需要写入选房条件。公租房、农村住房、单位宿舍等另有规则，不能直接套用全部条款。金额、日期与情境均为教学假设。[\[H1\]](../SOURCES.md#source-h1)

## 1.1 租得起要算两笔账

先问两个不同的问题：住进去后，每个月能否持续负担；签约当天，手上是否有足够现金。押金通常是暂时被占用的钱，首期预付租金覆盖未来月份，两者都不能只靠“月租不高”判断。

<a id="home01-sub-01"></a>

### 第一笔  每个月实际要花多少

用近几个月账单估计吃饭、医疗、债务、照护和其他必要支出，再确定能留给住房的金额。以下两套房完全是假设，只展示计算方法；水电燃气和交通应换成自己的用量、账单或可核实的计价。

| 项目 每月 元 | 房源 A | 房源 B |
| --- | --- | --- |
| 租金 | 2300 | 2700 |
| 物业 | 150 | 150 |
| 电费估计 | 180 | 160 |
| 水与燃气估计 | 120 | 60 |
| 网络 | 50 | 50 |
| 相关通勤交通 | 350 | 180 |
| 每月合计 | 3150 | 3300 |

B 的月租贵 400 元，但在这些假设下，总支出只多 150 元。还应比较通勤耗时、噪声、能否做饭和照护便利，不能仅凭这个结果选 B。夏冬电费差异、停车费等未列项目，要按自己的情况补进来。

<a id="home01-sub-02"></a>

### 第二笔  搬入前需要多少现金

假设 A 押一付三，B 押一付一，两套房均另需搬家 600 元、必要添置 300 元，没有其他前期费用：A 需要 2300 × 4 + 600 + 300 = 10100 元；B 需要 2700 × 2 + 600 + 300 = 6300 元。

如果另有中介费、网络安装费、旧新租期重叠，应继续加上。旧房押金只有实际到账后才可算作可用现金；不要把预计退回的钱安排成新合同当天一定能付出去的钱。

<a id="home01-sub-03"></a>

### 比较完以后做什么

给每套房写下三个结果：月度总支出、首次付款、尚未查明的收费。若日常生活费必须靠借款才能接上，先调整区域、面积、合住方案或付款条件，再决定；不要用一张空白预算表代替算过的结果。

<a id="home02"></a>

## 1.2 先弄清谁在把房子租给你

看房人、产权人、合同上的出租人和收款人，可能不是同一个人。你要核实的是他们之间的关系与权限，而不是看到某张证件照片就结束检查。《住房租赁条例》要求出租人出示身份与合法出租权材料，并配合依法核验。[\[H1\]](../SOURCES.md#source-h1)

| 遇到的情形 | 需要顺着核对的材料与关系 |
| --- | --- |
| 产权人直接出租 | 身份证明与产权或其他合法出租权材料；地址是否对应，签约主体是否一致；有共有等情况时进一步核实出租权限。 |
| 他人代产权人办理 | 除出租权材料外，核对授权的事项和期限，是否包含签约、交付等具体行为；通过可独立核实的途径向委托人确认。 |
| 现住户或个人转租 | 核对上手合同、剩余租期、出租人的同意或其他有效依据。对方自己还可租多久，与你准备租多久分别写清。[\[H2\]](../SOURCES.md#source-h2) |
| 企业经营出租 | 核对合同公司、经营与公开信息、对该房的经营管理权、收款账户。经营出租的企业与仅提供撮合的经纪机构不是同一角色。 |
| 中介带看或平台发布 | 核对经纪机构与人员信息、服务内容和中介费。经纪机构和信息发布平台不得代收代付住房租金、押金，不能把付款给带看人的个人账户作为交租方式。[\[H1\]](../SOURCES.md#source-h1) |

<a id="home02-sub-01"></a>

### 四项信息有一项对不上就继续问

把房屋地址、合同出租人、出租权限、付款安排写在同一页。出现不一致，可以问：“合同是甲方的名字，但你要求我付给乙方，请先提供能说明关系和收款安排的材料。”不一致不自动证明诈骗，但解释和文件未核实前，先不付款。

<a id="home02-sub-02"></a>

### 对方只发截图时

可以要求在签约时查看原件或可核验的电子材料，并通过当地官方租赁管理、房产信息或登记服务渠道依法核查；哪些信息可查、谁能申请，要按本地权限办理。若对方始终拒绝出示材料，只用“大家都这样”催付款，保留记录并结束这次交易。

核实不等于无限复制别人的身份证和产权资料。只保留办理和举证必要的信息，安全存放；不要把完整材料发进公开群。转租的法律规则见民法典第 716—717 条。[\[H2\]](../SOURCES.md#source-h2)

<a id="home03"></a>

## 1.3 看房时按生活顺序走一遍

带上能拍照和记事的手机，先征得拍摄与测试同意。请对方具体说明房屋条件，并逐项核对；不拆插座、不爬出窗外，也不靠试用去验证明显异常的燃气或电器。

| 检查位置 | 现场怎样做 | 发现问题后记什么 |
| --- | --- | --- |
| 到家路线 | 按通常下班时间走最后一段路，查看照明 门禁 电梯与实际通勤 | 末班交通或回家方式；雨天 夜班 照护接送是否仍可行 |
| 门窗与出口 | 开合门窗并试锁；从门口走到楼梯和地面出口 | 锁具损坏 通道堵塞；是否已明确处理人 |
| 睡觉的位置 | 站在床可能摆放的位置听道路 邻居和设备噪声 | 是否影响自己睡眠；只在白天看过则标为待复看 |
| 墙角与柜后 | 查看可见渗水 返潮 霉斑以及新遮盖的局部墙面 | 位置 面积照片；问出现时间 来源和修复记录 |
| 厨房与卫生间 | 短时开水 看下水 冲厕；查看柜底和洁具连接处 | 滴漏 堵塞 异味；不要只接受口头说交房前会修 |
| 固定家电 | 允许且无明显异常时，按正常用法测试基本功能 | 品牌型号 故障现象；危险异常则停用报专业人员 |
| 水电燃气收费 | 问清计量户号或抄表方式 看最近账单和计价依据 | 谁收款 多少单价 如何分摊；与合同是否相符 |
| 你自己的需要 | 确认做饭 晾晒 收纳 信号 宠物 无障碍或孩子活动条件 | 不满足的项目能否调整 由谁同意和承担费用 |

<a id="home03-sub-01"></a>

### 把结果分成三类再决定

可以接受：只是装饰和个人偏好差异；待解决：维修或费用问题尚未明确，需要复看或写进合同；先暂停：出租权不清、明显安全异常，或对方拒绝必要核验。分类是编者的决策办法，不是工程检测等级。

最终给对方发一条汇总：“今天看到卧室窗锁松动、洗手盆柜底有渗水，请确认是否在交付前修好，何时可复看。”修好再复核，或在已理解影响的前提下协商；存在安全健康风险时，不把租金优惠当作修复。

<a id="home04"></a>

## 1.4 合同里要能找到明确答案

逐条读完整文本与附件，先核对这八项。这里的示例用于提出修改，不是一份可直接代替完整租约的合同。官方 2025 版示范文本可以对照查漏。[\[H3\]](../SOURCES.md#source-h3)

| 项目 | 签字前应得到的答案 |
| --- | --- |
| 租的是什么 | 准确地址 整套或指定房间 可使用的公共区域；家具设备清单和已存在的缺陷。 |
| 租多久 何时交房 | 起止日期 交钥匙日 免租期；旧新住处有无重叠；对方交付延迟怎样处理。 |
| 总共收什么钱 | 租金 押金 物业 水电燃气 网络 中介服务等逐项列；每项谁支付 谁收 什么时间到期。 |
| 押金何时退 | 返还的触发条件 具体期限 可扣项目 结算方式；尚未出账的水电怎样处理。 |
| 坏了谁处理 | 哪些房屋和设备由谁维修；报修方式 进入预约 垫付确认和结算安排。 |
| 谁可以进门 | 常规检查 维修或带看先联系并约时间；不要留下“房东可随时进入”的含混表述。 |
| 提前离开怎么办 | 需要提前多少天通知 怎样送达 违约责任 如何找替租人；转租需要哪些同意。 |
| 到期怎么交接 | 通知与续租日期 验收标准 钥匙和账户交还 押金结算 争议处理条款。 |

<a id="home04-sub-01"></a>

### 把含混约定改成可讨论的文字

例如，“押金退房后退”可以提出补充：“双方于\_\_\_\_日办理房屋交接。租赁期间费用结清后，甲方于\_\_\_\_日内返还应退押金；拟扣项目应列明金额及依据。尚未出账的费用双方另行确认预留金额与结算日期。”留空项必须协商填妥，天数不是全国统一法定标准。[\[H1\]](../SOURCES.md#source-h1)

谈不拢时，看分歧是否会影响基本居住、资金或退出能力，再决定是否签。不要签完后才假定自己不喜欢的条款一定无效。所有附件与修改都留完整版本，核对签章；付款备注用途和期间，索取凭证。

维修、正常使用损耗、转租等还受法律规则约束，并非合同写什么都当然有效；重大不利条款或金额争议，应带完整文本咨询。[\[H2\]](../SOURCES.md#source-h2)

<a id="home05"></a>

## 1.5 合住要先区分对外合同和内部约定

合住时，“我只交自己那份”可能只是一句室友间的约定。先搞清与出租人签约的是谁，再谈日常分摊；内部约定能减少误会，但不能自动改变出租人依法享有的合同权利。

<a id="home05-sub-01"></a>

### 先画出签约关系

各自直接向房东租一间：分别核对房间与公共区域、各自押金、账单计量和维修联系。多人共同承租整套：核对每个人的身份、租金与违约责任如何约定，一人搬走是否需要其他人和出租人同意。一个人承租后再分租：还要检查转租权限、上手租期以及钱交给谁。[\[H2\]](../SOURCES.md#source-h2)

<a id="home05-sub-02"></a>

### 把五项日常规则谈具体

访客：是否允许过夜、提前告知方式、长期增加居住人数怎么办。安静时段：讨论各自真实的上班睡觉时间。卫生：按区域或轮值明确谁清洁，谁买公共用品。费用：哪些平摊、哪些按实际人数或独立计量。退出：提前告知、寻找新住户、押金结算和交接各由谁负责。

<a id="home05-sub-03"></a>

### 费用分摊可以这样演示

假设两人约定公共水电每月平摊，当月账单合计 260 元，则每人 130 元。某人多住了一位访客，另一方不应到月底才临时规定加倍收费；应提前讨论适用条件和计算方式。室友暂时出差是否仍分摊固定网络费，也先说清。示例不代表法定分摊比例。

<a id="home05-sub-04"></a>

### 不舒服的事情出现时怎样开口

可说：“这周有三晚凌晨还有很大说话声，已经影响我第二天工作。我们能否从今晚开始在约定时间后到客厅轻声聊，或改在外面聚会？”先描述可核对的行为，再提出明确改变；避免只说“你没有边界感”。

反复无法执行时，先保留沟通记录并核对自己的退出成本；需要时由出租人按合同参与协调。出现威胁、暴力或擅自使用你的账户和财物，优先确保人身与财物安全，不能只把它当作磨合问题。

<a id="home05-sub-05"></a>

### 共同确认的简短记录

“我们确认每月\_\_\_\_日前核对账单，按\_\_\_\_分摊；访客规则为\_\_\_\_；对方未同意时不进入其房间、不使用其个人物品。有人准备离开，按租约和另行确认的交接安排办理。”记录经双方确认后，各存一份。

<a id="home06"></a>

## 1.6 入住第一天留下可比较的记录

先完成交接，再拆大件行李。你需要的是以后能对照的房屋状态，不是拍几张看起来干净的远景。请出租人或其明确授权的人共同核对；对方未到场时，把当天记录及时发送并请其确认。

<a id="home06-sub-01"></a>

### 照片拍到哪里才有用

先从门口连续拍各房间整体，再拍缺陷近景。近景带上可以辨认位置的参照，并另拍一张说明它属于哪个房间。记录墙面旧痕、窗锁、家具边角、浴室渗水、家电显示和水电燃气读数。对显见异常停止试用，请专业人员检查。

| 交接记录 | 填写示例  均为虚构 |
| --- | --- |
| 位置与现象 | 卧室靠窗左侧墙面有一处旧磕痕 约指甲大小 |
| 证据编号 | 2026-10-08\_卧室墙面\_远景 与 同名近景 |
| 是否影响使用 | 目前不影响 已告知对方并保存回复 |
| 需要维修的项目 | 浴室窗锁松动 由出租人联系维修 |
| 约定安排 | \_\_\_\_日前联系人员 进门前与我预约 |
| 钥匙与权限 | 实体钥匙\_\_\_\_把 门禁\_\_\_\_张 智能锁管理员与旧权限待核对 |

<a id="home06-sub-02"></a>

### 把常用设施的正确用法问一遍

请房东、物业或专业人员指出总水阀、配电箱与燃气阀的位置，说明对应范围和正常操作；不凭开关颜色猜测。保存热水器、灶具的型号和说明书，记下官方报修途径。更改线路、燃气和安装方式由有相应能力的人员处理。[\[H4\]](../SOURCES.md#source-h4)

<a id="home06-sub-03"></a>

### 第一晚只安排真正必需的东西

先有能正常锁上的门、照明、手机充电、饮水、洗漱用品和基本寝具，再按生活补齐其他物品。确认回家路线和楼梯出口，设置自己能控制的门锁权限。把新地址告诉已同意的联系人，说明临时求助时怎样联系，不把完整证件和密码放进共享表。

保存顺序可用四个文件夹：合同与付款、入住状态、维修记录、退租交接。文件名包含日期、房间或事项；原图原消息另存，不只保留经过编辑的拼图。

<a id="home07"></a>

## 1.7 访客 维修人员和钥匙各有安排

日常安排的目标是知道谁会来、为什么来、如何结束这次访问。依据自己住所的设施和生活方式选择，不需要全天监控自己，也不把反复检查当作安全感的唯一来源。

<a id="home07-sub-01"></a>

### 有人临时上门时先核身份与任务

隔门或通过已有通讯方式确认对方来意。没有预约的维修、抄表、推销，先通过你已经核实的物业或服务机构联系方式确认，不仅拨打来人临时给你的号码。你可以说：“我先和报修平台确认工单，请稍等。”确认不了，重新预约。遇到暴力威胁等现实危险，联系警方。

<a id="home07-sub-02"></a>

### 报修预约讲清四件事

约定日期与时间范围、到场单位、具体故障、是否需要你本人在场。进入之前确认收费的组成：检查、人工、零件、上门费；有新增项目先报价再决定。需要离开家让别人操作时，先商量钥匙保管和结束后锁门确认；不把“有人来修”理解成所有人都可以自由进出。

<a id="home07-sub-03"></a>

### 房东带人看房也要预约

常规带看可回复：“周六 15 点到 16 点方便，请提前告诉我人数，我届时在场。”《住房租赁条例》对出租人擅自进入设有限制；同时保留依法可进入的情形，不能把日常预约安排解释为阻挡紧急救援。[\[H1\]](../SOURCES.md#source-h1)

<a id="home07-sub-04"></a>

### 钥匙和数字权限一起交接

智能锁核对管理账号、临时密码和旧住户权限，按设备说明及双方约定处理；需要换锁先约定责任与费用。对属于自己的路由器、摄像头、智能音箱和云端账号，检查谁有共享权限。新接手设备不能只换 Wi-Fi 就默认旧权限全部消失。

确实需要摄像设备时，先考虑放置范围是否会拍到室友或其他人的私人生活，与受影响的人协商并遵守法律及物业要求。门口有人经过、快递到达等普通情况，可以按预先安排处理；不必把每次动静都升级为异常。

<a id="home07-sub-05"></a>

### 忘带钥匙的备用办法

把物业、正规开锁服务和可信任联系人的信息保存在能取到的地方。请服务方说明身份核验和报价，避免由陌生人直接破坏门锁。若保留备用钥匙，选择双方同意且可控的保管方式；不在公开位置留下“钥匙放在哪里”的提示。

<a id="home08"></a>

## 1.8 报修要让对方知道发生了什么和你需要什么

先判断是否存在现实危险。普通设备故障可以按下面步骤沟通；燃气味、冒烟、明显漏电或水接触电气设备等情况，先按“安全异常先决定停用还是离开”一节求助，不等待对方在聊天里批准。

<a id="home08-sub-01"></a>

### 第一步  一次发齐信息

可修改使用：“我是\_\_\_\_房屋的承租人。今天\_\_\_\_时发现\_\_\_\_，具体表现为\_\_\_\_，已影响\_\_\_\_。附件是照片或视频；我已停止使用相关设备。请确认由谁检查和维修、预计何时联系。我可配合进门的时间是\_\_\_\_。”

例如“热水器坏了”不如“今天晚间正常开启后无法出热水，屏幕显示\_\_\_\_；我没有拆机，已停止使用”。描述观察到的现象，不自行诊断零件损坏；不反复试机去拍更多视频。

<a id="home08-sub-02"></a>

### 第二步  确认责任与下一次联系

查合同的维修约定，再核对设备是否由出租方提供、故障如何发生。民法典对维修义务、合理期限及承租人过错作有区分，不能概括为所有维修都由房东付钱。[\[H2\]](../SOURCES.md#source-h2) 请对方回答负责人员、检查时间和费用确认方式，并把下一次跟进写进日历。

<a id="home08-sub-03"></a>

### 第三步  对方拖延时继续留完整记录

可以再发：“我于\_\_\_\_日已报告该问题，目前仍无法\_\_\_\_。请在\_\_\_\_前回复具体检查安排。若不能按期处理，请说明替代方案。”这里填写的是你提出的回复时点，不是法律统一规定的维修天数；是否属于合理期限要看故障与影响。

<a id="home08-sub-04"></a>

### 第四步  需要垫付时先核实条件

民法典第 713 条规定了出租人未履行维修义务时的相应处理，但是否满足条件、金额是否合理、证据是否充分仍需判断。[\[H2\]](../SOURCES.md#source-h2) 能事先确认时，发送项目、报价、付款人和报销日期，请对方书面回复。保存维修前后照片、工单、明细和付款凭证；不要把单方面购买更贵的新设备都当作必然可报销。

存在争议时，可先带合同、报修记录和报价咨询当地房产管理或法律服务渠道。不要因觉得对方应付维修费，就自行决定扣租或停交全部租金。危险处置和必要的应急求助不应被账款争议拖延。

<a id="home09"></a>

## 1.9 安全异常先决定停用还是离开

以下用于识别需要停止日常处理的情形。不是维修教程，也不能替代消防、燃气或急救人员的指令。住处平时就应有可找到的抢修电话和出口位置。

<a id="home09-sub-01"></a>

### 闻到疑似燃气味

不要操作电灯、排风扇等电器开关，不点火，不在室内拨电话。在自身安全、无需冒险靠近泄漏处的条件下关闭气源和开窗，尽快撤至室外安全处，联系燃气抢修；紧急情况拨 119。不要返回室内拍照证明气味，也不要自行拆管找漏点。[\[H4\]](../SOURCES.md#source-h4)[\[H5\]](../SOURCES.md#source-h5)

<a id="home09-sub-02"></a>

### 出现烟火或浓烟

拨 119 说明准确地址、楼层和是否有人被困。通道安全时沿楼梯撤离，不乘普通电梯；通道已被浓烟封住时不要硬闯，关门隔烟，在相对安全处等待救援并报告位置。不同建筑和火情处理会不同，按现场救援指令行动。[\[H6\]](../SOURCES.md#source-h6)[\[H7\]](../SOURCES.md#source-h7)

<a id="home09-sub-03"></a>

### 水靠近电器或电路异常

先远离有水、裸露线路或疑似带电的区域，不涉水接触开关或配电箱，不反复合闸。让物业或专业人员处理；已出现烟火按火警求助。只有已知位置、可安全接近、自己理解正确操作的开关，才考虑按既有专业指导停用；不为关电冒险。

<a id="home09-sub-04"></a>

### 普通滴漏或设备无法工作

没有烟火、气味、触电等危险迹象时，停止使用相关设备，记录现象，联系责任方。可在安全情况下移开易损物品、接住少量滴水；这些临时措施不能代替排查原因。情况加重时重新判断，不因为起初只是小故障就继续等待。

<a id="home09-sub-05"></a>

### 电话里先说位置 再说情况

“我在\_\_\_\_区\_\_\_\_小区\_\_\_\_栋\_\_\_\_单元\_\_\_\_楼\_\_\_\_号，目前有\_\_\_\_，我已经在\_\_\_\_位置，现场有\_\_\_\_人，联系电话\_\_\_\_。”能看到的事实说清楚，不能确定的不要猜。听从接线人员指导，保持电话可联系。

身体不适需要医疗急救时拨 120。有人现实威胁、强行闯入等人身危险时拨 110。纯粹的押金或收费争议应走相应协商和法律渠道，不能预期报警就会即时解决。

<a id="home10"></a>

## 1.10 退租从通知日开始安排

先读合同中的通知、提前解除与交接条款。以下是工作顺序，不是全国统一的退租期限。把自己的日期填进去，完成一项就保存相应记录。

| 时间节点 | 要完成什么 | 留下什么记录 |
| --- | --- | --- |
| 合同要求的通知日前 | 确认是否到期退租或提前退出 按约定方式发通知 | 通知正文 送达信息 对方回复 |
| 搬家日期确定后 | 约交接时间 获取搬运完整报价 安排网络及收件变更 | 时间确认 报价单 待办清单 |
| 交接前 | 清点物品 清理个人数据 对照入住缺陷与设备清单 | 原始入住记录 待处理问题清单 |
| 交接当天 | 拍整体和细节 核抄表读数 交钥匙 逐项确认结算 | 双方确认的交接单 照片视频 账单 |
| 约定返款日 | 查是否实际到账 仅对未结项目继续跟进 | 到账流水 仍有争议的金额和理由 |

<a id="home10-sub-01"></a>

### 通知可以这样写

“我承租\_\_\_\_房屋，合同期限为\_\_\_\_至\_\_\_\_。现根据合同第\_\_\_\_条通知拟于\_\_\_\_日退租，建议\_\_\_\_时办理交接。请确认钥匙交还、账单核对及押金返还安排。若有需要提前处理的项目，请列明。”提前解除时应如实说明情形，别把到期退租模板直接用在所有情况。

<a id="home10-sub-02"></a>

### 交接前按原状核对

拿入住照片逐项比对：原来已有的缺陷、正常使用形成的损耗、可能需要你承担的损坏，分别记录。正常使用损耗与违约损坏的责任不同。[\[H2\]](../SOURCES.md#source-h2) 不在压力下把所有事项统一写成“承租人损坏”，也不直接宣布所有痕迹都属于正常损耗。

<a id="home10-sub-03"></a>

### 交钥匙时仍有分歧

写清双方已确认和未确认的事项，保留返还房屋、交钥匙与沟通证据。比如：“钥匙已交\_\_\_\_把；水电结清至\_\_\_\_；关于\_\_\_\_的扣款，双方尚有争议。”不要为了先离开就签与事实不符的“押金已全额退回”。对方拒绝接收等复杂情况，及时咨询合法交付与证据保留方式。

<a id="home11"></a>

## 1.11 押金争议先把一笔钱拆开

以下是虚构情境。你交了押金 2000 元，退租时对方提出扣清洁费 300 元、墙面修复费 400 元，只愿退 1300 元。下一步不是反复说“凭什么扣”，而是分别核实两项扣款的约定、事实和金额。

<a id="home11-sub-01"></a>

### 第一步  要一份逐项结算

发给对方：“请分别列明清洁费 300 元和墙面修复费 400 元的合同依据、对应照片及费用明细。我会对照入住和退租记录核对。请同时确认其余无争议金额的退回安排。”先收无争议部分是否会影响后续主张，要看对方要求你确认什么；不要随意签最终和解。

<a id="home11-sub-02"></a>

### 第二步  为每项找对应的事实

| 争议项 | 先核对的材料 | 可以提出的具体问题 |
| --- | --- | --- |
| 清洁费 | 合同清洁标准 交接照片 是否实际约定固定费用 | 是哪处未达到约定标准 如何得出300元 是否已实际发生费用 |
| 墙面费 | 入住同位置照片 退租照片 原有缺陷与使用经过 | 哪些是新增损坏 如何修复 为何需要整面处理 而非局部 |
| 未结水电 | 表号 起止读数 计价与历史账单 | 结算期间是否全属于我的租期 有无重复计费 |

<a id="home11-sub-03"></a>

### 第三步  发一条有金额的回应

“关于\_\_\_\_元，我对\_\_\_\_事实有异议，附件\_\_\_\_可供核对。我认可的已结费用是\_\_\_\_元，目前请求返还\_\_\_\_元。请于\_\_\_\_前回复结算依据和付款安排。”填写自己能够说明的金额，不因为情绪强烈就把不确定的损失都加上。对合同未约定且无正当理由的扣减，可以提出异议；具体认定仍看合同和事实。[\[H1\]](../SOURCES.md#source-h1)

<a id="home11-sub-04"></a>

### 第四步  协商不成时带材料找对渠道

整理一页事实时间线、合同与补充约定、押金付款、入住退租材料、扣款通知和催告记录。向房屋所在地房产管理或公共法律服务渠道说明问题，确认行政投诉、调解、仲裁或诉讼各自条件；仲裁并不是没有适用条件就能任选。保存受理信息与后续期限。

正常使用损耗可依据民法典第 710 条讨论；押金、维修、腾退纠纷的处理渠道见住房租赁条例第 35 条。[\[H1\]](../SOURCES.md#source-h1)[\[H2\]](../SOURCES.md#source-h2) 这些依据帮助提出主张，不保证每项扣款都会被撤销。
