# 04 身体由自己照顾

[← 上一章：生病时有安排](03-medical.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：一个人也要吃好 →](05-food.md)

<a id="introduction"></a>

照顾身体可以从很具体的事开始：把一份异常报告处理到有下一步，找到适合自己的避孕方式，在反复失眠时约一次门诊，给一周留出能做到的活动时间。目标是让身体得到需要的照顾，也让生活留有余地。

本章面向成年读者。年龄、既往疾病、正在出现的症状、性接触和妊娠可能会改变建议，婚姻状态无法代替这些信息。下面的记录方法与话术可直接改写；检查、用药、接种和运动的个体方案应与相应专业人员确认。

## 4.1 安排体检时，先列问题，再挑项目

打开体检套餐以前，先写自己为什么想检查：有症状需要解释、旧异常到了复查时间、存在家族风险，还是没有不适、想安排常规预防？这几种情况的入口不同。已经出现乳房新变化、异常阴道出血或持续影响生活的不适，应及时到相应门诊评估，不能只等单位年度体检；无症状筛查与针对症状的诊断性检查也不能混为一谈。[\[BODY01\]](../SOURCES.md#source-body01)[\[BODY02\]](../SOURCES.md#source-body02)[\[BODY15\]](../SOURCES.md#source-body15)

<a id="body01-sub-01"></a>

### 先做一张个人情况卡

写年龄、主要疾病和手术、正在用的药、以前重要异常和处理结果。家族史尽量记谁患过什么病、大约多少岁发现，不知道就写未知，不必靠猜测填满。吸烟、工作暴露、性接触、妊娠可能和既往宫颈病变等信息，按实际需要向医师说明。可以申请单独沟通，不必由陪同者替你回答。

| 先问的内容 | 为什么要问 |
| --- | --- |
| 这项检查适合我的年龄和风险吗 | 确定是否属于需要的人群 |
| 主要寻找什么问题 | 避免只看项目名称或“全面”二字 |
| 可能出现什么假阳性或漏检 | 理解正常和异常都存在边界 |
| 异常后需要做什么、花多少时间 | 为后续诊断和随访留预算 |
| 上次何时做、结果是什么 | 避免机械重复，也避免漏掉规定复查 |

可以把医生建议整理成三栏：现在做、到指定时间做、目前不需要或需要更多资料再决定。每项写理由和下一步日期。这不是你凭网络资料给自己开检查，而是把咨询结果变成可管理的安排。若对方只说“女性都要查”，继续问适用于你的具体依据；若医生根据症状提出检查，则请其解释诊断目的。

<a id="body01-sub-02"></a>

### 把预算留给后续处理，不全花在第一次筛查

虚构预算示例：你能够用于本轮健康安排的现金是1200元。先核实已被建议的项目与门诊费用，再留出复诊、交通和可能的进一步检查空间。不是将1200元一次全部买成套餐，也不是所有人都只花这个金额。预算不足时，直接请医生按医疗紧迫性和收益解释先后顺序，不自己删掉最关键的一项。

中国国家“两癌”筛查工作方案对服务对象和实施流程有明确安排，其中项目对象为35至64周岁妇女，并优先保障部分人群；这不等于其他年龄不需个体评估，也不保证每个地方对所有人免费。[\[BODY01\]](../SOURCES.md#source-body01) 向当地妇幼保健机构或社区核对现行年龄、居住或户籍、既往筛查间隔、预约和后续诊断收费，得到确认再登记。

没有异常时，把医师建议的下一次时间记入日历，而不是年年换一家机构重复购买全套。发现异常时，将任务从“体检完成”改为“等待解释或复核”。完整体检的结束标志，是每个需要处理的问题都有负责人、日期和下一步。

如果某项检查让你不舒服或担心隐私，提前说明，询问目的、操作方式和可行替代。你不需要为了证明自己重视健康而接受没弄明白的操作，也不必因害怕就彻底不就医；把困难说出来，和医疗团队共同找到能够完成的路径。

<a id="body02"></a>

## 4.2 乳腺和宫颈报告异常时，把担心换成待办事项

“阳性”“结节”“建议进一步检查”会让人紧张，但这些词本身不等于癌症诊断。宫颈筛查的目的包括发现需要进一步评估的异常；筛查、后续诊断和治疗是连续但不同的环节。[\[BODY01\]](../SOURCES.md#source-body01)[\[BODY02\]](../SOURCES.md#source-body02) 拿到报告后先保存全文，核对姓名、日期、检查种类和结论，不只把最吓人的一行截给朋友。

<a id="body02-sub-01"></a>

### 先确认这份报告现在需要谁来解释

联系开检查的门诊或项目指定随访机构，说明报告已出、有何结论以及是否有症状，询问预约科室和时间要求。若报告已注明尽快复诊或医院主动通知，按要求行动；电话暂时接不通，通过医院官方服务台确认替代渠道。不要因为没有痛感就默认可拖到下一年。

准备三个问题：“这次检查已经知道什么，尚未知道什么？下一项检查是为了确认什么？请写明最迟何时完成或何时复查，以及期间出现什么变化要提前来。”如果有旧影像、宫颈细胞学、HPV或病理资料，带齐前后版本。是否可以对照、是否需要重复，由医生根据质量和时间判断。

| 得到的建议 | 应该落实到纸上的内容 |
| --- | --- |
| 按期复查 | 哪一项、哪一天或时间范围、哪个科室 |
| 进一步诊断 | 预约入口、准备、是否需要陪同、结果解释 |
| 转诊 | 推荐机构或专业、需携带的原始资料 |
| 开始治疗讨论 | 目的、备选方案、风险及允许考虑的时间 |

教学情境：报告写“建议进一步评估”，你不把它改写为“确诊严重疾病”，而是先预约能解释报告的门诊；门诊明确下一项及时间后，再把状态标为“待完成”。检查完成后继续追踪结果，不因为做了第二次检查就把整件事划掉。表格记录的是行动，不是自行判断病情轻重。

<a id="body02-sub-02"></a>

### HPV结果不适合用来推断感情经历

HPV感染与癌前病变、癌症不是同一件事，后续取决于具体结果与个体情况。疫苗用于预防，不能当作清除现有感染的治疗；接种后仍需按适合自己的方案筛查。[\[BODY02\]](../SOURCES.md#source-body02)[\[BODY03\]](../SOURCES.md#source-body03) 不凭一次结果认定感染发生的时间或指责某个人，也不因为羞耻而躲开随访。

乳房出现新肿块、皮肤或乳头新变化，或其他持续症状时，告诉医生症状开始的时间与变化，不只展示上一张“正常”报告。年龄未达到某项公共筛查项目条件，并不妨碍因症状就医。每月反复摸查、频繁换机构做检查也不能替代有理由的评估；请医生明确观察和复诊安排。[\[BODY15\]](../SOURCES.md#source-body15)

进一步检查若涉及妇科内诊、阴道镜、取样等，先问做什么、可能有什么不适、何时可以要求暂停及做完注意什么，提出遮挡和隐私需求。有创伤经历或强烈恐惧时可以提前说明，不必讲超出医疗需要的细节。具体检查方式和是否可调整由医疗团队评估。

预算或交通使随访难以完成时，联系项目机构询问可接续的正规地点、是否需要转诊及资料转移。不要直接从日历删除。对医院给出的时间保留原样，无法按时完成就尽早沟通新的安排。

## 4.3 把疫苗接种做成一份能接续的记录

先找已有接种证、电子记录和曾接种机构，按疫苗名称、产品、剂次、日期整理。完全找不到的地方写“待核实”，带去正规预防接种门诊讨论，不凭年龄或模糊记忆认定自己一定打过，也不自行决定全部重打一遍。预防接种方案会受到年龄、健康情况、既往接种和国家程序影响。[\[BODY04\]](../SOURCES.md#source-body04)

<a id="body03-sub-01"></a>

### 预约时说出会影响评估的真实情况

告诉接种人员既往严重过敏、过去接种后的明显反应、正在用的药、慢病、妊娠或备孕情况，近期身体不适也应说明。把不知道的药名拍清楚带去。是否适宜当天接种、需要暂缓或采用不同安排，让接种门诊按当前产品说明和规范评估，不通过社交平台投票决定。

询问HPV疫苗时，不只问有没有某种价数。问当前可选产品及获批适用范围、自己是否适合、总共怎样安排、后续剂次怎样预约、全部费用和中途搬家如何接续。WHO公共卫生建议与中国每一种产品的获批说明不是同一份规则，不能把国外一张图上的剂次直接照搬。

| 比较项目 | 方案A | 方案B |
| --- | --- | --- |
| 本人适用与需确认事项 | \_\_\_\_ | \_\_\_\_ |
| 产品及接种程序 | \_\_\_\_ | \_\_\_\_ |
| 全程费用及服务费 | \_\_\_\_ | \_\_\_\_ |
| 后续预约、换城市与缺货处理 | \_\_\_\_ | \_\_\_\_ |
| 接种后咨询途径 | \_\_\_\_ | \_\_\_\_ |

这张表用于和门诊核对，不用于自己给疫苗排名。已经有过性接触、出现过HPV阳性或做过相关检查的人，也应拿真实记录咨询，不能单凭“有过性生活”就认定毫无意义，也不能把接种承诺成治愈感染。疫苗预防和异常结果随访分别安排，不能用其中一个替代另一个。[\[BODY02\]](../SOURCES.md#source-body02)[\[BODY03\]](../SOURCES.md#source-body03)

<a id="body03-sub-02"></a>

### 顺便核对其他疫苗需求，但不要一次购买所有项目

可以问：“结合我的记录、年龄、慢病、工作和出行计划，流感、乙肝等方面有什么需要补齐或更新的吗？”有旅行计划时说目的地和出发时间，有职业暴露就说明工作内容。这里列的是咨询方向，并非每位女性都需要相同清单；本书不规定品牌、剂次或个体禁忌。

收费先问整个安排而不是只看第一针价格。当地免费项目、补助和预约资格以接种门诊或政府现行通知为准，不能用外地截图推断自己免费。遇到加价代约、代购针剂或承诺“无需评估随时可打”的个人渠道，回到正规机构核实。正规渠道也应允许你先理解说明再决定。

接种当天按机构要求留观，保存名称、批号、接种日期和后续预约；身体不适的咨询和急症处置途径问清楚。后续剂次延迟、遗失记录、换城市或原产品暂缺时，联系接种机构讨论接续，不自行重启或随意混用程序。

最后在日历中分别保留接种任务与筛查任务。比如“某日咨询接种记录”“按医师确认时间筛查”，不要只剩“HPV已安排”一条笼统备注。预防管理的价值在于完成适合自己的事项，不在于把记录表填得越满越好。

<a id="body04"></a>

## 4.4 选择避孕方式，要能适应自己的身体和生活

是否发生性行为、采用哪些方式以及是否继续，都应出于自愿。单身者可能没有性关系，也可能有固定或非固定伴侣；婚恋标签不能替代实际接触史。没有相关需求时可以跳过本节；有可能导致妊娠的性行为时，提前讨论避孕比事后临时找办法更从容。

可以先对伴侣说：“我不接受没有保护的性行为；如果我说停，就要停。避孕不是由我一个人承担的事。”事先同意某一种行为，不等于同意其他行为，也不意味着之后不能改变主意。遇到对方拒绝保护、故意破坏约定或施压，可以结束当次接触，优先离开无法自主决定的情境。

<a id="body04-sub-01"></a>

### 去咨询时，带上你真正担心的问题

向妇科或正规相关门诊说明自己的健康史、药物、是否吸烟、月经情况、怀孕计划及过去使用经历。还要说实际执行条件：经常忘记每日任务、轮班、会出差、预算有限或不希望某类操作。某个方法在别人身上方便，不代表对你也适合；专业评估要结合健康状况和个人偏好。[\[BODY05\]](../SOURCES.md#source-body05)

| 方案比较时问 | 要获得的答案 |
| --- | --- |
| 怎样起效与使用 | 什么时候开始有保护，哪些情况需要额外措施 |
| 可能的变化与风险 | 常见不适、需要及时就医的变化，以及适用限制 |
| 忘记或失败后怎么办 | 针对该方法的补救程序和咨询途径 |
| 持续成本 | 药物或操作、复诊、取出或停用的实际费用 |
| 以后想怀孕或换方法 | 停用、取出和转换怎样衔接 |

不要靠一句“长期吃会不会不好”结束咨询。可以具体说：“我担心\_\_\_\_，请解释这对我有哪些实际风险、怎样监测、还有哪些替代。”得到方案后用自己的话复述开始、使用、遗漏处理与复诊安排。本书不提供具体激素药物或剂量，拿到新处方时请医生或药师核对其他正在用的药。

<a id="body04-sub-02"></a>

### 避孕与感染预防要分别问

不同避孕方法对妊娠预防的作用不同，并非都能预防性传播感染。安全套在正确使用时能够同时降低妊娠和包括HIV在内的性传播感染风险，但不能保证消除全部风险。[\[BODY05\]](../SOURCES.md#source-body05) 购买正规合格产品，检查包装与有效期，按说明使用；不把对方的外貌、职业或口头承诺当成感染状态证明。

采用其他避孕方式时，也要根据实际接触讨论感染防护与检测。就诊可如实说明接触类型，医生才能考虑适合的检查；不必用“干净不干净”评价自己或伴侣。一次阴性结果只反映相应检测条件与时间，是否需要后续检测应由专业人员结合暴露和检测方法安排。[\[BODY16\]](../SOURCES.md#source-body16)

方法不适合时，不必硬撑到下次例行复诊，也不要突然停用后假设仍有原来的保护。联系门诊讨论转换与过渡。担心隐私可以询问账单、短信通知、取药和病历访问的实际方式，按自己的设备与账户情况调整；不让伴侣掌握账户密码成为获得避孕支持的条件。

关于生育，你可以现在想要、现在不想要或还没有决定。需要咨询生育力或生殖服务时，把问题分成医学适合性、机构服务条件、费用与后续责任逐项确认。不能把广告中的技术可行性等同于中国大陆所有单身女性都能够使用相同服务，也不接受“现在不买就没有机会”的营销催促。

<a id="body05"></a>

## 4.5 保护失败或发生不愿意的接触后，先处理时间敏感的事

安全套破裂、未按要求使用避孕方式，或发生没有保护的接触后，先记下发生时间、接触情况、原来的避孕方式和已经采取的处理。这些信息用于医学评估，不是要求你解释为什么会发生。不要先等伴侣承认责任、先看身体有没有感觉，才寻求医疗帮助。

<a id="body05-sub-01"></a>

### 分别考虑妊娠风险和感染风险

有妊娠可能时，尽快向正规医疗机构或药师咨询紧急避孕。可用方法、时间窗口、适用情况和获得渠道不同，应尽早处理，不把某一种药的限制推广到所有方法，也不拖到所谓截止时间。紧急避孕不是终止已建立妊娠的药物方案，也不能替代之后的常规避孕或感染预防。[\[BODY06\]](../SOURCES.md#source-body06)

咨询时直接说：“接触发生在\_\_\_\_，原用方式是\_\_\_\_，现在距发生约\_\_\_\_小时，我用过\_\_\_\_。请确认现在可行的措施、后续怎样验孕或复诊、期间如何保护。”如有呕吐、再次暴露、月经变化或不确定是否正确使用，按药师或医生针对本次方案的指示处理，别自行叠加多种药。

可能发生HIV高风险暴露时，尽快联系具备相应服务的医院或当地疾控咨询评估。中国疾控资料提示，符合条件者应在医生指导下于暴露后72小时内尽早使用阻断药；这是需要争取的处理窗口，不是可以等待三天再行动。是否需要用药、如何用药和随访由专业人员决定。[\[BODY07\]](../SOURCES.md#source-body07) 即使已经超过窗口，也仍应咨询检测和后续安排。

| 现在需要确认 | 行动记录 |
| --- | --- |
| 时间与实际接触 | 发生时间\_\_\_\_；已采取处理\_\_\_\_ |
| 紧急避孕评估 | 联系机构\_\_\_\_；得到的安排\_\_\_\_ |
| 感染暴露评估 | 联系机构\_\_\_\_；需检测或复诊日期\_\_\_\_ |
| 现实安全与支持 | 现在安全地点\_\_\_\_；愿意联系的人\_\_\_\_ |

<a id="body05-sub-02"></a>

### 检测不是做一次就覆盖所有问题

向医生说明接触时间与类型，由其确定需要哪些检测、何时做以及是否复测。不同病原体和检测方法的窗口不同，一次刚发生后的阴性结果不一定结束评估。[\[BODY16\]](../SOURCES.md#source-body16) 自测结果异常应去正规医疗或疾控机构确认，不在群聊里让陌生人凭一张照片定论。[\[BODY07\]](../SOURCES.md#source-body07) 记录采样与复诊日期，比每天换一款试纸更有帮助。

发生非自愿接触时，先到安全地方，联系可信任的人或相关救助，受伤或存在危险时及时急救和报警。就诊可以说“我经历了非自愿的接触，需要伤情、妊娠和感染风险评估”，不必先把所有细节讲给多个无关的人。需要取证和法律支持时，由当地正规机构说明流程；医疗照顾不应被等待证据或决定是否举报拖延。

对方要求你保密、阻止看病或用费用迫使你继续关系，都不应成为延迟就医的理由。可以只给支持者一个具体任务：“请陪我去医院，暂时不要追问经过，也不要替我联系对方。”你可以决定向谁讲多少，医疗团队需要的事实则尽量真实说明。

处理之后把后续检测、验孕或门诊日期设置提醒，记录实际费用和仍未完成的事项。情绪反应有时会晚些出现；睡眠、工作或安全感持续受影响时，可以寻求心理或精神卫生专业支持。医学补救和情绪支持可以同时进行，不需要先证明自己受到的影响足够严重。

<a id="body06"></a>

## 4.6 月经变化、更年期不适，都可以带着具体记录就医

月经记录不必精确到每次更换用品的分钟。写开始与结束日期、与平时相比的出血变化、疼痛和对生活的影响、经间或性交后出血、正在使用的药，以及是否可能怀孕。使用纸本或自己愿意接受隐私条款的应用都可以；应用推算只是记录辅助，不能单独判断疾病或提供可靠避孕。

<a id="body06-sub-01"></a>

### 描述“影响了什么”，比只说痛更容易沟通

可以说：“过去我能照常上班，这次连续两天需要停下工作；夜间因疼痛醒来；出血比平时明显增加。”补充是否伴随头晕、乏力或其他变化，并带既往检查。没有记录也可以先就医，别为了凑够几个周期而忍着明显问题。周期或出血发生变化需要按情况评估，经间、性交后和绝经后出血应接受医生检查。[\[BODY08\]](../SOURCES.md#source-body08)

突然剧烈腹痛、晕厥、大量出血或明显身体不适，尤其存在妊娠可能时，及时急诊或呼救，不先当成普通痛经。[\[MED02\]](../SOURCES.md#source-med02) 怀孕可能与婚姻状态无关；该说明的信息如实告诉医护。症状较稳定但反复影响工作、睡眠或活动时，预约妇科评估，不以“女性都这样”打发自己。

| 门诊前写下来 | 填写示例或提示 |
| --- | --- |
| 原来的情况 | 以前周期和持续天数大致怎样 |
| 这次变化 | 从什么时候开始，与平时具体哪里不同 |
| 生活影响 | 请假、夜醒、不能活动、用品更换明显增多等 |
| 相关情况 | 药物、避孕、妊娠可能、旧报告 |
| 最想解决的问题 | 疼痛、出血、周期变化或对治疗的顾虑 |

买药或使用过去处方前，先让医生或药师确认当前是否合适，尤其有其他疾病、同时用药或可能怀孕时。保暖和休息可以帮助舒适，但不能代替对明显变化的评估。不要因为想赶旅行、考试或约会，就照着他人方案自行用激素调整月经。

<a id="body06-sub-02"></a>

### 更年期不是一张“所有不适都正常”的通行证

潮热、睡眠和情绪变化、泌尿生殖方面不适可能出现在围绝经期，但新症状仍需要结合个人情况评估，不能自行把一切都归为更年期。中国卫健委相关科普强调，更年期不适可以寻求专业帮助；是否采用激素等治疗需结合具体情况。[\[BODY09\]](../SOURCES.md#source-body09) 本书不建议自己购买激素，也不把一种治疗说成人人必要或人人危险。

就诊可准备：“这些变化从\_\_\_\_开始，最影响我的是\_\_\_\_；我希望了解非药物安排和医学治疗分别能解决什么、有什么风险、怎样复查。”把既往疾病、手术、家族史和正在用的药告知医生。治疗前问清目标：缓解某种症状、处理具体疾病还是其他需要，避免将“保养卵巢”“逆转衰老”的营销语言当成医疗目标。

同时询问骨骼、心血管等与个人年龄和风险相关的评估，不凭绝经二字给自己开全套影像或补充剂。工作中可尝试可调整的衣着、休息和环境安排，但这只是生活支持；严重不适或活动受限，应继续与医护讨论，不要求自己通过意志适应。绝经后再次出血尤其应就医，即使量很少。[\[BODY08\]](../SOURCES.md#source-body08)

复诊时带治疗前后变化，指出改善了什么、仍困扰什么和有哪些新不适。方案可以随评估调整；停止、换药或增加其他产品前先咨询。你要得到的是适合此时身体的安排，不是符合某个年龄段应当如何表现的想象。

<a id="body07"></a>

## 4.7 睡不好时，先看一周真实生活，再决定需要怎样的帮助

先区分“没有给睡眠留时间”和“有机会睡却睡不着、睡不好”。两者可能同时存在，但解决办法不同。睡眠需求有个体差异，不能只用手环分数或某个固定时长判断健康。中国睡眠健康核心信息强调，持续出现入睡或维持睡眠困难、白天嗜睡、睡眠呼吸异常等，应及时寻求专业帮助。[\[BODY10\]](../SOURCES.md#source-body10)

<a id="body07-sub-01"></a>

### 用一周记录找阻碍，不把睡觉变成另一份考核

早晨回想大致上床、入睡、醒来和起床时间，记夜间醒来情况、白天困倦、午睡、咖啡酒精及轮班。无需半夜反复看钟；记不准写大约。若记录使焦虑明显增加，简化成“昨晚主要困难、今天受影响的事”两行，并和专业人员讨论。

| 可能的阻碍 | 可以先做的小调整 |
| --- | --- |
| 工作挤占睡眠 | 明确结束工作的时间，减少临睡前必须完成的任务 |
| 房间噪声与光线 | 处理可改变的光源、遮光和声音；与室友协商安静时段 |
| 睡前仍持续兴奋 | 留一段不处理工作与争论的缓冲时间 |
| 周末与工作日起床差别很大 | 尝试较稳定、适合工作要求的起床安排 |
| 药物、疼痛或明显打鼾 | 整理记录就医，不自行停药或仅换枕头 |

先选一到两项最可改变的事情，持续观察它是否帮助白天状态。轮班工作者不必把自己硬塞进统一的“早睡早起”时刻表，可以向医生咨询如何结合班次安排休息。生活条件无法立刻改变时，也可以先处理最妨碍睡眠的一环，而不是为没有理想卧室自责。

<a id="body07-sub-02"></a>

### 不靠酒精或别人的药把自己放倒

规律起床、合适睡眠环境、白天活动和减少影响睡眠的刺激，可作为一般生活调整；睡眠问题持续影响生活时，应向医生求助。[\[BODY10\]](../SOURCES.md#source-body10)[\[BODY11\]](../SOURCES.md#source-body11) 不自行长期使用安眠药、叠加助眠产品或借用他人处方。正在服用相关药物的人，是否调整或停用应与开药医生讨论，不能因为看到风险提示突然停药。

白天困到难以保持清醒，先停止驾驶或需要高度警觉的危险活动，再安排评估。睡觉时响亮打鼾伴呼吸间歇、反复惊醒、异常行为或睡得很久仍明显疲惫，都值得如实告诉医生，不能仅解释成自己懒或压力大。[\[BODY10\]](../SOURCES.md#source-body10) 独居者没有人观察睡眠，不代表这些问题不存在；把自己能观察到的情况说清楚即可。

挂号时可以咨询全科、睡眠门诊或相应专科。带一周记录、用药清单和最影响生活的例子，问：“需要排查哪些原因？建议的治疗目的是什么？怎样判断是否有帮助，何时复诊？”如果等待门诊期间症状明显变化，及时重新评估就医时机，不必等记录完成。

某一晚睡差后，第二天先降低不必要负荷，把基本吃饭、工作安全和休息安排好，不必用一场超强运动或漫长补觉惩罚或补偿自己。下一步看持续趋势与日间功能；能完成一次合适的求助，比不断购买新的助眠工具更可能接近问题本身。

<a id="body08"></a>

## 4.8 身体活动从能持续的一小段开始，再补上力量练习

身体活动不只发生在健身房，步行通勤、家务和主动休闲也属于活动。WHO建议一般成年人争取每周至少150分钟中等强度活动，并强调减少久坐、任何活动都比完全不活动好，力量练习也有价值。[\[BODY12\]](../SOURCES.md#source-body12) 这个公共健康目标不要求久坐多年的人第一周一次补齐，更不是用来惩罚没有时间的人。

<a id="body08-sub-01"></a>

### 先找当前能做的起点

回看普通一周：哪天有相对稳定的十几分钟，哪里安全，什么活动不会增加通勤负担？既往有疾病、近期手术、妊娠相关情况、活动时不适或功能限制的人，先按医疗建议确定适合内容。不是每个人开始普通散步都要买检查套餐，但也不能忽略自己的医疗限制。

| 教学示例：刚开始增加活动的一周 | 实际安排 |
| --- | --- |
| 周一、周三、周五 | 各步行10分钟，按自己的能力和环境调整 |
| 周二或周四 | 找合适的入门指导，学习安全的力量动作 |
| 周末 | 一次20分钟舒适活动，或分成较短时段 |
| 每天 | 在能够安全做到时穿插起身和走动，减少连续久坐 |

这份例子步行部分合计50分钟，是开始尝试的安排，并未达到150分钟目标；如果当下体力适合，再逐渐增加。不要把较少活动说成已经满足全部建议，也不要因为没到目标就放弃。记录完成次数、体力反应和实际障碍，下一周只调整一项，例如增加一天或延长一次。

<a id="body08-sub-02"></a>

### 力量训练先学动作，再谈重量

选择能讲清动作与调整方法的合适指导者，说明旧伤、疼痛及医疗限制。先问这项练习训练什么、如何开始、怎样识别需要停止的表现，不跟着短视频盲目追求重量和速度。老人、行动受限或有慢病者可咨询康复或运动相关专业人员获得适配练习；不把站立和负重当成人人都能做到的前提。

出现胸痛、晕厥、明显呼吸困难等危险表现时，停止活动并按情况急救；新出现或加重的疼痛也不应当成“越疼越有效”。[\[MED02\]](../SOURCES.md#source-med02) 普通疲劳、恢复与训练安排怎样判断，可以在入门指导时问清，避免把一句“坚持就好”用于所有反应。

预算有限可先使用安全的步行空间和少量必要装备，真正持续后再决定是否购买课程。体验课问清实际强度、指导人数、退改规则和是否适合当前能力；不用为了留下优惠一次付很长的课程。比较价格时把交通和时间一起算，远处便宜但难以到达的课，未必适合你的生活。

<a id="body08-sub-03"></a>

### 活动计划要与吃饭和恢复相容

在《一个人也要吃好》中选择方便准备的正餐和蛋白质来源，避免忙于运动反而漏餐。运动不需要以外貌变化为唯一回报，可以记录上楼是否轻松、搬日用品是否更有把握、心情和活动耐受是否改善。是否需要营养补充或更专业的运动处方，按个人情况咨询。

加班、经期不适或病后恢复时，可以缩短、减轻或按医嘱暂停。错过一次不必隔天加倍完成；把计划改成能继续的版本，比一次性透支更有意义。一个月后回看哪些时段最容易兑现，再确定下个月增加什么，而不是每周重新开始一份完美计划。

<a id="body09"></a>

## 4.9 心理困扰影响生活时，给求助安排一个具体入口

情绪低落、焦虑、失眠、害怕出门或持续失去兴趣，可能与许多经历和身体情况有关。你不需要先在网上确诊，才有资格寻求支持；也不应因为某份量表得分就把它当成诊断。先写发生多久、什么情境加重，以及对吃饭、睡眠、工作、人际和自我照顾有什么影响，带这些事实去咨询。

<a id="body09-sub-01"></a>

### 先决定现在最需要哪一种支持

想有人听你讲、一起处理具体生活困难，可以联系可信任的人或正规心理支持服务；症状持续影响功能、伴明显身体变化或需要判断是否治疗，向正规医疗机构的精神科、心理或相关门诊咨询，挂号名称先向院方核实。中国《精神卫生法》对心理咨询与精神障碍诊断治疗有明确职责区分，不能只凭“老师”“疗愈师”的称呼推定医疗资质。[\[BODY13\]](../SOURCES.md#source-body13)

| 预约前问服务方 | 希望得到的明确回答 |
| --- | --- |
| 谁提供服务 | 专业身份、所在机构、擅长处理的问题 |
| 每次怎样进行 | 时长、形式、频率及线上服务适用边界 |
| 费用和结束方式 | 单次价格、取消规则、是否有长期预付要求 |
| 隐私如何处理 | 保存什么资料，保密范围与例外如何说明 |
| 超出能力怎么办 | 何时转诊，紧急情况应联系什么正式渠道 |

第一次可以这样开口：“最近\_\_\_\_周我经常\_\_\_\_，已经影响\_\_\_\_。我最希望先解决\_\_\_\_，也担心\_\_\_\_。请告诉我适合怎样评估和后续安排。”不想一次讲完的经历可以先说明，重点先放在当前安全、功能与最困扰的问题。咨询者应尊重你的节奏；医疗评估所必需的信息，则可讨论怎样逐步提供。

<a id="body09-sub-02"></a>

### 支持者能做的是具体任务，不是全天候负责你的情绪

可以给朋友发：“我最近状态不太好，已经约了门诊。周三能否陪我走到医院门口，或晚上通话十分钟？如果你没空，直接告诉我，我再找别的安排。”另一个可行请求是一起吃一顿饭、帮忙核对预约或在恢复期送日用品。先问对方是否愿意，再约时间，不把未回复自动理解为不在乎。

找不到合适亲友时，可查询所在地卫生健康部门公布的心理援助热线或公共心理服务，核实服务时间、接入方式和范围。国家有关部署要求心理援助服务具有相应人员和接听安排，但不能据此保证每个地区随时立即接通。[\[BODY14\]](../SOURCES.md#source-body14) 记录一个医疗预约入口和一个日常支持入口，服务忙线时有下一步可做。

若已经无法保证自身或他人安全、有正在发生的伤害行为或其他紧急危险，先到有人能帮助的安全环境，联系可信任的人到场，并立即拨120或前往合适急诊；不要独自等到预约日。向接线或医护明确说明现实危险和所在位置。日常心理咨询、聊天工具或朋友陪伴不能替代紧急医疗处置。

<a id="body09-sub-03"></a>

### 几次接触后，评估是否得到需要的帮助

回看是否更清楚问题、是否商定可行目标、是否能自由提问、对费用和边界是否知情。提出疑问时可说：“我们目前在处理什么？接下来怎样判断有帮助？如果没有改善会怎样调整？”不要求每次谈话都立即变好，但应有能够讨论的方向。出现越界、恐吓、羞辱、保证治愈或强迫大额预付，可以暂停并寻找合适服务；医疗用药的调整仍需与医生沟通。

吃饭、洗澡、缴账单和回复工作若已变得困难，把今天缩成一两件基本任务，必要时请人协助。恢复不是完成一套自律挑战，也不需要将心理困扰全部公开。把能持续的支持留下，其他事情可以分阶段处理。

<a id="body10"></a>

## 4.10 把健康安排收成一页，留住下一步而不是焦虑

读完本章不必立刻约齐所有门诊。拿一张纸，先列当前最影响生活或已经被要求处理的事情，再列可以按计划推进的预防任务。正在发生的危险优先及时就医；稳定的日常安排可以分散到能够承担的时间。排序依据是实际问题和专业建议，不是哪个视频让你最害怕。

| 事项 | 下一步与完成条件 | 日期／入口 |
| --- | --- | --- |
| 当前症状或旧异常 | 预约解释或评估，记录明确处置 | \_\_\_\_ |
| 筛查计划 | 根据年龄、风险及旧结果确认项目 | \_\_\_\_ |
| 接种记录 | 带记录咨询适合的补齐或接续 | \_\_\_\_ |
| 避孕与性健康 | 按实际需要咨询，写清失败后联系途径 | \_\_\_\_ |
| 睡眠与活动 | 选一项可做到的生活调整或专业求助 | \_\_\_\_ |
| 心理与生活支持 | 一个服务入口，一项可以提出的请求 | \_\_\_\_ |

虚构填写示例：“事项：上次检查建议复核但尚未安排。下一步：明天用医院官方入口询问合适科室，带完整旧报告；完成条件：已得到结果解释和下一次安排。”这比“今年要重视健康”更容易执行。另一个例子是“每周三下班先步行十分钟”，不是同时要求饮食、睡眠、力量训练和情绪全部改变。

<a id="body10-sub-01"></a>

### 每次复核，只更新改变的地方

如果新增诊断、换药、搬家、发生妊娠相关情况、出现新症状或医生调整随访，更新相应记录。没有变化的部分不用反复重做。将已经完成的项目写上结果与下一步日期后归档，把真正未完成的事项留在首页，避免一个巨大待办清单长期压着自己。

每月抽一小段时间看三件事：有没有漏掉医嘱要求的复诊或报告；近期哪些安排改善了生活；哪些做不到，需要缩小、换方法或求助。这个月没有能力付费做所有事情，就先问清专业上不能拖的事项，再讨论分步完成。未知费用标待核实，不能因担心很贵就自行认定一定承担不起。

<a id="body10-sub-02"></a>

### 健康信息也需要选择性保管

病历、月经和性生活记录可能包含敏感信息。只在可靠设备和必要账户中保存，检查是否同步到他人的家庭账户或共享相册。向朋友求助时可以分享任务所需内容；向医护提供诊疗相关事实；向单位提供办理手续所需资料。不同对象需要的信息不同，不必把同一份完整档案到处转发。

遇到宣称“所有女性都缺”“一张图判断是否患病”“买了就能彻底改善”的内容，先写下它究竟在主张什么，再查是否来自与你情况有关的可靠医学信息。如果已经让你想改变处方、推迟检查或花一大笔钱，先带问题咨询相应专业人员。转发量、评论里的成功故事和销售者自称的经历，都不能替代个体评估。

最后给自己留一个很小的行动空格：“我接下来会在\_\_\_\_之前，通过\_\_\_\_完成\_\_\_\_。”一次完成一个明确环节，也是在照顾身体。你可以喜欢运动，也可以暂时只做到准时复诊和吃上一顿饭；生活状态会变化，计划应当能够跟着调整。

本章没有提供个体诊断、药物剂量或适用于所有年龄的筛查处方。来源支持相应医学原则与制度事实，记录表、教学情境和话术是便于行动的编排；涉及你个人的决定，带着真实记录与专业人员一起确认。
