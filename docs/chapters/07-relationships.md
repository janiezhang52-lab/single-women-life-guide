# 07 关系与支持

[← 上一章：工作中的权益](06-work.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：未来有人照护 →](08-care.md)

<a id="introduction"></a>

单身不等于身边只能有自己，独处也不等于需要尽快被一段关系填满。你可以选择恋爱、不恋爱，与人同住，或保留独立住处；朋友、家人、邻居、同事和专业服务，都可能以不同方式参与生活。本章讨论怎样把关心、分歧、共同责任和求助说清楚，使关系不只依靠猜测维持。

沟通话术、支持名单和虚构情境是可调整的工具，不能保证他人配合。遭受威胁、控制或暴力时，责任在实施侵害的人；无需先证明自己已经表达得足够好，才有资格求助。以下同样适用于不同年龄、性取向和家庭经历的读者，涉及具体法律关系时则按相应规则处理。

## 7.1 面对催婚，先决定自己愿意说到哪里

有些追问只是笨拙的关心，有些已经变成持续施压。你不必先判断亲人到底爱不爱你，才能决定今天不谈这个话题。先把信息分三栏：愿意分享，例如最近周末安排；只向少数人说，例如正在接触的人；暂时不分享，例如性经历、存款和生育计划。边界可以随关系和处境改变，不需要向每个人开放同样的内容。

<a id="rel01-sub-01"></a>

### 先用一句话说决定，再提供你愿意谈的内容

如果没有结婚安排，可以说：“我目前没有结婚计划，有变化我会主动告诉你。最近我想先处理工作和住处。”如果愿意认识人，可以说：“你可以先发基本情况，我自己决定是否联系；请不要先把我的号码和照片发给别人。”若不愿接受介绍，就直接说：“这次不安排见面。”不需要为了让拒绝显得合理，编造一位不存在的伴侣。

假设周末家庭饭局里有人连续三次问“到底什么时候结婚”，第一次可以简短回答，第二次重复决定并转话题，第三次说明自己的行动：“这个话题我已经回答了，继续讨论我会先离席休息。”事先安排好离开时间和交通，能让这句话真的执行。离开是结束这轮谈话，不必宣布关系从此彻底断绝。

<a id="rel01-sub-02"></a>

### 对方说你不懂事时，不必把整个人生拿来辩护

可以回应：“我知道你着急，也听到了你的担心。但婚恋决定需要我自己作。我愿意聊你最近的身体情况，今天不继续讨论结婚。”既不承诺一个无法确定的日期，也不试图在十分钟内改变对方所有观念。法律保护妇女的婚姻自主权，禁止干涉结婚、离婚自由；家人的愿望不能替代本人意愿。[\[REL01\]](../SOURCES.md#source-rel01)

如果家人以“介绍都安排好了”施压，先联系实际组织者明确取消，避免让陌生人承担一场你未同意的约会。若你的照片或联系方式已经被转发，要求停止继续传播，并向接收方说明自己未同意该安排。必要时保存相关消息；不必为了顾全场面，完成一次自己不愿参加的相亲。

<a id="rel01-sub-03"></a>

### 仍依赖家里住房或收入时，先处理现实条件

不是每个人都能立刻挂断电话或搬家。先盘点重要证件、可用现金、收入、居住权和可暂住的地方，选不会让自己突然陷入困境的沟通方式。可以先减少细节披露，约定每次谈话时长，或请能尊重你决定的家人协助转达；不把一次激烈对抗当作勇敢的唯一证明。

对话转成扣留证件、限制出门、逼迫转账、威胁或伤害时，应按具体风险求助，跳到本章“分手后的跟踪与威胁”所列安全处理方法。亲属关系不能使侵害变得合理。对于仍能沟通的人，过几天可以恢复日常联系，但无需用取消边界交换和好；观察后续行为是否改变，再调整相处距离。

<a id="rel02"></a>

## 7.2 家里需要钱时，把关心与长期承诺分开

家人一句“你没结婚，开销小”，并不能说明你真的有多少余力。先回到收入篇的必要支出表，算出自己的住房、治疗、债务、孩子或其他照护费用，再看能提供什么。单身不意味着可以自动承担最多钱和最多时间；同时，家庭边界安排也不能替代法律上的抚养、赡养等义务判断。[\[REL02\]](../SOURCES.md#source-rel02)

<a id="rel02-sub-01"></a>

### 先问清这是哪一种请求

把“家里缺钱”拆成具体用途：日常生活、突然住院、亲属经营周转、购房，还是偿还旧债。问总金额、什么时候必须支付、谁已经承担、有没有账单和可用保障。不是为了审问亲人，而是决定能否提供一次帮助、持续支持、直接支付某项费用，或只协助办理事情。紧急医疗应先保障必要救治，核对账目可以与其他人分工完成。

| 教学假设 | 怎样落实 |
| --- | --- |
| 每月可持续帮助 800 元 | 约定用途和转账日，三个月后按情况复看 |
| 本次另愿提供 1500 元 | 写清为一次性支持，不自动变成每月额度 |
| 有人提出借 10000 元 | 先看可承受损失和还款安排，不能借则直接说明 |
| 需要长期每天陪护 | 列每周任务与可投入时间，另找其他亲属或服务分担 |

以上金额只是演示。可以说：“我现在每月能稳定承担 800 元，这次另有 1500 元可以支持。超过这个范围，需要大家重新商量，我不能承诺全部补上。”如果是借款，借与赠与要说清；有必要时写下金额、付款、归还和双方确认。将来是否能追回仍看事实和法律，亲属间一张表并不能自动解决所有争议。

<a id="rel02-sub-02"></a>

### 把没有薪酬的照护工作也摆上桌面

陪就医、找护工、买药、记账和夜间接电话都需要时间。开家庭讨论时，先列一周里真实发生的任务，再让能参与的人认领：谁联系医院，谁负责交通，谁每周到场，谁承担付费服务。人在外地的人仍可处理预约和账单，住得近也不意味着必须全天值守。每项有负责人和替补，才不会最后又落到一个人身上。

对方不接受额度时，可以继续提供事实：“我的必要支出是\_\_\_\_，可持续余量是\_\_\_\_，再多会影响住房和治疗。我们需要减少某项成本，或找其他承担方式。”不愿公开完整收入时，直接说明能力边界即可。亲属经营、投资或替别人还贷的要求，不能和紧急生活救助混在一起；担保与借名贷款的风险见收入篇。

<a id="rel02-sub-03"></a>

### 你接受家人帮助时，也把附带条件谈清楚

临时住家里或获得一笔资助，可以确认期限、是否归还、家务和私人空间怎么安排。若帮助被临时附加“必须相亲”“必须交出工资”等条件，先评估自己有哪些替代安排，再讨论或退出，不用为证明独立让自己失去基本住处。财务支持不应成为持续羞辱和控制的理由。

每次达成安排后发一条简短记录：“我们确认本月由我支付\_\_\_\_，其他\_\_\_\_由\_\_\_\_负责，下次在\_\_\_\_核对。”发生长期分担争议、父母或孩子基本权益受到影响时，带具体情况咨询公共法律服务或专业人员；不要仅用本书的预算示例认定自己已经履行了全部法定义务。

<a id="rel03"></a>

## 7.3 开始约会时，让同意和离开的选择都清楚

约会不需要像审查候选人，也不必以投入越快证明认真。先确定你这次想要什么：聊一小时、吃饭、散步，或了解是否愿意继续接触。对方怎样回应小小的不同意见，往往比一连串承诺更能帮助你了解相处方式；但没有任何观察表能保证识别所有风险，也不能据此责怪受害者没有看准人。

<a id="rel03-sub-01"></a>

### 把第一次见面做成容易结束的一段时间

选自己容易到达和离开的地点，确认交通、营业时间和消费范围。可以说：“周六下午三点喝杯咖啡，我五点有自己的安排。”按意愿告诉可信任的人大致地点和预计结束时间；是否分享位置由你决定。对方临时改成偏僻地点、要求上车去别处或不断延长，可以拒绝、改期或离开，不必完成原计划才算礼貌。

消费提前说一句就能减少很多猜测：“这家人均预算我不太合适，换一家吧。”“这次我们各付自己的。”对方请客不产生身体接触、继续约会或替他办事的义务。自己的支出超预算，可以选择更简单的见面；不需要用消费能力证明配得上关系。

<a id="rel03-sub-02"></a>

### 身体接触与私密信息，逐件确认

愿意见面、接吻或曾经发生过性行为，不表示对之后所有行为都同意。同意应当出于自愿，并且可以随时改变；面对犹豫、沉默、明显醉酒或无法清楚表达时，应停止推进并确认。可以直接说：“我想停下来。”“今天不去你家。”“这件事我不愿意。”对方也有同样表达和改变决定的权利。

安全套、避孕、性传播感染检测和是否拍摄，应在能平静讨论时分别谈，不能把不提问当成已经解决。具体健康选择见“身体由自己照顾”。你无须提供账户密码或私密照片来证明信任；已经分享过，也不意味着对方可任意再传播。妇女权益保障法保护人格、隐私等权益，并禁止违背妇女意愿实施性骚扰。[\[REL01\]](../SOURCES.md#source-rel01)

<a id="rel03-sub-03"></a>

### 不舒服之后，按事实决定下一次是否见面

可以写下具体行为：“我说想回家后，对方仍扣着我的包不让我走”，这比只问“是不是我太敏感”更有助于决定下一步。普通节奏不一致可以沟通：“我一周最多见一次，请别临时到公司找我。”若对方接受并持续做到，可以再观察；若继续施压、羞辱、控制或威胁，就不把它仅当作沟通风格不同。

结束约会可以很短：“我觉得不合适，不再继续见面。请尊重这个决定。”不愿当面说或担心安全时，可以在离开后通过信息表达；没有义务单独见最后一面。若已发生伤害，先就医、离开危险和求助，保留你愿意且安全可保留的材料。是否穿什么、喝过酒、是否曾同意其他接触，都不应成为把侵害责任转给你的理由。

<a id="rel04"></a>

## 7.4 亲密不等于所有账号都要彼此开放

数字权限常常在不知不觉中留下：对方曾帮你修手机，自己的邮箱仍登录在他的电脑，共享相册里有住址，购物账户保存了家人的电话。先做一份“谁能看到什么”的清单，而不是只改一个社交软件密码。日常维护可以两个人各自完成，既尊重彼此隐私，也减少关系变化时的混乱。

| 先检查哪里 | 要核对什么 |
| --- | --- |
| 主要邮箱和手机号码 | 找回账号的方式是否由自己控制 |
| 设备登录与云服务 | 哪些电脑、平板仍有会话；同步了哪些照片文件 |
| 位置与家庭共享 | 谁能看实时位置、相册、日历和设备状态 |
| 支付与购物 | 免密支付、共享支付方式、默认地址和订单可见范围 |
| 门锁及家居设备 | 管理员、访客码、摄像设备及旧权限 |

<a id="rel04-sub-01"></a>

### 正常情况下，先建立自己可恢复的账户

不同重要账户使用不同密码，优先保护邮箱和支付账户。支持时开启多因素认证，也就是密码之外再用设备、验证器等方式确认身份；它能增加保护，但仍要注意钓鱼和授权误操作。[\[REL03\]](../SOURCES.md#source-rel03) 恢复号码、邮箱和备份码由自己保管，不能开启验证后却把唯一恢复手段放在别人的设备里。具体设置以服务商当前说明为准。

在可信设备上查看已登录会话，退出自己不认识或不再需要的设备。更改密码后继续检查找回方式和第三方授权，因为有的共享权限不会随密码自动消失。不要清空他人的设备或越权查看对方私信；可以要求对方退出你的账户，自己的账号则通过官方安全功能处理。

<a id="rel04-sub-02"></a>

### 照片、行程与关系公开也要先商量

例如：“这张合照可以发朋友圈，但不要带我家地址；工作单位和孩子的照片先不公开。”“我们的关系暂时只告诉亲近朋友，请不要替我向同事宣布。”每种信息分别约定，不因为同意发一次合照就理解为以后都可随意发布。你也应同样尊重对方的决定，尤其是对方尚未公开的性取向、健康与家庭情况。

如果已经有私密图片或个人信息被传播，先保存原链接、账号、时间和上下文，在不扩大传播的前提下备份必要证据，再使用平台投诉和正式求助渠道。不要为让朋友帮忙判断，把全部原图转进大群。向支持者说清你需要的是记录链接、陪同报案还是协助下架。

<a id="rel04-sub-03"></a>

### 怀疑被监控时，安全计划先于一次性大清理

若对方可能通过设备、定位或账户跟踪你，改密码、关闭共享甚至卸载软件都可能触发通知或引起对方反应。优先使用对方接触不到的可信设备联系支持者、平台客服或专业机构，结合现实安全决定操作顺序；先确保有能到达的安全地点和联系方法。不要为了证明监控存在，冒险拿对方设备或单独对质。

一般的账号安全检查不是对监控是否存在的诊断。出现不明登录、密码被改、定位权限异常等，记录具体提示与时间，请官方支持帮助核查；账户之外的人身威胁同时按安全求助处理。清理完成后保存新的恢复方式，检查一次能否正常登录，不把重要备份只放在刚刚被怀疑不安全的设备上。

<a id="rel05"></a>

## 7.5 准备同居时，把共同支出、家务和退出谈到能执行

同居可能带来陪伴，也会增加彼此对住处、作息和钱的依赖。准备搬进去之前，先核对谁有合法居住与出租权限、谁在合同上、押金由谁交、谁对房东承担付款责任；租约部分参照“住得安心”。两个人私下写了“各付一半”，不自动改变与出租人的合同关系。共同购买房屋、按揭或重大财产安排，应另做专业审核。

<a id="rel05-sub-01"></a>

### 公共费用可以选择不同分法，但要双方都看得懂

| 教学假设：公共支出每月 4000 元 | 甲承担 | 乙承担 |
| --- | --- | --- |
| 双方同意各半 | 2000 元 | 2000 元 |
| 按双方确认的可支配收入 6000∶9000 分摊 | 1600 元 | 2400 元 |

两种算法都只是协商选项，没有哪种自动更公平。先定义公共支出是否包括房租、食材、水电与共同活动；个人爱好、个人债务、送礼是否另算。按收入比例分摊的，还要商量是否定期更新和信息披露到什么程度。若一方多承担照护与家务，也应一起讨论，不能只比较转账金额。

选择一个结算日，各自保存原始账单，公共账只记录共同项目。假设本月共同支出 4000 元，甲先付 2800 元、乙先付 1200 元，按各半安排，乙需向甲补 800 元。付款备注“某月共同费用结算”并保留双方确认。临时买贵重物品前，先说清归属、出资及退出时如何处理，不在分手时才第一次讨论。

<a id="rel05-sub-02"></a>

### 家务写到能看见的结果

“你负责厨房”太宽泛，可以改成“晚饭后洗净餐具、擦灶台并倒厨余；采购由另一人按共同清单处理”。包括规划、预约维修、记账和提醒这些不显眼的工作。先试行两周再调整，如果一方不会做，可以约一次学习和说明，但不把永久监督、提醒的任务也默认交给另一人。

访客过夜、安静时段、工作空间、宠物、吸烟和独处安排，按真实需要谈。可以说：“我周三需要独自休息，不安排朋友来家里。”“进入我的工作文件夹或使用我的物品，请先问。”对方临时带人回来时，先处理当天可接受的安排，之后再核对长期规则；不以冷战来让对方猜。

<a id="rel05-sub-03"></a>

### 退出安排在相处顺利时也能讨论

写下有人决定搬走时的通知、租约处理、押金、账单、家具和钥匙交接。保留各自可用的钱、证件和账号，不把全部资金混在一个只能由对方控制的账户里。有孩子或照护对象时，另列实际责任；亲密关系变化不自动解决抚养、居住或监护问题。

书面生活约定可以减少误会，但不是所有条款都有同样法律效力，也不能直接套用夫妻共同财产规则。发生大额财产或债务争议时，带原合同、出资与沟通记录咨询。若对方用断钱、换锁、扣证件或威胁阻止你离开，优先启动安全与求助安排，不再把唯一目标设为谈成一份公平的家务表。

<a id="rel06"></a>

## 7.6 普通分手时，让情绪和交接各有一条线

这一节适用于没有现实威胁、双方能够进行基本沟通的分手。若有暴力、跟踪、扣留物品限制离开或威胁传播隐私，直接按下一节处理。分手可以难过，也可以明确；不必等双方对所有原因达成一致，才有资格结束一段不想继续的关系。

<a id="rel06-sub-01"></a>

### 决定本身与待处理事项分开表达

可以说：“我决定结束恋爱关系，不再讨论复合。还有租房和物品需要交接，我们通过这个渠道，只处理这些事情。”若希望暂时停止联系，明确从何时开始、哪些必要事务可通过什么方式处理。不用把每一次回消息都变成重新解释决定，也不以故意刺激、泄露对方隐私或制造嫉妒作为退出方法。

如果决定尚未确定，可以先表达需要独处和思考的时间，但不要假装已经决定分手来迫使对方改变。对方要求更多解释时，你可以给愿意提供的部分，并说明谈话何时结束。哭泣、失望或愤怒不自动表示危险；威胁、限制行动和持续侵扰则要作为具体行为处理，不能只看对方说自己多爱你。

<a id="rel06-sub-02"></a>

### 把需要交接的东西列成几行

| 事项 | 能实际结束的安排 |
| --- | --- |
| 私人物品 | 列清单，约地点、时间和接收人，必要时用可追踪寄送 |
| 租房与押金 | 按合同通知和交接；向出租人确认变更，保留结算 |
| 共同购置物品 | 核对出资与约定，协商实物归谁、补款多少 |
| 共同服务 | 订单、订阅、宠物照料等分别取消、变更或另约 |
| 数字权限 | 检查共享账户、位置、相册及恢复方式 |

例如共同买了某件家具，先确认是否原本约定共有、由谁付款、是否还有贷款，再讨论一方保留、出售分配或其他方案。没有一致意见就把争议部分单列，不为赶快结束而签一句范围不清的“再无任何财务往来”。日常礼物、借款、共同投资或涉婚财物的法律性质可能不同，不能用所有转账一律退还或一律不退概括。

<a id="rel06-sub-03"></a>

### 对方迟迟不取物品，先记录通知和可行方案

发清单及合理可行的交接选项，保留回复；不擅自销毁、出售或扣着证件逼对方付钱。金额大、归属有争议或取物可能引发冲突时，先咨询物业、社区或法律专业人员可采取的安排。需要朋友陪同，应征得朋友同意，讲清是协助记录与搬运，而不是参与对抗。

有孩子时，另列接送、费用、沟通渠道和现有协议或裁判文书，避免让孩子负责传话、选边或收集证据。非婚生子女依法享有与婚生子女同等的权利；结束恋爱或离婚也不能简单消除相应抚养责任。[\[REL02\]](../SOURCES.md#source-rel02) 孩子的具体安排应结合安全、利益和适用法律确定，必要时寻求专业帮助。

<a id="rel06-sub-04"></a>

### 交接完成后，给生活一个新的小节奏

把需要补上的现实支持先安排好：原来谁帮忙接送、谁提醒账单、谁照顾宠物，这些空位可以分给不同的人或服务。想念对方时，可以写下未发送的信息、联系朋友或离开刺激性内容；不必为了证明自己已经走出来，马上开始下一段关系。

如果情绪持续影响睡眠、吃饭、工作或照护能力，可考虑专业支持，参照身体照顾篇的求助方法。分手后的生活不必立刻变得精彩，先有正常的一餐、能休息的住处和一位可以联系的人，就足够作为这一周的安排。

<a id="rel07"></a>

## 7.7 分手后的跟踪与威胁，要把安全和正式求助接起来

反复到住所或单位堵人、尾随、用不同号码持续联系、威胁伤害你或他人、强迫见面、以传播私密内容逼迫复合，都是值得认真处理的行为。判断依据是发生了什么以及现实危险，不是对方是否把行为解释为爱。你不需要先等到出现明显伤口，也没有义务单独赴约把话再说清楚。

<a id="rel07-sub-01"></a>

### 危险正在发生时，先离开对方能控制的范围

在能够安全做到时去有工作人员或其他人可以协助的地方，拨打 110；受伤或需要急救时联系 120。报告准确位置、对方正在做什么、是否持有危险物品、现场是否有孩子等关键信息。不要为录像返回危险现场，也不要把计划发送到对方可读的共享账户。暂时无法离开时，向可协助的人和警方提供可执行的位置与情况，按现场指引处理。

证件、常用药、通讯工具和必要现金可在安全条件下准备，但物品不能成为必须冒险返回的理由。需要暂住，先确认接待者愿意且地点是否会暴露；可联系当地妇联、社区或相关救助机构询问现实可用的支持。机构开放时间、入住条件与容量要实际核实，不把一个网上名字当成一定有床位。

<a id="rel07-sub-02"></a>

### 把经历写成事实时间线，保留已有材料

| 记录字段 | 虚构填写示例 |
| --- | --- |
| 时间与地点 | 某月 12 日 18:20，单位大门外 |
| 观察到的行为 | 对方挡住去路并连续要求上车；我拒绝后仍尾随 |
| 可找到的材料 | 原始消息、出入口记录线索、同事姓名、报警回执 |
| 影响与当前担忧 | 无法正常下班，担心其继续到住所；需安全离开 |
| 已采取动作 | 报警并请单位安保协助，保存后续联系记录 |

截图尽量包含账号、时间和上下文，原始消息和文件另存；备份到对方无法访问的位置。伤情照片、就医记录、出警与求助记录有助于呈现经过，缺少其中一项不意味着不能先求助。最高法关于人身安全保护令的规定列有当事人陈述、报警和医疗记录、通讯信息等多类证据。[\[REL04\]](../SOURCES.md#source-rel04) 不用冒险诱导对方再实施一次侵害来补证。

<a id="rel07-sub-03"></a>

### 把保护需要讲给能作决定的机构

妇女权益保障法第二十九条禁止以恋爱、交友为由或在恋爱终止、离婚后纠缠、骚扰妇女及泄露、传播其隐私和个人信息；遭受上述侵害或面临现实危险的，可向人民法院申请人身安全保护令。[\[REL01\]](../SOURCES.md#source-rel01) 最高法公布的案例也展示了终止恋爱后的跟踪骚扰适用保护令的情形。[\[REL05\]](../SOURCES.md#source-rel05) 是否签发及具体措施由法院依法判断。

可以向法院诉讼服务或法律服务人员说明：“我们是什么关系，对方在这些时间做了这些事，我目前担心什么，希望禁止哪些具体行为。”询问受理法院、申请方式、材料和紧急处理，保留提交回执。已经拿到保护令的，把文书保存好，并问清如何报告违反行为；不要由自己承担对方是否遵守的全部监督和执行工作。

给单位、物业或可信任的人发必要信息时，说明具体请求，例如按流程核验访客、不向外提供班表与地址、下班时协助联系警方。不要只说“帮我注意一下”。怀疑数字监控时，参照上一节从可信设备求助，结合安全安排调整权限。朋友可以陪同和协助，但无法替代警方、法院与专业机构的职责。

<a id="rel08"></a>

## 7.8 支持网络按任务建立，不要求一个人包办全部

“有事找我”很温暖，却还不够明确到手术当天能顺利接你回家。先想实际任务，再找愿意承担的人：谁能接一通电话，谁住得近，谁能短时间陪就医，谁熟悉孩子或宠物，哪些事情需要付费服务。朋友、邻居、亲属和同事可以各做一小部分，不必先找到一个像家人一样亲密的人才开始。

<a id="rel08-sub-01"></a>

### 发出请求时，给对方判断所需的信息

例如：“我下周三有一项检查，医院说需要有人接我回家。预计下午四点结束，在\_\_\_\_医院，可能要等一小时。你是否方便？交通费用我承担，不方便也请直接说，我会安排备选。”先核对医院对陪同者的实际要求，不能把任意接送都当成符合离院条件。时间不确定时说明范围，之后及时更新。

| 任务 | 已确认的人或服务 | 需要提前说清 |
| --- | --- | --- |
| 临时电话联系 | 朋友甲 | 可联系时段；无法接听时的替补 |
| 附近实际协助 | 邻居乙 | 只做约定的小事，不默认有进门权限 |
| 检查后接送 | 朋友丙或服务 | 医院要求、地点、时长、费用和取消 |
| 孩子或宠物临时照护 | 已确认的可信人员 | 接送授权、照料说明、备用安排 |
| 法律或长期照护问题 | 相应专业机构 | 服务范围、资质、收费与预约 |

填写真实姓名或服务之后，还要有“已征得同意”的日期。通讯录里存着名字并不代表对方已承诺值守。支持者可以拒绝或因自身情况变化退出；你可以提出新的请求，但不把过去帮过一次解释为永久义务。

<a id="rel08-sub-02"></a>

### 约定失联处理，要有触发条件和行动顺序

普通独居日常可以不设置打卡；若某次出行或恢复期确实需要联系，写清预计结束时间、先打哪个电话、多久后联系备选人，以及出现什么明确危险信息时报警。例如“我预计晚九点到家，若晚一小时仍联系不上，先打电话并联系\_\_\_\_；若收到求救信息直接联系警方”。这是双方自定的示例，不是普遍适用的危险判定时间。

让联系人知道准确地址、必要的门禁联系办法和你愿意共享的信息即可。无需发所有账号密码，不能鼓励对方因普通晚回复就擅自破门。紧急联系人、代办人、医疗决定相关身份及监护人并非同一概念，具体授权见“生病时有安排”和“未来有人照护”。

<a id="rel08-sub-03"></a>

### 把临时帮忙变成双方都可持续的安排

朋友陪完就医后，及时说明已安全到家，结清约定交通等费用。可以询问“这次有没有哪部分给你造成负担，下次怎么调整”，不必马上用同等价格还礼。你能回馈的可能是帮忙取材料、照看植物或一次有质量的倾听；互助可以长期有来有往，不需要逐分钟清算。

当需求变成连续多日照护、频繁接送或复杂心理支持，就重新讨论时长与专业服务补位，不把好友慢慢变成无偿长期护工。没有合适人选的空格可以写“待建立”，先寻找一项可预约的替代服务。搬家、换号码、关系变化或实际用过一次后，再更新名单，通常比把表填得很满更重要。

<a id="rel09"></a>

## 7.9 朋友之间有分歧时，把不舒服说成一件具体的事

朋友迟到一次、忘回消息或对同一件事看法不同，不一定说明关系需要结束。先把你观察到的事实、自己的感受和希望对方改变的事情分开。例如“上两次见面都比约定晚了四十分钟，我等得很累，希望以后来不了提前告诉我”，比“你从来不在乎我”更容易让对方知道具体怎么做。

<a id="rel09-sub-01"></a>

### 一次谈一件最影响你的事

选双方能够说几分钟的时段，先问是否方便。不要在多人群里突然公开审判，也不要把积累几年的委屈一次塞进十几个例子。可以说：“我想聊上次未经我同意把我的事告诉别人，这让我很不舒服。以后关于我的健康情况，请先问我。”接着给对方解释或承认的空间，但不把解释自动当作问题已经解决。

若对方回应“我只是开玩笑”，可以继续把标准说清：“我知道你可能不是想伤害我，但这个内容我不希望被当作笑话，也不希望继续传播。”你需要的可能是删除一条公开内容、停止某类话题或下次先征求同意。提出可执行的要求后，观察实际行为；不必强迫对方用完全一样的措辞承认你的感受。

<a id="rel09-sub-02"></a>

### 钱和帮忙的冲突，尽早在小额阶段处理

假设三人聚餐合计 360 元，事先约定平摊，每人应付 120 元；你先垫付后，可发原账单和一句“这次每人 120 元，方便本周内转我”。若有单点、酒水或一人提前离开等情况，按此前约定核对，没约定就协商，不能事后突然强迫某一种算法。一次忘记可以提醒，反复拖延则减少垫付或改为当场各付。

朋友请你免费做专业工作，也可以说：“我可以用十分钟帮你判断方向，完整制作需要按正常项目安排。”对方处境困难时，你可以自愿提供明确的一次帮助，例如改一页简历，但要讲清范围和结束点。帮忙并不意味着你永远不能觉得累，拒绝新请求也不抹去过去的友谊。

<a id="rel09-sub-03"></a>

### 对方不改，调整关系的使用范围

有些人适合一起运动，不适合谈隐私；有些人适合偶尔见面，无法承担临时求助。可以减少敏感信息、停止借钱、缩短见面时长，把关系保持在实际舒服的位置。若发生持续羞辱、威胁或利用，不必先完成一次完美沟通才能拉开距离。调整相处距离是你能控制的行动，改变对方的人格不是你的任务。

自己造成伤害时，道歉也要落到动作：“我未经你同意说了那件事，是我的问题。我会停止转述，并联系已经听到的人更正。”不要求对方立即原谅，不把自己很难受作为对方安慰你的任务。涉及照片或文件，按实际授权处理，别用一句“都删了”代替能核对的行动。

如果双方都想修复，可以约定下次遇到同类情况如何提醒，并过一段时间回看。关系里仍能享受的部分也可以继续存在；不需要把所有朋友都评为完美或有毒。把重要支持分散在几个真实可用的关系里，也能减少一次失望带来的全盘无助。

<a id="rel10"></a>

## 7.10 不习惯求助或刚到新城市，从一件小事开始

“我不想麻烦别人”有时来自体贴，有时是以前请求被拒绝后的自我保护。你不必先变得非常外向，才有资格建立支持。先选一件范围明确、对方容易回答的小请求：确认一个办理地点、陪你打一通需要勇气的电话、一起去附近公园走半小时。第一次不用讲完人生经历，也不用从借钱或连续照护这样负担重的请求开始。

<a id="rel10-sub-01"></a>

### 让拒绝有空间，自己也准备第二条路

可用这个结构：“我遇到\_\_\_\_，现在想请你帮我\_\_\_\_，大概需要\_\_\_\_，在\_\_\_\_之前。你不方便也可以说，我会另作安排。”例如“我明晚需要向房东确认扣款，能不能先帮我看十分钟消息是否说清楚？不需要你替我交涉。”对方拒绝时，先接受这个具体结果；有空再问是否愿意推荐公开渠道，不反复证明自己值得被帮助。

如果身边暂时没人，就把事情交给对应的入口：房屋问题找正规管理或法律渠道，医疗问题找医院窗口，社区服务找实际所在社区。先询问服务范围、预约和费用，记录真实联系人。遇到一句“这不归我们管”，可以继续问“那应该由哪个部门办理，您能否告诉我业务名称或公开联系方式”，把转介信息写下来。

<a id="rel10-sub-02"></a>

### 建立新关系时，选择能重复见面的小场合

从自己真的有兴趣、时间能承受的活动开始，例如社区阅读、固定散步、课程或志愿服务。先核对组织者、地点、费用和退出安排，去一次就够决定是否再去。熟悉可以通过多次一起做小事形成；不必第一次就交出住址、收入和全部孤独感，也不以报名高价课程作为获得朋友的必要成本。

有了初步熟悉的人，可以发具体邀请：“下周六下午想一起去图书馆坐一小时吗？不方便就改天。”两三次没约上，可以暂时放下，继续保留其他连接。朋友的忙碌不自动等于拒绝你这个人；同时，也不用在明显单向付出的关系里不断加码。

<a id="rel10-sub-03"></a>

### 把本章收成一张真正能更新的支持卡

| 要填的字段 | 填写方式 |
| --- | --- |
| 当前最想解决的一件事 | 写动作，例如检查后有人接，不写“有人爱我” |
| 第一联系人及已同意范围 | 姓名／联系方式；日期、时段与任务 |
| 备用联系人或服务 | 是否已核实；费用、预约要求 |
| 需要提供的信息 | 地点、预计时长、必要照料说明，避免多余隐私 |
| 对方无法帮忙时 | 延后非急事，换渠道；危险事件直接求助相应紧急服务 |
| 完成后的收尾 | 告知结果、结清费用、取消多余预约与共享权限 |

填写后先实际核实一项，例如问朋友是否愿意做这次联系人，或打电话确认某项服务是否存在。未经确认的格子标“待核实”，不要在真正需要时才发现只有一个网页链接。支持卡可放在自己容易找到的地方，必要时给已同意的人一个只含相关信息的版本。

支持网络不能替代专业照护和心理治疗。若痛苦持续影响基本生活，参考身体照顾篇寻求评估；朋友可以陪你预约、在候诊时等候，但无需承担全部治疗责任。你也不必等生活彻底失控才提出请求。一次有明确范围的小帮助，已经是在让生活多出一种可行的办法。
