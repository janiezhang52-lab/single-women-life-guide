# 03 生病时有安排

[← 上一章：收入撑得住生活](02-money.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：身体由自己照顾 →](04-health.md)

<a id="introduction"></a>

一个人生病时，困难往往不只来自症状：手机里找不到病历，不知道是否需要空腹，检查做完没人解释，出了医院才想起家里没有饭。提前把这些环节接起来，可以少一些临时决定，也更容易向别人提出明确的帮助请求。

本章面向中国大陆成年读者，重点是就医准备和生活安排。单身不等于独居，也不等于没有孩子或亲友。你可以根据自己的照护关系改写例子。医疗判断由医护人员结合实际情况作出；出现紧急危险时，先求救，记录、钱款与证件随后处理。

## 3.1 平时整理一份医疗资料，临时不必从聊天记录里翻找

选一个今天能够完成的小任务：把正在用的药、已知过敏和最近重要报告放到同一处。纸质文件袋或手机文件夹都可以，不必为了准备而购买健康管理软件。先覆盖真正会影响就医的信息，随后再补历史资料。资料太多时，一页索引比几十张没有日期的截图更有用。

<a id="med01-sub-01"></a>

### 首页只放当次就医需要迅速看到的信息

写姓名、出生年月、联系电话、现住地址、主要既往疾病和手术、已知药物过敏、当前用药。过敏写清“曾用什么、出现什么反应、何时发生”；记不清就标注待核实，不把一次胃不舒服直接写成已经确认的药物过敏。用药包括处方药、自己买的药、中药和保健品；拍包装正面及成分名称，标注最近一次实际服用时间。

| 资料 | 怎样存才容易用 |
| --- | --- |
| 首页摘要 | 每次新诊断、换药或搬家后更新；写最近更新日期 |
| 检查与影像 | 日期＋医院＋项目；报告、影像入口与下载期限分别记录 |
| 处方与出院记录 | 保留完整版本，旧版注明已调整，不与当前方案混放 |
| 费用与凭证 | 费用清单、票据、结算信息另放，避免看病时被账单淹没 |

示例文件名可以是“2026-10-17\_某医院\_腹部超声\_报告”，这只是命名演示，不代表做过这项检查。不要只截取报告的红色箭头；姓名、日期、单位、参考范围和结论都可能影响解释。前后结果来自不同机构时，原件一起保留，请医生判断可否直接比较。

<a id="med01-sub-02"></a>

### 联系人先问过，再写进去

可以对朋友说：“我想把你留作生病时的联系人，主要请你帮我通知另一位朋友或送资料。你通常哪个时段接得到电话？联系不上时我先找谁？”对方同意后，存两条联系路径，并说明谁负责什么。填写紧急联系人不等于授予其医疗决定权；涉及代办、代领或医疗沟通，需要另外向医院确认。

给联系人一份最小必要的信息，例如住址、本人电话、常去医院和资料存放位置。完整病历、身份证照片、账户密码无需发进亲友群；手机解锁方式也不必与求助卡绑在一起。临时找人帮忙时，再提供完成任务所需材料。医疗机构依法负有病历保管与隐私保护义务，患者也可依法请求查阅、复制相应病历资料。[\[MED01\]](../SOURCES.md#source-med01)

没有可靠亲友时，先记录医院官方咨询电话、社区卫生服务中心和居住地可以联系的服务渠道，分别问清是否提供预约协助、上门服务或照护转介。记录的是已核实的服务范围，而不是把一个机构名称当成随时有人上门的承诺。每次搬家或换工作后，顺手复核一次。

<a id="med02"></a>

## 3.2 身体不舒服时，先选对就诊入口，再安排这一天

先回答两件事：现在是否有需要急救的危险表现？如果暂不紧急，这个问题由哪类门诊接手？严重呼吸困难、突然说话不清或一侧肢体无力、意识异常、大量出血等，应立即寻求急救；这不是一份穷尽的症状清单。拿不准突发状况是否危险时，如实向120说明，听从调度。[\[MED02\]](../SOURCES.md#source-med02) 常规预约不应拖延紧急处理。

<a id="med02-sub-01"></a>

### 不知道挂什么科时，把问题讲成身体发生了什么

使用医院官网、官方公众号、官方应用或院方公开电话核实科室及院区。可以问：“我主要是\_\_\_\_不适，已经\_\_\_\_天，是否适合挂这个科？如果不是，请告诉我应该咨询哪里。”不要只说“我怀疑自己得了某病”。有多个分散问题、无法判断入口时，可以询问全科或导诊；具体服务名称以医院为准。

预约前逐项核对姓名证件、日期、院区、科室、医生或门诊类别，以及报到截止时间。很多奔波来自同一家医院的两个院区混淆。把预约截图与地图目的地对照，问清退改规则和当日能否完成检查。号源已满时询问其他合适门诊或转诊建议，不相信陌生人“包看上、包住院”的承诺。

<a id="med02-sub-02"></a>

### 准备不是一律空腹，也不是自行停药

按预约项目向科室确认是否需要空腹、是否可饮水、原有药物如何处理、有无月经或妊娠相关注意事项。对“检查前停药”的含混提示，报出药名再核对，不把其他人的经验套到自己身上。没有得到明确指示时，不擅自停用长期处方药；联系不到科室，可通过医院官方咨询或开药医生确认。

出门前把证件或医保凭证、旧报告、用药清单、充电设备和必要辅助用品放好。需要轮椅、手语、无障碍厕所、阅读协助等支持的，提前联系院方问具体入口。带食物和水是否能用，要服从检查要求；“包里有”不等于任何时点都可以吃喝。

| 这一段时间 | 提前留出的安排 |
| --- | --- |
| 出发与报到 | 交通、找院区、排队和无障碍移动时间 |
| 门诊与检查 | 可能分开预约，别假定一个上午都能完成 |
| 回程与家务 | 疲劳时的回家方式，当天必要照护由谁接替 |
| 结果与复诊 | 报告何时出，是否需重新挂号，谁负责解释 |

如果临时发热、症状加重、出现新的妊娠可能，或准备要求没有完成，主动向科室说明，由医院决定是否调整，不隐瞒后照原计划做。身体已明显不适时，减少同一天夹带的购物、面试和长距离赶路。请假可以只提供办理所需的就诊信息，病情细节由你决定向谁说明。

预约后还剩一个问题没有答案，例如“能否独自离院”，就把它写成下一通电话的第一句话。准备清单的作用是发现缺口，不是要求自己在生病时把所有事情做得完美。

<a id="med03"></a>

## 3.3 在诊室把问题说清楚，把决定听明白

就诊前用五到十分钟写一段时间线，长度以能够读给医生听为准。顺序是：最困扰的症状、何时开始、怎样变化、对吃饭睡觉工作有什么影响、已经采取什么处理。补充相关病史、用药和过敏；有妊娠可能、近期手术或特殊接触时主动说明。不要为“显得懂医”堆砌网络诊断。

虚构的表达示例：“我三天前开始腹部不舒服，今天比前两天明显，已经影响进食。昨天自己服用了\_\_\_\_，实际用量写在这里。以前有\_\_\_\_病史，这次与过去的不同是\_\_\_\_。”如果痛得说不清，先告诉医生最影响你的事情，不必努力讲完全部历史。记录可以交给医生看，也可以由你允许的陪同者补充。

<a id="med03-sub-01"></a>

### 把最重要的三个问题放在前面

第一，医生目前怎样判断，哪些仍不确定？第二，建议的检查或治疗是为了解决什么，结果会怎样改变下一步？第三，出现哪些变化需要提前回来，何时复诊？复杂问题可能需要多次沟通，但离开前至少应知道今天要做什么、不能拖的是什么、下一次找谁。

涉及手术、特殊检查或特殊治疗，医务人员依法应说明医疗风险和替代方案等，并取得相应明确同意；不能或者不宜向患者说明时，法律另规定向近亲属说明的情形。[\[MED01\]](../SOURCES.md#source-med01) 你可以说：“这个词我没听懂，请用平时说话的方式解释。若暂时不做，主要风险是什么？有没有其他可行方式？”这不是要求医生保证结果，而是让选择建立在理解上。

<a id="med03-sub-02"></a>

### 用自己的话复述，比点头更容易发现误会

离开诊室前说：“我理解今天先做\_\_\_\_；报告出来后在\_\_\_\_联系\_\_\_\_；若发生\_\_\_\_就提前就医，对吗？”把关键期限写成具体日期或由医护确认的时间范围。不要把“过段时间复查”自行理解为下个月。治疗有选择时，问清可用于考虑的时间；需要紧急处理则按医疗团队安排。

觉得被打断时，可以温和而具体地说：“还有一件可能影响判断的事，我正在用\_\_\_\_药，请您确认是否相关。”如果沟通仍无法完成，询问能否在适合时段补充、挂复诊号或通过院方指定渠道反馈。对重大、非紧急且自己仍不理解的决定，可以带完整资料另寻合适专科意见；同时确认等待会不会影响治疗时机。

第二位医生意见不同，不必马上判断其中一位不可靠。请其说明差异来自新资料、风险取舍还是可用方案，并把两次建议连同时间一起记录。不要自己把两份处方拼成第三套方案。陪同者可以帮你记要点，但不能替你隐瞒症状、抢答敏感问题，或把其个人偏好当成你的选择。

如需录音帮助记忆，先征得在场人员同意并遵守医院规则；不拍摄其他患者。即便没有录音，也可以在离开后立即写三行：今天得到的判断、已决定的行动、仍需确认的问题。原始报告与医嘱另存，个人笔记不能替代正式医疗记录。

<a id="med04"></a>

## 3.4 检查做完还没结束：报告、解释和下一步要接上

每新增一项检查，就留下“何时做、何时出、在哪看、谁解释”四个答案。不同项目可能分批出报告；完成抽血或取样，并不表示所有结果已经返回。离院前问：“这次共有几份结果？哪些需要晚些领取？需要我主动预约复诊吗？”不要把“医院没有打电话”理解为一切正常。

| 项目 | 完成与预计出结果 | 后续责任 |
| --- | --- | --- |
| 教学示例：检查甲 | 周一完成，窗口告知周三查询 | 本人周三查询，按医嘱约结果解释 |
| 教学示例：检查乙 | 周一取样，预计另行通知 | 先确认通知途径，逾期向指定窗口核查 |
| 实际填写 | \_\_\_\_ | \_\_\_\_ |

表中日期只是说明记录方法，不代表任何检查的统一时限。医生说某项结果需要尽快处理，就按其要求安排；已经不舒服或症状加重时，不为等待一张完整报告而延迟就医。电子系统里只有部分结果时，核对项目清单，不把空白自动当成阴性。

<a id="med04-sub-01"></a>

### 看见箭头时，先保留完整信息

记录检查日期、当时症状、是否按要求准备、相关用药与旧结果，把完整报告给负责解释的医师。一个红色箭头、结节或阳性字样不能独自说明病情严重程度。不要在网上对着单项数值自行确诊，也不要因为短视频说“大家都有”而跳过医生安排的复核。具体解释需要结合检查方法、病史和上下文。

可以问：“这项异常目前意味着什么？还缺什么证据？需要马上处理、补充检查，还是按期复查？如果复查，什么时间、同一项目还是另一项目、去哪一科？”听见“观察”时，把需要观察的变化和提前回诊条件问清楚；没有这些信息，观察很容易变成无限期搁置。

<a id="med04-sub-02"></a>

### 联系不上时，按现有路径逐层补齐

先核对原就诊记录中指定的报告或病区联系方式；无人接听时，通过医院官方总机、门诊服务台或预约渠道询问替代联系办法，说明就诊日期、科室、项目和问题。必要时预约结果解释门诊。不要把病历发给搜索广告中自称“专家助理”的私人账号，也不要在陌生群里公开身份证和检查条码。

如果医院来电提示异常，先记下来电科室、需做的行动和时限。涉及转账、验证码或安装软件的要求，暂停操作并用院方公开号码回拨核实。核实身份与及时就医可以并行：若已出现危险症状，直接急救，不等回拨完成。

结果明确后，把该项状态从“待查看”改成“已解释”，并写上处置结论与下次日期。转去另一家医院时，问是否需要原始影像、病理材料或其他文件，按机构流程办理，不能只带一张转发截图。患者有权依法查阅、复制相应病历资料；具体办理材料、领取和邮寄方式向医疗机构确认。[\[MED01\]](../SOURCES.md#source-med01)

委托别人代取报告时，先问医院接受什么授权及证件，不把所有证件一次性发给商业陪诊人员。对方的任务可限定为“领取并交给本人”，解释报告仍由合适医务人员完成。

<a id="med05"></a>

## 3.5 换药、加药和出院后，重新核对正在执行的那一份药单

用药清单记录的是你实际怎么用，而不只是医生过去开过什么。跨医院就诊、增加保健品、出入院或换处方时，都容易出现信息没有接上的情况。世界卫生组织把多重用药与医疗照护交接列为用药安全的重要关注点；中国的用药安全要求也强调处方、调配、给药和患者用药全过程管理。[\[MED03\]](../SOURCES.md#source-med03)[\[MED04\]](../SOURCES.md#source-med04)

| 需要问清的字段 | 记录方法 |
| --- | --- |
| 名称与规格 | 通用名、每片或每支规格；外盒照片辅助 |
| 本次安排 | 用法、频次、疗程、开始日期，由医护确认 |
| 旧药衔接 | 哪些继续、哪些停止、哪些调整，不留“应该照旧” |
| 异常与漏服 | 可能出现什么问题，发生时联系谁，漏服怎样处理 |
| 补药与复诊 | 药量预计到何时，下一次处方或监测如何安排 |

拿药时核对药袋上的姓名、药名、规格、数量与本次处方；发现不一致，当场问药师。药的颜色或包装变了，不自行认定拿错，也不直接认定是同一种；先让药师确认。一个药有多个商品名，凭品牌外观无法排除重复。

<a id="med05-sub-01"></a>

### 把容易含混的句子变成问题

“一天几次”还不够时，问“如何与吃饭安排？能否与我正在用的这些药一起？需要避免哪些饮品、活动或其他药？”如果工作轮班、吞咽困难、视力不好或记不住复杂安排，直接说明，让医护考虑合适的执行方式。不能把别人用过的药、剂量或“睡前一片”套到自己身上。

遇到多张处方，你可以说：“这两位医生分别给了我这些药，清单是我现在实际服用的。请帮我核对是否重复、有没有需要调整的地方，并给我一份当前方案。”有疑问时找开药医生或药师，不自己停掉全部药，也不为了“保险”同时服用。具体处理要依据药物和病情。

<a id="med05-sub-02"></a>

### 发现不适时记录事实，不急着给原因下结论

写下开始用药的时间、不适何时出现、具体表现、同时使用的其他东西，并及时咨询。是否继续、暂停或替换由医护结合药物风险判断；明显呼吸困难、喉部肿胀、晕厥等严重表现先急救。[\[MED02\]](../SOURCES.md#source-med02) 不要为了验证“是不是药引起的”而自行再吃一次，也不自行用别人的抗过敏药抵消。

日常可以用一张纸或手机提醒标记已服，但不要在多个应用里重复打卡造成误会。药盒分装前确认该药是否适合离开原包装、如何防潮避光；冷藏、避光或其他要求照说明与药师指导。原标签、说明书、有效期和批次信息保留，别把所有药倒进一个无标识的小瓶。

需要别人帮你拿药时，任务说到可执行：“请按这张本次处方领取；如果缺货或要求换药，先联系我，由药师或医生确认。”他人可以提醒和记录，不应擅自调整处方。丢失药物、快用完或外出时间延长时，提前问补方或接续办法，不靠省着吃来延长疗程。

每次方案调整后，在旧清单上写“已被某日期方案替代”，保留历史但把当前清单放首页。这样下一次看病时，医生看到的是正在发生的事实，而不是你手机里最早的一张处方。

<a id="med06"></a>

## 3.6 先问清费用如何发生，异地就医多核对一层

谈费用可以从具体限制说起：“我担心总支出超出预算，请帮我区分必须尽快做的、可以分步安排的，以及可能的替代方案。”临床必要性问医疗团队，收费组成问收费或价格咨询窗口，医保支付问医保窗口或参保地经办机构。一个窗口未必能准确回答全部问题，不把“应该能报”当成结算承诺。

非紧急项目可以要求了解费用构成：检查或治疗本身、麻醉、材料、病理、床位、护理，以及可能增加的项目。询问是估计范围还是确定收费，哪些情况会增加支出。预交金不是最终总价；也不能用一个治疗名称推断所有医院和所有病情的总费用相同。紧急处置不应被这张预算表拖延。

| 教学预算，金额均为假设 | 金额与需要确认的事 |
| --- | --- |
| 医疗自付预留 | 1500元；等待医院与医保核实，暂不当作最终报价 |
| 交通和必要陪护 | 300元＋600元；向实际服务方询价 |
| 恢复期生活支出 | 400元；餐食及基本用品 |
| 合计现金准备 | 1500＋300＋600＋400＝2800元；另留余量，不代表报销金额 |

这笔钱不是人人应准备的统一标准。你的预算还可能包括请假收入变化、孩子照护和复诊交通。先用已确认金额，再把未知项目标注待核实；没有报价的地方不能填零。商业保险是否赔付另按合同与保险公司流程确认，不因买过保险就先假定全部由其承担。

<a id="med06-sub-01"></a>

### 跨省就医，先确认参保地和这一次服务

通过国家医保服务平台、国家医保局公开渠道或参保地医保经办机构，核实备案类别、材料和状态，以及拟去机构是否开通对应直接结算服务。按实际情况选择长期居住、转诊或其他临时外出等类型，不为提高待遇填不真实信息。备案提交成功与审核完成不是同一个状态。[\[MED05\]](../SOURCES.md#source-med05)

跨省直接结算的一般框架涉及就医地支付范围、参保地待遇政策及就医地管理；住院、普通门诊和门诊慢特病还要分别确认。[\[MED06\]](../SOURCES.md#source-med06) “医院能刷医保”不能自动推导为你这次项目、资格和备案均可结算。问清是否需要转诊、备案何时生效、急诊情形如何处理、回参保地看病是否受影响。

异地急诊抢救人员有视同已备案的规则。符合规定时，医疗机构如实上传相应急诊标志，参保地按异地急诊抢救相关待遇办理直接结算；这不等于所有自费门诊都自动适用。发生急症先就医，不为等待备案或医保手续耽误救治，再请医院医保窗口核对本次情形与参保地规则。[\[MED06\]](../SOURCES.md#source-med06)

现场结算失败时，先请窗口核查身份、参保状态、备案、机构和项目，不急着重复缴费。请工作人员说明具体失败原因，记录时间、窗口与查询编号；按参保地要求确认能否补办或办理零星报销，需要保留哪些原始票据、清单和病历。不能保证所有自费都能事后补报。

离院前核对费用明细、退款或补款情况，留好电子票据下载方式。帮忙付款的人与决定治疗的人可以不同，不因为谁垫钱就自动交出病情信息和选择权。钱款争议通过正规窗口处理；对方要求转入私人账户时，先向医院核实收费主体与用途。

<a id="med07"></a>

## 3.7 手术和镇静检查：本人同意、接送、陪护分别落实

预约时就说清真实条件：“我目前没有同住成年人，可以自己沟通和作决定。请确认这项操作需要什么陪同、接送和离院后的照看。”这句话越早说，越有时间找可行安排。不同操作、麻醉方式、身体状况和医院流程可能不同，不能一律认为必须有配偶，也不能一律认为一个人到场就能完成。

<a id="med07-sub-01"></a>

### 先核对医疗安排，再找合适的帮助

记录术前评估、检查材料、禁食禁饮要求、原有药物处理、报到地点与时间。禁食和停药必须按医疗团队针对本次操作的指示执行，不直接照书里的统一小时数。身体出现新不适、未按要求准备或陪护计划改变，提前联系科室，让团队决定是否调整。

请医生说明目的、主要风险、替代方案和不做或推迟的后果。民法典第1219条规定知情说明与相应同意；第1220条另对抢救生命垂危等紧急情况、不能取得患者或近亲属意见时的处置作出规定。[\[MED01\]](../SOURCES.md#source-med01) 日常预约中的签字手续与紧急救治应区分，不能用一句“没有家属就不能救”概括。

| 角色 | 要确认的任务 |
| --- | --- |
| 本人或依法有权者 | 理解医疗说明，依具体情形作出医疗同意 |
| 联系人 | 医院怎样联系、希望通知谁，不自动取得代签权 |
| 接送人 | 是否符合院方要求，到场时间、地点与交通 |
| 陪护或生活支持 | 需要照看多久、能做哪些事情、临时缺岗谁替补 |

本人能够理解、表达并作决定时，应直接参与医疗说明和决定；亲友可协助沟通，但不能仅凭联系人身份取代本人。特殊情形依法律和医疗流程处理。[\[MED01\]](../SOURCES.md#source-med01) 希望朋友帮助沟通或代办时，先问医院所需授权范围、形式和身份材料。不要让朋友假扮亲属，也不要把网上下载的“全权委托书”当成普遍有效的解决办法。对方不能满足要求时，询问患者服务、医务部门或社会工作部门有哪些可行程序，必要时请科室书面列出缺少的事项。

<a id="med07-sub-02"></a>

### 把术后第一晚安排到具体行动

全身麻醉影响可能延续到离院后，自觉清醒也不能据此判断可以驾车、做饭或独自照护孩子。NHS的通用建议涉及接送、陪伴和避免影响安全及判断的活动；中国医院针对本次操作的具体指示应另行确认。[\[MED07\]](../SOURCES.md#source-med07) 问：“何时可以独处？出现什么情况要联系医院？今晚需要有人在同一住处，还是有其他符合要求的安排？”

给接送人发清楚的任务：“请在医院通知后到\_\_\_\_楼\_\_\_\_处接我；先到护士站确认离院要求；送到家后陪到\_\_\_\_，如不能继续请提前联系我和科室。”网约车司机的运输服务不等于陪护。商业陪诊能否满足要求，必须由医院确认，再核对其身份、服务内容、替班、收费与退改办法。

陪同者临时有事时，立即联系科室，讨论更换合格支持、调整时间或其他医疗上可行的安排。不要为了不损失预约费隐瞒独处事实，也不自己延长在院停留而假设医院提供免费陪护。出院前请医护再次确认你实际回家的环境、交通和支持，取走书面注意事项与可联系途径。

<a id="med08"></a>

## 3.8 住院期间，把护理、院外事务和信息沟通分开安排

入院前先列一张“我不在家时谁接手”的清单：孩子、长辈、宠物、必要工作、房租水电和必须到场的事务。每项写具体人、开始与结束时间、能够使用的资料或钥匙。家里没有这些任务就划掉，不把别人的生活模板全部背到自己身上。突发住院来不及准备时，先交出最急的一两件事。

对朋友说“这周照顾一下我”很难执行。可以改成：“周二晚请帮我把换洗衣物送到病区指定位置；周三请帮我联系猫的临时照看；后续我周四再确认。”对同事只交接工作所需的信息，请假材料按实际流程办理。把所有帮忙的人拉进一个群未必更省事，可以指定一位经你同意的协调者，避免重复询问和扩散病情。

<a id="med08-sub-01"></a>

### 护理需求要具体到动作

入院后告诉责任护士自己能否独立如厕、进食、上下床、取物和呼叫，有无视听障碍或跌倒等既往情况。觉得疼、恶心或头晕时及时告知，别为了不麻烦别人隐瞒。护理站如何呼叫、夜间怎样求助、哪些活动需要协助，第一次就问清楚，不等尝试失败才求助。

需要服务时，先问医院实际提供什么，是否允许外聘人员，谁负责专业护理，谁只提供生活协助。陪诊、护工、家政和护士不能仅凭名称互相替代。商业服务核对合同主体、人员身份、服务时段、是否同时照顾多人、夜间和节假日安排、临时替班及费用，不把注射、换药等专业操作交给未经确认资质的人。

| 每天简短记录 | 用来解决什么 |
| --- | --- |
| 医护告知的重要安排 | 今天做什么，是否需要准备，仍有哪些待定事项 |
| 吃饭活动与实际困难 | 向团队反馈完成情况，不自行修改治疗方案 |
| 待出结果与沟通问题 | 留到合适沟通时段逐项确认 |
| 照护排班和院外任务 | 谁来、几点换班、哪项仍没有人接手 |

病区忙时，可以问医生或护士何时适合集中沟通，先把问题写下；有紧急变化则立即呼叫，不等固定沟通时间。若不同工作人员给出看似冲突的安排，复述差异，请负责团队统一核对。不要因怕冒犯而自己选一条执行，也不要把工作群里的转述当正式医嘱。

<a id="med08-sub-02"></a>

### 照护预算不够时，先暴露缺口

直接说：“我只能承担\_\_\_\_天的陪护，目前如厕仍需要帮助。请评估这部分能有哪些安排。”可询问医院社会工作、患者服务和所在地相关救助咨询；是否有名额、资格和资金支持须逐项核实。没有落实的公益或社区服务不能填进正式排班。可把亲友支持集中在最需要的时间段，而不是默认某一个人连续陪住。

需要别人了解病情时，明确你同意共享到什么程度；不愿在多人病房谈敏感事项，可以询问是否有更合适的沟通空间。医疗隐私受法律保护，但实际交流也需要你及时表达偏好。[\[MED01\]](../SOURCES.md#source-med01) 离院前把临时授权和钥匙去向复核一次，住院结束不意味着临时权限自动收回。

<a id="med09"></a>

## 3.9 出院前先演练：回到家后，我能完成这些事吗

出院的医疗判断由治疗团队作出，回家后的生活条件也要如实告诉团队：“我住在无电梯的楼上，白天主要自己在家，卫生间离卧室较远。”这些信息比一句“我能自己照顾自己”更有用。需要换药、管路处理、康复或他人协助时，出院前就确认接续地点与具体方法。

<a id="med09-sub-01"></a>

### 把医嘱变成今天回家能够执行的安排

请医护核对新旧药如何衔接、饮食与活动限制、伤口或其他护理要求、复诊时间、待出报告和需要及时返回的变化。不会的操作请其示范，并在允许的情况下让你复述或演练；仍做不到，直接说明。不要把“回去注意点”自行补成专业护理教程，也不让短视频代替面对面的指导。

| 离院核对 | 确认结果 |
| --- | --- |
| 回程 | 谁接、怎样上楼、必要辅助器具是否到位 |
| 当前药单 | 哪些继续或停用，药量是否能衔接下次就诊 |
| 恢复限制 | 哪些活动暂缓，何时及按什么条件恢复 |
| 后续医疗 | 复诊、检查、换药或康复的地点与预约 |
| 异常求助 | 什么变化要立即处理，白天与夜间分别联系哪里 |

核对表不代替书面医嘱。可以照着说：“我回家后先按这张新药单执行，\_\_\_\_日复诊；出现\_\_\_\_时立即就医。关于\_\_\_\_我还做不到，请帮我确认替代安排。”不要因担心耽误办理而略过最关键的困难。取齐出院记录、处方和费用凭证，病历复制及待出报告另按医院流程办理。

<a id="med09-sub-02"></a>

### 恢复期按真实体力排日程

家里先安排能轻松拿到的水、符合医嘱的餐食、日用品、手机与充电，减少搬重物、爬高和需要长时间站立的家务。示例安排可以是：第一天只完成回家与休息，朋友送一餐；第二天电话确认状态；第三天是否能自行采购，按医嘱和实际情况再决定。这是生活组织示例，不是所有手术的恢复时间表。

需要照护孩子或长辈的人，把“能出院”和“能够独立照护他人”分别问清。返工也不只问能不能坐在电脑前，还要告诉医生通勤、搬重物、夜班和持续站立的要求。请单位按真实情况讨论请假或工作调整；不要用一个朋友的康复速度评判自己。

回家后记录医嘱要求观察的事项及变化，不必无依据地反复测所有指标。出现医嘱强调的警示症状，按要求联系医院；明显危急时直接120。医院联系电话暂时无人接时，询问官方总机或到适当急诊就医，不无限等待某位医生的私人消息。症状缓解也不等于可以自行停药或取消所有复诊。

恢复后把这次经验写成两条可改进的安排，例如“下一次提前问清接送要求”“把药单首页更新”。不需要给自己的表现打分。支援你的朋友也应知道任务何时结束、是否还有待归还物品或结算费用，让帮助有清楚的开始和结束。

<a id="med10"></a>

## 3.10 突然需要急救时，先让人找到你

平时在手机容易找到的位置和钱包里存一张简短求助卡：姓名、准确地址、本人电话、重要疾病与过敏、当前重要用药、已同意的联系人。地址写到楼栋、单元、楼层和门牌，搬家后马上更新；人在酒店或短租房时，补充当前地点，不让地图默认的家地址误导救援。

<a id="med10-sub-01"></a>

### 拨通120后，先说位置，再说发生了什么

可以这样说：“我在\_\_\_\_区\_\_\_\_路\_\_\_\_小区\_\_\_\_栋\_\_\_\_单元\_\_\_\_楼\_\_\_\_号，一个人在家。刚才开始\_\_\_\_，大约\_\_\_\_分钟前发生，我现在\_\_\_\_，联系电话\_\_\_\_。”补充大致年龄、意识和呼吸情况、重要病史及已做的处理。别急着挂断，听调度员继续提问，保持电话畅通。[\[MED02\]](../SOURCES.md#source-med02)

严重胸痛伴大汗、明显呼吸困难、突然说话不清或一侧肢体无力、意识异常、大量出血等，是需要立即求助的示例。不是必须同时出现才算紧急，也不是没有这些表现就一定安全。突发情况不能判断时如实说明，避免等到朋友回信或自己在网上查完才行动。[\[MED02\]](../SOURCES.md#source-med02)

等待时停止不必要的活动，按调度指导留在安全、便于被找到的位置。身体和环境允许时准备开门或让可靠的人接应；开不了门，就立即告诉调度。不要为取证件下楼追车，不洗澡换衣，不自己驾车。需要采取现场措施时，按调度或医护指导，不凭本书自行服用所谓通用急救药。

<a id="med10-sub-02"></a>

### 孩子、宠物和家门，可以交给另一条支持线

完成呼救后，如有能力再联系事先约定的人：“我已经呼叫急救，现在在\_\_\_\_。请你帮忙处理\_\_\_\_，不要为了接我耽误急救。”孩子、失能长辈或宠物在场，应告诉急救人员和联系人，由合适的人另行接手。没人能立即来时如实说明，不为了把家事安排周全而拒绝转运。

陌生城市或户外地点没有门牌时，说附近明显建筑、路口、入口或定位信息，按调度要求提供。不要只说商场昵称或某平台的定位短链接而假设对方已经收到。手机快没电、门禁困难、楼里无电梯等情况，也尽早说明。任何临时处理都以自身安全和调度指示为前提。
