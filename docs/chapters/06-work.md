# 06 工作中的权益

[← 上一章：一个人也要吃好](05-food.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：关系与支持 →](07-relationships.md)

<a id="introduction"></a>

这章按一份工作的实际顺序来写：应聘、拿到录用通知、签约、领取工资、面对不合理要求，以及离开。你不需要等到发生冲突才整理材料；平时留下少量连续记录，往往比事后回忆整段经历更有帮助。

主要适用于中国大陆劳动关系中的职工。实习、退休后返聘、个人接单、承揽与劳务合作，适用规则可能不同；要看实际管理、工作和报酬安排，不能只凭合同标题下结论。下文的话术、表格、工作次序及虚构金额用于帮助行动，具体法律结论仍须结合完整事实。

## 6.1 面试被问婚育，把问题带回岗位

面试官问“有对象吗”“什么时候生孩子”，你可能首先担心，不回答会失去机会。可以先决定这次沟通的目标：继续了解岗位、确认对方是否设置限制，或结束面试。你没有义务在当场完成一场辩论，也不必为了显得坦诚，把整个私人生活交给对方评估。

<a id="work01-sub-01"></a>

### 面试前先保留岗位的原貌

投递时保存招聘页面、公司全称、岗位职责、条件、薪酬范围、链接和日期。把自己提交的简历版本一并存下，避免之后出现“你没有提供某项经验”的争议。招聘者使用简称时，询问实际签劳动合同的单位名称；集团品牌、招聘平台账号和用人单位未必是同一个主体。这里只保存与你应聘有关的材料，不收集无关人员的私人信息。

面对普通岗位安排，可以回答具体的工作能力：“这个岗位每月需要出差几天？提前多久确定？我可以根据安排说明能否配合。”如果被追问婚育，则可说：“我愿意讨论到岗日期、排班与出差要求。婚育属于我的私人安排，我们可以继续谈岗位需要吗？”把“未来是否永远没有家庭事务”换成“现在是否能完成已经说清的工作要求”，有助于双方判断是否合适。

<a id="work01-sub-02"></a>

### 对方坚持时，确认它是否成为录用条件

可以追问：“我想确认，未婚或有生育计划是否会影响这次录用？如果是，请说明公司的具体条件。”不要为取得证据而激怒对方，也不用当场承诺几年内不结婚、不生育。妇女权益保障法对进一步询问或调查女性求职者婚育情况、入职妊娠测试、婚育限制等作出禁止规定，同时保留国家另有规定的边界。[\[WORK01\]](../SOURCES.md#source-work01)

假设面试中对方说“这个岗位要求连续三年不生育”，你可以记下原话；若对方只说“我们近期项目比较忙”，则先追问工作量与排班。后者本身不足以证明婚育歧视。记录要区分对方实际说过的话、你的理解和目前无法确认的部分，这样后续咨询更容易判断，而不是把所有令人不舒服的提问归成同一种问题。

<a id="work01-sub-03"></a>

### 面试结束后，补一页事实记录

写下日期、地点或会议平台、在场人员、关键原话、你的回复，以及后续录用或拒录消息。保存原始聊天和邮件，截图留上下文。需要录音等材料时先考虑取得方式的合法性与自身安全，不公开传播未经核实的指控；证据能否采用应由相应机构判断。没有当场提出异议，不等于你认可了歧视条件。

如果仍想争取岗位，可发：“感谢今天的沟通。我确认可以满足已说明的\_\_\_\_工作安排。关于面试中提到的\_\_\_\_，请确认是否属于录用条件，并请按岗位能力继续评估。”如果决定退出，可直接结束应聘，同时保留材料。追责和继续求职可以并行，不必把下个月的生活费押在对方改变态度上。

对方不回复，或岗位已下架时，整理招聘页面、面试记录、沟通原件与诉求，向当地人社部门咨询招聘歧视投诉，也可向妇联或工会求助。[\[WORK01\]](../SOURCES.md#source-work01) 问清受理单位、补充材料、查询方式和编号。尚未建立劳动关系的就业歧视纠纷，不能机械地按劳动仲裁处理；请公共法律服务机构确认适合的途径。投诉可能促成纠正，但不保证获得录用或赔偿。

<a id="work02"></a>

## 6.2 录用通知到劳动合同，把承诺落在同一张纸上

口头谈妥“月薪一万”后，先别急着搬家或结束旧工作。把你将据此作出的决定列出来：辞职、迁居、租房、安排照护，以及放弃其他机会。决定越难撤回，越需要先确认录用条件和仍未完成的环节，例如背景核实、体检、审批或明确的到岗要求。书面录用通知有助于核对，却不能保证任何情况下都不会变化。

<a id="work02-sub-01"></a>

### 先对照三个版本

把招聘说明、录用通知和拟签合同并排读。核对实际用人单位、岗位与地点、合同期限、试用期、固定工资、绩效规则、发薪日、工时制度，以及保密、培训、竞业限制等附件。写明“见公司规定”的地方，请对方提供你将被要求遵守的具体版本。空白金额、空白日期、口头说以后补的附件，应补齐并核对后再签。

| 需要核对 | 不要只接受这种说法 | 进一步问什么 |
| --- | --- | --- |
| 固定与浮动报酬 | 综合薪酬很高 | 固定税前数、绩效条件、发放时间 |
| 实际工作地点 | 服从公司统一安排 | 常驻地址、出差范围、变更流程 |
| 附件与规章 | 都是标准模板 | 现行版本、适用范围、完整副本 |
| 签约主体 | 我们都是同一集团 | 雇主全称、合同签章、工资与参保主体 |

例如下面这组是虚构数字：甲方案固定税前工资 8000 元，另有最多 2000 元绩效；乙方案固定税前工资 9500 元，另有不确定年终奖。不能把甲直接理解为每月稳定拿到 10000 元，也不能把乙的年终奖提前算入房租来源。先用明确的固定部分做现金安排，再询问浮动部分的考核、结算和离职时处理方式。到手数还会受依法扣缴项目等影响。

可写：“录用通知写月度薪酬\_\_\_\_元，合同拆分为固定\_\_\_\_元及绩效\_\_\_\_元。请提供绩效条件、考核周期、调整流程和发放时间，确认试用期间分别适用什么标准。”试用期长度与工资有法定限制，受合同期限、同一单位是否已经约定过试用期等影响；拿完整条款核对，不能以“新人都这样”作为依据。[\[WORK02\]](../SOURCES.md#source-work02)

<a id="work02-sub-02"></a>

### 签完后拿到自己的完整版本

| 合同期限或情形 | 试用期核对点 [\[WORK02\]](../SOURCES.md#source-work02) |
| --- | --- |
| 不满3个月，或以完成一定任务为期限 | 不得约定试用期 |
| 满3个月、不满1年 | 最长1个月 |
| 满1年、不满3年 | 最长2个月 |
| 3年以上固定期限或无固定期限 | 最长6个月 |
| 同一单位与同一劳动者 | 只能约定一次；试用期包含在合同期内 |

全日制劳动关系原则上应订立书面劳动合同；已开始用工而未同时签约的，应自用工之日起一个月内订立。[\[WORK02\]](../SOURCES.md#source-work02) 这不表示单位可以任意让人无合同工作一个月，也不表示未签合同就不存在劳动关系。保存到岗安排、工作指令、工资支付等实际用工材料。双签或盖章后的合同、附件和后续变更，自己应能取得并阅读完整内容。

电子签约时，在自己确认的页面核对全文和签约主体，下载可读取的最终文件及签署记录。不要只保存“签署成功”截图；留意链接是否有到期限制。对方说系统不支持下载，可以书面索取完整合同副本。不要为了拿到合同而删除已经存在的原件，或在空白文件上先签名供对方补填。

<a id="work02-sub-03"></a>

### 对方临时改条件怎么办

到岗前发现地点、工资或雇主与承诺不一致，先发一条列出差异的消息，要求确认最终版本和原因。已经根据承诺辞职、搬家或支付费用的，保留原承诺、作出决定的时间及实际支出凭证，再咨询责任与救济；不要仅凭一条取消录用通知就预设补偿金额。是否接受新条件由你判断，沉没成本并不会使更差的岗位自动变得合适。

有“离职必须交几十万”“任何同行都不能去”等条款时，带原文咨询。竞业限制的适用人员、秘密接触情况、范围、地域、期限与补偿都需要审查；2025 年司法解释进一步明确相关边界。[\[WORK03\]](../SOURCES.md#source-work03) 不能只凭条款夸张就认定它完全无效，也不能把签了字理解成任何要求都必然有效。

## 6.3 工资与社保，每月花十分钟核对

每个月选择固定时间，把工资条、银行到账、社保缴费记录放在一起。核对的目标是找出差额及原因，而不是追求一张复杂表。没有工资条时，可向人事或财务索取本人的工资项目和扣缴明细；尽量使用可留痕的渠道，不只在走廊里问一句“这个月怎么少了”。

<a id="work03-sub-01"></a>

### 把固定、浮动和扣减拆开

下面是假设的完整月份：固定工资 8000 元、当月确认绩效 1000 元、已确认补贴 300 元，应发合计 9300 元；依法代扣项目等合计 1500 元，其他经核实扣款为 0 元，则实发 7800 元。这里的 1500 元只是教学数字，不能用来推算你的税费和社保比例。若实际到账 7300 元，应追查 500 元差额，不要直接写成“公司拖欠我所有工资”。

询问可以这样写：“我收到\_\_\_\_月工资\_\_\_\_元。根据现有工资明细，我理解应发为\_\_\_\_元、扣减为\_\_\_\_元，仍有\_\_\_\_元差额。请提供各项依据及计算过程；如需更正，请确认支付日期。”先核对是否跨月发绩效、入离职非整月、请假、补发或重复扣款。确认有争议后，把对方说明与自己的异议分别保存，不在表里覆盖掉旧数字。

若公司用“绩效不达标”解释减发，询问适用规则、公布方式、目标如何确定、你的实际完成数据、由谁确认和是否有复核渠道。考核可以有合理依据，但不能只用一个总分替代全部事实。你可以提出：“请提供本期扣减对应的指标和记录，我将在\_\_\_\_前逐项回应。”这里的回复时间是双方沟通安排，并非通用法定期限。

<a id="work03-sub-02"></a>

### 试用期也要核对参保

依法参保缴费的义务不因试用期而取消。[\[WORK04\]](../SOURCES.md#source-work04) 在当地官方社保服务渠道查看参保单位、缴费月份和基数，留意申报或到账显示周期。新入职当月暂时看不到记录时，先问申报时间及当前状态，不能仅凭一次页面空白判断漏缴；连续缺失或解释矛盾，则留存查询结果并向社保经办或征缴部门核实。

“我自愿不缴社保，把钱发给我”的协议不能使法定义务消失。2025 年劳动争议司法解释明确，这类约定或承诺无效；单位补缴后，已支付的社保补偿如何返还也有相应规则。[\[WORK03\]](../SOURCES.md#source-work03) 因此不要把现金补贴当作与依法参保等价的选择。若已经签过，保存协议和付款记录咨询，避免只把协议扔掉后失去经过证据。

<a id="work03-sub-03"></a>

### 发现漏缴或错缴，分清两类请求

一类是核实参保、补缴和更正记录，先向负责征缴或经办的部门询问本地程序；另一类是因单位行为引起解除或待遇损失等争议，需要另行判断法律路径。不是所有社保问题都通过同一个劳动仲裁请求解决。与人事沟通时写清月份、记录中的问题和请求，不在不了解程序时随口同意“算你自愿放弃”。

如对方反复说“下个月一定补”，把承诺日期列成时间线，按约定节点查看是否落实，同时开始咨询正式渠道。你可以继续履行正常工作并保留材料；是否据此解除、如何发通知、是否符合经济补偿条件，要结合实际情况确认后再行动。收入正在受影响时，另按“收入撑得住生活”一章安排基本开支，不把尚未收到的钱当作已经可用。

平时只需留本人记录。工资条属于私人资料，不为证明自己的差额擅自拷走同事薪酬库。若确需同岗比较，咨询合法取得和使用相关证据的方法；专业机构需要原件时，说明来源与存放位置，避免把未经核实的聊天传言当成确定事实。

## 6.4 加班与休假，让工作量和工时有对应记录

“每天都很累”说明生活已经受影响，但处理工时争议还需要回答：哪一天、做了多久、是谁安排、完成了什么，以及有无休息和补休。平时可以用简单日历记录，不需要把工作之外的每一分钟都监控起来。先明确岗位适用标准工时、综合计算工时还是不定时工作制；单位口头称“弹性工作”不能代替适用依据。

<a id="work04-sub-01"></a>

### 接到临时任务，先确认安排

可回复：“现有的甲任务预计今天完成，新增乙任务约需\_\_\_\_小时。如果乙必须今晚交付，请确认调整优先级、加班安排和补偿方式。”这样既让对方看到工作量，也避免将无法同时完成的任务默默压到自己身上。确实不能延时工作，可说明可以完成的范围和替代交付时间，不必披露全部家庭或健康隐私来证明自己有资格拒绝。

记录一条虚构例子：周三正常工作结束后，主管在 18:10 要求修改报告；18:30 至 20:00 实际处理任务，中间无额外休息；20:05 提交，对方回复收到。保存安排和交付记录，再核对考勤。仅有 20:05 的打卡，可能无法解释这段时间是否在工作；仅有聊天“辛苦了”，也不一定能说明具体时长。

<a id="work04-sub-02"></a>

### 补休和加班费要按情形区分

在适用的标准工时规则下，依法认定的工作日延时，支付不低于工资的 150%；休息日工作且不能安排补休，不低于 200%；法定休假日工作，不低于 300%。工作日延时和法定休假日工作不能仅以补休替代相应加班工资。[\[WORK05\]](../SOURCES.md#source-work05) 综合工时、不定时岗位还需核对批准情况、计算周期和地方规定，不能直接套用这三项比例。

不要只问“周六有没有三倍工资”。先查当年官方节假日安排和本人的排班，区分法定休假日、休息日以及调休后的工作日。加班工资基数也不必然等于银行到手数。你可以发：“请确认\_\_\_\_日的性质、本岗位工时制度、认定工时和支付或补休依据。”没有得到答复时，把具体日期带到当地人社渠道咨询。

<a id="work04-sub-03"></a>

### 请假前把手续和交接分开

需要休年假、病假或其他假期，先核对适用条件、申请方式与材料。能预先安排的，提出起止时间、工作交接和紧急联络范围；突发不适来不及走完系统时，先以可行方式通知，并按规则补材料。病假工资、医疗期和地方特别假期不能全国一概而论，应结合工龄、诊疗材料与当地规则核实。

休假申请可以写：“拟于\_\_\_\_至\_\_\_\_休\_\_\_\_假，甲事项已交接给\_\_\_\_，乙事项可于\_\_\_\_前完成。请确认审批结果及需补充材料。”如果被拒，问清原因、可安排的替代日期以及是否影响已有假期。不要因口头同意就认为系统中自动留了记录，也不要自行缺勤后才回头争论对方本来应该批准。

<a id="work04-sub-04"></a>

### 记录被删除或工时不被承认时

在仍有正常权限时，合法保存本人的排班、加班申请、工作通知和交付记录，文件名包含日期。不要下载客户资料、源代码或同事信息来“备份证据”，也不要绕过权限进入系统。部分记录由单位掌握，可在争议程序中具体说明名称、期间和证明目的，请求依法提供。[\[WORK06\]](../SOURCES.md#source-work06)

若长期超时已经影响身体或照护安排，除了核对补偿，还要提出可持续的工作量方案：延期、减少并行任务、明确值班轮换或换班。谈过后给一条书面纪要，让双方知道下一次怎样执行。危险作业、胁迫或现实人身风险不应被当作普通排期问题；先确保安全并及时向相应部门求助。

<a id="work05"></a>

## 6.5 面对调岗、降薪和被要求离职，先问这是什么决定

主管说“下周去另一个城市，薪酬重新算”，或人事把辞职申请放到你面前时，先暂停自动签字。此刻最需要的是拿到完整文字，区分公司是在提出协商方案、发出工作安排，还是已经作出解除决定。不同情形的责任和应对不同；不要让一张写着“个人原因”的表格替你定义整段经过。

<a id="work05-sub-01"></a>

### 把变化拆成可比较的项目

列旧岗位和新安排的名称、主要任务、汇报对象、地点、工时、固定与浮动薪酬、生效日期、过渡安排。比如“同城换办公室”和“跨城长期驻点”带来的生活成本不同；“固定工资下降”与“目标未完成导致浮动奖金减少”也需要分别核对。保留合同、现行岗位说明、过往工资和此次通知，避免只围绕“我被针对了”争执。

可以回复：“我已收到\_\_\_\_安排。请说明它是协商建议还是正式决定，提供依据、生效时间、岗位与薪酬明细。我希望在了解完整内容后书面回复；目前我仍愿意按现有安排履行工作。”劳动合同约定内容的变更原则上需要协商一致并采用书面形式，但具体岗位调整还涉及合同约定和合理管理权限，不能概括为所有调岗都可拒绝，或单位都能单方决定。[\[WORK02\]](../SOURCES.md#source-work02)

<a id="work05-sub-02"></a>

### 不同意时，说出具体异议与可接受方案

可写：“新地点使单程通勤由约\_\_\_\_变为\_\_\_\_，并新增\_\_\_\_支出；薪酬结构与现有合同存在\_\_\_\_差异。我不接受目前方案，愿意讨论\_\_\_\_替代方案。”把观察与成本列清楚，不以辱骂、删资料或消失回应。是否继续到原地点出勤、如何回应新指令，可能影响之后认定，情况复杂时尽快带文件咨询，不能靠一条网上建议统一处理。

假设原固定工资 9000 元，拟改为 7000 元加最高 2000 元绩效。即使名义上的“总包”没变，稳定部分已经下降；要确认绩效条件和争议处理，而不是只看合计。若公司愿意保持固定工资但调整任务，也需要评估能力、培训、健康和照护安排。金额均为虚构，计算只是帮助看清变化，不等于降薪合法性判断。

<a id="work05-sub-03"></a>

### 被告知不用来时，保存决定和履职意愿

请对方出具书面通知，写明决定、理由、生效日期和交接安排。若门禁或工作账号被停用，合法记录时间及无法工作的情况，向单位确认后续安排；不要冲闯办公室或借他人账号登入。可发：“今天\_\_\_\_时发现无法进入办公场所／工作系统，请确认原因及工作安排。我仍愿按要求正常履职。”如果已经收到解除通知，再按具体法律路径处理。

“签了才给工资”或“先写辞职以后谈补偿”出现时，要求把全部结算方案放在一起。工资、补偿、赔偿、报销、未休假期等应分项目核对，不把所有钱写成一个无法解释的整数。并非所有离职都有经济补偿，也不是所有争议都能获得俗称的“N+1”或“2N”；解除依据、程序、工作年限和工资基数都会影响结果。[\[WORK02\]](../SOURCES.md#source-work02)

<a id="work05-sub-04"></a>

### 协商协议可以争取时间阅读

索取完整草案，核对付款主体、金额性质、到账时间、税费处理、离职证明、违约处理和权利放弃范围。签收文件与同意内容不是一回事，但具体签注效力需结合情形；不懂就先问专业人员。协商期间同时核对时效，不能无限等待“老板出差回来”。即使决定接受方案，也要保留已签版本并跟踪实际到账，口头承诺不替代付款。

<a id="work06"></a>

## 6.6 遭遇性骚扰，先让自己离开，再建立可处理的记录

性暗示消息、反复展示色情图片、未经同意的触碰，或以晋升和工作机会交换亲密行为，都值得认真对待。是否单身、此前是否友好、有没有当场严厉拒绝，不决定你是否有权要求停止。人在压力下僵住、笑着应付或延迟求助，是可能发生的反应；记录行为与影响，比反复追问自己为何没有“更勇敢”更有用。

<a id="work06-sub-01"></a>

### 当下先处理安全与接触

能离开时去有其他人在场的地方，联系可信任的人。愿意且安全时可以明确说：“我不接受这类消息／接触，请停止。”如果对方掌握你的工作安排，可以先结束单独会面、改为公开场所或要求他人在场。出现暴力、强迫、限制自由等现实危险，及时报警；受伤或需要医疗帮助时及时就医，不必等待公司先作判断。

<a id="work06-sub-02"></a>

### 原件和时间线分开保存

保留完整消息、账号资料、时间和上下文，不只截最刺眼的一句。另写事件记录：发生地点、行为、你的反应、见证人、后续威胁，以及是否影响排班、绩效或健康。将就医、曾向可信任的人求助的记录按日期列入。证人愿意协助时征得同意后留联系方式，不替别人写结论，也不冒险再次单独赴约来补证。

例如可写：“\_\_\_\_日约\_\_\_\_时，在\_\_\_\_会议室，对方说了\_\_\_\_并做了\_\_\_\_。我随后离开，\_\_\_\_可能看到离开经过；当晚收到\_\_\_\_消息。”不能确定的时间标“约”，记不清的原话标为大意，避免后来为使叙述显得完整而补造细节。原文件不修改，便于阅读的标注副本另存。是否构成特定违法及材料如何采信，由有权机构依据事实判断。

<a id="work06-sub-03"></a>

### 向单位提出具体保护请求

先查防骚扰制度、负责人员、投诉邮箱及可绕开直属主管的渠道。投诉可分成事件概要、证据目录、当前风险、请求四段。请求不只写“严肃处理”，还可写避免单独接触、调整直接汇报安排、保存相关监控、限定资料使用范围，以及告知承办人、程序与书面结果。单位依法负有预防和制止性骚扰等职责。[\[WORK01\]](../SOURCES.md#source-work01)

可发送：“我现反映\_\_\_\_在\_\_\_\_期间的行为，具体经过与材料见附件。为避免继续接触，请先安排\_\_\_\_；请及时保存\_\_\_\_时段\_\_\_\_位置的监控，并确认收件、负责人员及调查安排。希望仅向处理此事必要的人员披露相关资料。”保密不能保证绝对无人知情，因此先问谁会接触材料、如何联系你、是否会通知被投诉者，不要因一个笼统的“保密”就误解流程。

<a id="work06-sub-04"></a>

### 单位拖延或你遭到不利对待时

把首次提交、补充材料、对方承诺和实际进展列为时间线。再次询问未完成的具体事项；若出现突变的考核、调岗、孤立或威胁，记录时间、决定人和所给理由，不急着假定所有变化都已经被证明属于报复。可向妇联、工会和公共法律服务机构求助，依法也可向公安机关报案或提起民事诉讼。[\[WORK01\]](../SOURCES.md#source-work01) 内部投诉不要求你放弃外部救济。

对方提出和解、保密或离职协议时，把完整文本带去咨询，尤其看哪些权利被放弃、付款何时履行、违约条款是否对等。不要为换取“先看看证据”而签下自己不理解的最终结清声明。你可以请可信任的人陪同整理材料、就医或咨询，也可以按承受能力安排节奏；不把坚持到哪一步作为衡量受伤是否真实的标准。

<a id="work07"></a>

## 6.7 准备离职，把通知、交接和结算分别完成

离职前先确认原因：主动选择新工作、双方协商、公司提出解除，或因单位存在特定问题而解除。这不是措辞的小差别，可能影响程序和权利。不要把任何情形都套进网络上的“个人原因辞职信”。如果有欠薪、社保、逼迫离职或解除争议，先带事实材料确认适用路径，再决定通知怎么写。[\[WORK02\]](../SOURCES.md#source-work02)

<a id="work07-sub-01"></a>

### 普通主动离职，安排送达和最后工作日

一般情况下，劳动者提前三十日书面通知可解除劳动合同；试用期内提前三日通知。[\[WORK02\]](../SOURCES.md#source-work02) 这与请求单位同意缩短通知期不同。保存通知正文、发送或签收记录、对方回复和约定最后工作日。岗位涉及特殊约定或你希望立即离开时，需要核对适用情形；不要把“我已经发了一句不干了”当作所有义务都自动处理完毕。

可用的基础表达是：“本人现通知解除与\_\_\_\_单位的劳动合同，拟最后工作日为\_\_\_\_。请确认交接负责人、工资与报销结算安排，并依法办理离职证明等手续。”日期应按实际送达和适用规则确定。此模板仅适合普通主动离职，不用于代写因单位违法而解除的理由；后者的事实、证据及通知表达应单独咨询。

<a id="work07-sub-02"></a>

### 交接做成可以确认接收的清单

把进行中任务、到期事项、工作文件位置、设备和单位账号分别列明。设备写型号或编号、配件、状态和交还时间；工作资料按单位规定交付，不把私人账号密码混在其中。接收人不愿签字，可通过已确认的工作渠道发交接清单并请回复，保留实际移交证据。不要以扣住设备、删掉项目资料或停止必要交接作为催款方式。

原来以私人手机号注册的工作系统，提前联系单位和平台完成合法移交；个人照片、通讯与支付账户则按政策妥善解绑。离开前合法取得本人的合同、工资、缴费、通知及交接记录，避免账号关闭后无法取用。这里不授权复制客户库、商业秘密或与你争议无关的文件。

<a id="work07-sub-03"></a>

### 结算单逐项核对

请列最后一个工资周期、已确认未付绩效、报销、依法应处理的未休假期、经济补偿等适用项目，并写明支付日期和方式。哪些项目成立、基数怎样确定，取决于具体事实。若双方只确认部分金额，可以将已确认和仍有争议的部分分开写，不因为先领到一笔钱，就无意签下“全部权利已经结清”。

假设待付工资 4200 元、已审核报销 680 元，两项已确认合计 4880 元；另有 1000 元绩效争议。可写：“已确认款项 4880 元请于双方确定的日期支付；绩效 1000 元的条件与金额仍待核对。”这是虚构演示，不表示对方必须接受分项方案；如果提供的协议要求放弃一切请求，先判断你是否真的同意该整体交换。

<a id="work07-sub-04"></a>

### 对方不办手续或不付款时

劳动合同法对解除或终止证明、档案及社保关系转移等规定了单位义务。[\[WORK02\]](../SOURCES.md#source-work02) 你可书面列出未完成项目、已交接事项与所需文件，再向当地人社或法律服务渠道咨询。普通离职不应被拖成无期限等待。新单位需要说明时，只提供已核实事实与必要材料，避免仓促签不实的离职原因来换一张证明。

最后核对离职后的医保、收入和重要账单衔接，见“收入撑得住生活”。同意一个过渡时间表后也要看实际到账、记录更新与文件交付。把争议期限写进日历，结束工作账号不等于结束尚未完成的结算。

<a id="work08"></a>

## 6.8 遇到拖欠工资，先做金额表，再选处理渠道

欠薪最容易把人拖进反复催问：今天说财务不在，明天说客户没付款。先做一页可以反复使用的事实和金额表。写单位全称、实际工作地点、入职日期、工资约定、每月应发与实际支付、催问和承诺时间。公司经营困难的解释可以记录，但不能代替明确的付款安排。

<a id="work08-sub-01"></a>

### 金额按月份拆开，口径保持一致

下面是假设案例：六月应付劳动报酬按已核实口径为 7600 元，已付 5000 元，差额 2600 元；七月同口径应付 7600 元，已付 0 元，差额 7600 元，合计 10200 元。税前应发、税费代扣和实发必须分开核对，不能拿税前数直接减银行到账后把全部差额都称为欠薪。暂时拿不到明细时，标“暂计、待核对”。

| 月份（教学假设） | 同口径应付 | 已支付 | 待付差额 |
| --- | --- | --- | --- |
| 六月 | 7600元 | 5000元 | 2600元 |
| 七月 | 7600元 | 0元 | 7600元 |
| 合计 | 15200元 | 5000元 | 10200元 |

把劳动报酬与报销、借款、补偿等分项，附合同、工资条、银行流水和考勤等对应材料。某项只有口头约定，就如实说明何时、谁承诺以及还有什么旁证。不要为了凑足金额把无法证明的年终奖或精神损失一起写进工资差额。请求越清楚，后续咨询越容易判断每项是否适合该程序。

<a id="work08-sub-02"></a>

### 催告要有具体内容和下一个节点

可写：“截至\_\_\_\_，我核对\_\_\_\_月及\_\_\_\_月劳动报酬差额暂计\_\_\_\_元，计算见附件。请核对并说明具体支付日期；如认为金额有误，请逐项提供依据。”提出一个合理的回复时间，并保留送达；这个时间不是全国统一的法定催告期。对方愿意分期时，先确认总额、每期日期、支付主体和逾期后果，再评估自己是否能承受等待。

不要在工资未到账时签“已足额领取”，也不要因收到少量款项就删除原欠款记录。更新成“原差额\_\_\_\_，本次收到\_\_\_\_，尚余\_\_\_\_”。对方给现金时核对金额、凭证和对应月份；收款确认只写实际发生的事，谨慎处理附带的最终和解条款。

<a id="work08-sub-03"></a>

### 电话咨询以后，要确认是否已正式受理

向用工所在地等有管辖权的人社部门说明欠薪事实，询问劳动保障监察、调解、仲裁各自适用条件和材料。劳动争议调解仲裁法规定了欠薪等事项向劳动行政部门投诉的途径，也规定仲裁及后续救济。[\[WORK06\]](../SOURCES.md#source-work06) 不必为了“态度好”无限等待所有非正式协商完成，但要避免重复提交矛盾内容；记录每个渠道办理的事项和状态。

打电话问过政策、平台显示“已咨询”、工作人员口头说会看一看，都不等于正式立案。完成指定提交后保存回执、案件编号、补正要求和截止日期。单位名称写错、把老板个人当成所有请求的义务人，可能耽误处理；不确定时拿合同、登记信息和实际用工证据请受理机构指导。

<a id="work08-sub-04"></a>

### 眼下生活已经困难时，要说出具体影响

向咨询或承办人员说明是否已影响租金、医疗、基本生活，并询问是否有适用的法律援助、救助或程序安排。法律中的先予执行等措施有条件，不能承诺申请就马上拿钱。[\[WORK06\]](../SOURCES.md#source-work06) 同时把短期开支重新排序，与房东或账单机构协商自己能够兑现的安排。避免为了等工资继续借成本不清的贷款，也不要付费给声称“有内部关系保证追回”的人。

若公司关门、迁址或疑似转移财产，及时保存可合法取得的经营与联络变化信息并告知承办机构。现实威胁、拘禁等人身危险另行报警；单纯工资争议并不必然由报警即时解决。已经取得生效文书仍不履行时，继续询问执行程序，不能只把裁决书收好就认为款项会自动到账。

<a id="work09"></a>

## 6.9 准备劳动争议材料，先核对日期，再整理证据

咨询前先写一页事实概览，比发送几十张没有顺序的截图更省力。第一段写劳动关系和工作地点；第二段写争议起因及主要日期；第三段列具体请求和暂计金额；最后写已采取的行动、收到的文件及最紧迫的期限。长经历另附时间线，不要求自己一次写出专业法律文书。

<a id="work09-sub-01"></a>

### 不同请求，分别核对时效

劳动争议仲裁一般时效为一年，从知道或应当知道权利被侵害时起算。劳动关系存续期间追索拖欠劳动报酬有特别规则；劳动关系终止后，应在终止之日起一年内提出。依法还存在中断、中止等情形。[\[WORK06\]](../SOURCES.md#source-work06) 工资、解除、未签合同等不同请求不能全部套一个最晚日期；拿不准时，把全部时间点带到受理机构或律师处尽快确认。

“我一直和老板聊天”并不必然证明时效一直重新计算。保存你向谁、何时、就什么权利提出了什么要求，以及对方回应；再由专业人员判断是否满足相关条件。不要故意等到自己估计的最后一天才提交，补材料、管辖核实或系统故障都可能增加困难。临近期限时，优先询问正式申请所需的最低完整材料和办理方式。

<a id="work09-sub-02"></a>

### 证据按证明目的放，不按情绪强弱放

可以分四组：证明实际劳动关系的合同、安排与支付记录；证明收入的约定、工资明细和到账；证明工作及工时的考勤、排班和交付；证明争议的通知、沟通与处理结果。每份加编号、日期、来源和“想证明什么”。原件另存，只在副本上高亮或打注释；照片、聊天和电子文件保留完整上下文，不把剪辑后的拼图当成唯一原件。

例如“证据 03：七月工资条，拟证明应发项目；证据 04：七月至八月本人账户流水相关部分，拟证明实际支付情况”。提交时按机构要求处理无关隐私，保留能核验账户和交易的必要信息。不要为减少页数删掉影响意思的上下文，也不要把对方说过“会处理”直接改述为承认你提出的全部金额。

<a id="work09-sub-03"></a>

### 缺少单位掌握的材料，具体说出是什么

法律对由单位掌握管理、与争议有关的证据规定了提供义务及相应后果。[\[WORK06\]](../SOURCES.md#source-work06) 你仍应尽量说明材料名称、时间段、谁管理和证明目的，如“\_\_\_\_系统内本人\_\_\_\_月的考勤及加班审批”，而不是只写“请公司提供所有证据”。具体举证责任与是否作不利认定，由受理机构结合案件判断。

需要请律师或代理人时，核验身份，签明服务范围、收费、包含的程序和额外费用。一次咨询、代理仲裁、代理诉讼和执行可能是不同服务，不将“包赢”视为专业保证。符合条件者可咨询法律援助；劳动仲裁本身不收费，但交通、材料、误工和自行委托代理的费用仍要考虑。[\[WORK06\]](../SOURCES.md#source-work06)

<a id="work09-sub-04"></a>

### 收到文书后，看结果，也看后续期限

留存实际收到日期、文书全文及送达记录，读清补正、举证、开庭和救济告知。不同裁决类型、不同当事人的后续程序可能不同，不能只凭“仲裁已经赢了”忽视履行或起诉问题。不理解时当天整理问题咨询；不要把文书放进未读消息中，等一周后才打开。

协商和调解时确认究竟签的是一般和解协议、调解协议，还是具有相应效力的仲裁调解书，以及不履行后怎么办。若同意撤回申请，先理解撤回与付款、时效、再次申请的关系。完成一项行动就在事实表更新日期、联系人、结果与下一步，避免同一段经历因多次转述产生矛盾。

<a id="work10"></a>

## 6.10 把日常记录收成一份可接手的工作档案

这份档案不用记录每天所有对话。它的作用是让你换设备、离职或需要求助时，仍能找到自己的关键事实。可以用已有的本地文件夹和备份方式，不必购买所谓“维权神器”。按每段劳动关系建一个主文件夹，再按约定、月度记录、变更、离职或争议分开。

<a id="work10-sub-01"></a>

### 一个已经填写的例子

以下为虚构记录：“单位：甲公司；实际工作地：某市；到岗：某年 3 月 4 日；合同存于 01\_合同；固定税前工资 8000 元；绩效规则版本：某年 3 月版；工资核对日：每月到账后第一个周末；社保查询：本地官方渠道；未解决问题：七月绩效计算缺少明细。”这里的时间安排是个人习惯，不是法定核对频率。

当你要查询七月工资，就能先找到合同和绩效版本，再找当月工资条与银行流水；不需要从几年的微信里翻“月薪到底说了多少”。合同更新时保留旧版，并注明何时生效、谁确认。不要把新工资直接覆盖旧工资，否则之后难以说明变化发生在哪一个月。

<a id="work10-sub-02"></a>

### 下面这些字段，可以复制后填写

单位全称与联系地址：\_\_\_\_；实际工作地点与到岗日期：\_\_\_\_；岗位、工时制度及核对依据：\_\_\_\_；合同和附件存放处：\_\_\_\_；固定工资、浮动规则及发薪日：\_\_\_\_；参保单位和查询方式：\_\_\_\_；最近一次变更及生效日：\_\_\_\_；待解决问题及已提交材料：\_\_\_\_；下次跟进日期与承办人：\_\_\_\_。

发生争议时再增补：我的请求：\_\_\_\_；暂计金额和计算方法：\_\_\_\_；关键日期：\_\_\_\_；每项请求的对应证据编号：\_\_\_\_；时效咨询结果和咨询日期：\_\_\_\_；受理单位与编号：\_\_\_\_；下一份必须提交的材料及截止日期：\_\_\_\_。没有确认的地方写“待核对”，不要用空白或零元掩盖不确定性。

<a id="work10-sub-03"></a>

### 每次沟通结束，发一条简短确认

例如：“根据今天的沟通，我理解目前已确认\_\_\_\_，尚需你方核对\_\_\_\_，预计\_\_\_\_前回复。若我的理解有误，请指出。”对方回复后保留原始记录。对方不回复时，这条消息只能证明你发出了什么，不自动证明双方已经达成全部约定；不要在后续表格中擅自把它标成“公司承认”。

如果只有电话沟通，通话后及时写自己的备忘，注明“本人回忆记录”，再通过合适渠道核对关键内容。收到新材料时先检查是否改变原有判断，如金额已有部分支付、实际雇主与招聘主体不同、某项记录日期错误。修正事实有利于处理，不必为了维持早先叙述拒绝接受新证据。

<a id="work10-sub-04"></a>

### 找人协助时，先说你需要哪一小块帮助

可以请朋友陪你整理时间线、检查金额加总或陪同咨询，不要求对方立即判断谁违法。向专业人员提问可用三句话：“我在\_\_\_\_单位工作，发生\_\_\_\_；我希望解决\_\_\_\_；手上有\_\_\_\_，最急的是\_\_\_\_日期。”一次只推进几项关键问题，记录结论及仍需核实之处，下一次就能从这里继续。

档案中涉及薪酬、身份证明和健康资料，只向必要人员提供。重要密码、验证码和无关私人聊天不放进共享目录。关系或合作结束后检查共享权限，定期确认备份仍能打开。材料整理是为了保留选择，不必让它侵占全部休息时间；没有发生争议时，完成当月核对就可以把工作放下。
