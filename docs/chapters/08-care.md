# 08 未来有人照护

[← 上一章：关系与支持](07-relationships.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：日子过得有意思 →](09-everyday-life.md)

<a id="introduction"></a>

未来的照护安排，可以从一场短期住院、一次父母陪诊和一份资料索引开始。不必等到年纪很大，也不必一次解决所有问题。先知道需要哪种帮助、谁愿意做、费用从哪里来，以及原计划做不到时还有什么选择。

单身不等于没有亲人，也不等于默认由朋友承担长期责任。以下将生活协助、具体授权、成年人的监护、养老服务和身后财产分别处理。涉及医疗与法律的事项，需要把个人情况交给相应专业人员确认；本章的讨论表和话术是准备工具，不是可以直接签署的法律文件。

## 8.1 父母开始需要帮助时，先看一周里实际发生了什么

父母说“我都能行”，你却发现他们常常吃不上饭；或一次住院后，家里立即讨论谁辞职回去照顾。先把近期真正需要帮助的事项写下来，再谈居住方式和人手。一次生病不意味着此后所有事情都不能自主完成，也不意味着过去能完成的事现在依然安全、轻松。

<a id="care01-sub-01"></a>

### 从本人想保留的生活开始问

可以说：“我想先了解你现在最费力的三件事，看看哪些能帮上忙。你希望继续自己做什么？哪些帮助可以接受？”听清对住所、作息、饮食、来访人员和隐私的偏好。会使用手机不等于愿意被全天定位；愿意接受送餐也不等于同意搬家。安排服务前，让本人知道会有什么人来、做什么、费用怎样支付。

<a id="care01-sub-02"></a>

### 用事实记录，不在家自行打医疗分数

连续观察一段实际生活：吃饭是否需要准备或喂食，洗澡如厕是否需要帮助，起身和走动有没有困难，服药是否有漏服或重复，买菜和账单谁在处理，夜里是否经常需要人。记录发生时间、本人描述与已经提供的帮助。不要因为一次忘带钥匙就自行诊断认知障碍；新出现或加重的身体、记忆及情绪问题应及时就医评估。

假设母亲能自己洗漱、穿衣，却因关节问题很难上下楼，每周取药和买菜都需要帮忙。当前缺口可能是出行、采购和就医支持，未必需要立即全天陪护。另一位老人白天看似独立，但夜间频繁需要扶助，单纯增加一顿送餐也未必能覆盖关键需要。这里是虚构比较，作用是提示看具体任务，不能据此评定护理等级。

<a id="care01-sub-03"></a>

### 把医疗要求与日常协助分开

出院或复诊时，向医护确认哪些事项可由经过指导的家人完成，哪些需要专业人员、设备或再次就诊。记录频率、注意事项和异常时联系方式。不要把“有人陪着”当成能承担所有护理操作；未受训练者不凭视频尝试管路、伤口或其他专业处置。医疗判断参见“生病时有安排”，照护表只承接已经确认的实际任务。

把任务分成固定发生、临时发生、需要马上处理三类。固定任务可安排轮班和服务；临时任务如复诊，需要提前预约替补；急迫变化则按医护和急救安排行动，不等待家庭群投票。每次病情、居住地或人员变化后重新核对，不让几个月前的一张表长期替代本人现在的需要。

<a id="care01-sub-04"></a>

### 本人拒绝帮助时，先谈一个最小试用

询问拒绝的是费用、陌生人入户、失去自主，还是对服务不了解。可说：“我们先试一次有人陪你去复诊，只负责路上和取资料，其他决定仍由你来做。结束后你告诉我哪些有用。”能自主决定的人有权表达偏好，家人不应仅以“为你好”代替同意。出现明显无法保障安全或疑似能力受限的情况，寻求医务、社工和法律专业支持，而不是由子女自行宣布接管全部生活。

记录最后保留两列：“本人希望”和“仍未覆盖的帮助”。它们可能暂时有冲突，不必在一次谈话中解决。下一步先选择一个本人能接受、能实际执行的安排，再观察是否减轻困难；不要为了让表格看起来完成，就把没有人承诺的任务填上某个家人的名字。

<a id="care02"></a>

## 8.2 家庭分工要写到事项、时段、费用和替补

“你离得近，多照顾一点”“你还单身，时间比较自由”，都不能说明一周究竟由谁做什么。讨论分工前，各自写出能够稳定承担的时段、费用和远程任务，同时列明不能承诺的部分。照护需要持续，靠某个人短期超负荷撑住，并不等于已经有了长期方案。

<a id="care02-sub-01"></a>

### 开一次只解决实际安排的家庭会议

先确认老人愿意如何生活，再按任务分人：陪诊、接送、买菜、夜间联络、费用核对、联系服务机构。远方家人也可承担预约、比较服务、整理账目和固定费用，不能把“我不在当地”直接等同于没有可承担的事。每项写负责人、完成时间、无法执行时提前通知谁，以及替补是谁。

| 事项 | 负责人及时间 | 替补与确认方式 |
| --- | --- | --- |
| 复诊接送 | \_\_\_\_；\_\_\_\_日\_\_\_\_时 | 不能到场时由\_\_\_\_在\_\_\_\_前确认 |
| 日常送餐或采购 | \_\_\_\_；频率\_\_\_\_ | 服务停止联系\_\_\_\_ |
| 费用与凭证 | \_\_\_\_；每月\_\_\_\_核对 | 异常款项经\_\_\_\_复核 |
| 夜间必要联络 | \_\_\_\_；可联络时段\_\_\_\_ | 联系不到转\_\_\_\_；紧急情况按急救流程 |

例如可说：“我能承担周三晚间送药和每月一次陪诊，工作日白天不能持续请假。周一复诊由谁到场？若没人能去，我们需要询问陪诊服务，并确认其职责和费用。”把可做和不能做同时说清，避免先答应“都交给我”再靠争吵撤回。家人不同意时，要求具体补足任务，而不是继续讨论谁更孝顺。

依法负有赡养义务的人应履行相应责任；不能亲自照料时，可以按老人意愿委托他人或机构照料。经老人同意，赡养人之间可以依法订立分工协议。[\[CARE01\]](../SOURCES.md#source-care01) 家庭表格不能免除法定义务，也不能用“我以后不继承”作为拒绝赡养的理由。实际分担方式及争议仍须结合个人情况处理。

<a id="care02-sub-02"></a>

### 费用先算缺口，再谈分担比例

下面是虚构月度预算，不代表服务市场价：基本生活 2200 元、日间协助 2400 元、复诊交通 400 元，共 5000 元。老人明确愿意且能够用于这部分支出的收入为 3200 元，则常规缺口为 1800 元。若两位家人协商分别承担 1000 元和 800 元，刚好补齐；这只是约定例子，不是法定比例。突发医疗和临时增加照护另作预案，不能假定全部包含在这 5000 元里。

核对资金时尊重老人的财产权，先征得其对用途和支付方式的同意。不要因负责陪诊就擅自把存款转到自己账户，也不要要求老人先赠与房产才能获得照护。现金垫付写日期、用途、金额、付款人和凭证，约定何时对账。若有人同时管理资金和购买服务，增加另一位经同意的核对人，帮助减少误解。

<a id="care02-sub-03"></a>

### 分工失效时，启动替补，不靠忍到爆发

出现连续夜间照护、照护者生病、工作变化或服务人员请假时，明确哪一项任务今天会无人完成。先补缺口，再讨论长期调整。可以说：“原安排本周已无法执行，今天的\_\_\_\_需要\_\_\_\_接手；如果没人可接，我们共同确认临时服务及费用。下周重新讨论轮班。”替补和付费服务也必须有人实际联系并确认，不能只写“必要时找护工”。

如果家人长期拒绝沟通，保留实际支出、照护经过和你的合理请求，可向社区、社工、妇联或公共法律服务渠道咨询协调及依法履责问题。存在暴力、经济控制或严重旧有冲突时，不要求你独自把所有人劝好；先保障安全与基本照护，再寻求外部帮助。家庭会议的目标是让具体事项有人负责，不是评选谁最有牺牲精神。

<a id="care03"></a>

## 8.3 自己短期生病时，准备能维持几天的生活支持

安排照护不一定要从养老机构开始。一次门诊处置、发热卧床或腿脚受伤，都可能让独居者发现：外卖可以解决一顿饭，却不能自动解决取药、下楼和照顾孩子。先按医生已经说明的需要，把未来几天必须完成的事情拆开，看看哪些能自己做、哪些可以远程完成、哪些确实需要有人到场。

<a id="care03-sub-01"></a>

### 预约治疗前，问清支持要求

向就诊机构询问是否需要接送、陪同、留观或居家观察，预计哪些活动会受到限制，出现哪些情况应联系医院或急救。接受治疗后的要求随项目和个人状况不同，不能用“一般都能自己回家”作决定。若需要符合特定要求的陪同者，提前确认朋友或购买的服务能否满足机构要求；不要治疗当天才发现对方只能在门口等。

<a id="care03-sub-02"></a>

### 先列生活缺口，再邀请具体帮助

可以问朋友：“周五下午我需要从医院回家，医院要求\_\_\_\_。你愿意在\_\_\_\_时陪同吗？如果不方便，我会安排其他服务。”另一位朋友可只负责第二天送一次饭；并不是每个人都要承担连续几晚。说明结束时间、花费如何处理及备用方案，允许对方拒绝，才能判断哪些支持是真的落实了。

假设医生预计你两天内不宜搬重物，但可以正常沟通和支付。提前把饮水、简单食物和常用物品放到方便取用的位置，安排送货与必要接送；你仍然自己作决定。需要协助照顾孩子、其他被照护者或宠物的，另列具体人选和交接，不把“朋友会来看我”理解为对方同时接管整个家庭。

<a id="care03-sub-03"></a>

### 把联络安排说到“未回应以后怎么办”

与自愿的联系人约定一个与你的病情、生活习惯相符的联系时间，以及未回应时先拨电话、联系替补还是按已知风险求助。不要一概把晚回消息当成紧急事故，也不要让对方以为“没有回我就是在睡觉”。住址、楼栋和必要进门安排应能找到；钥匙如何保管须双方同意，不在群里公开门锁密码。

紧急联系人仅是被联系的人，不会因此自动取得医疗决定、银行取款或财产处置权限。[\[CARE02\]](../SOURCES.md#source-care02) 需要朋友代办具体手续时，提前向接收机构问授权形式与证件要求。你仍能理解、表达和决定时，应由你参与自己的医疗和生活安排；身体行动不便不等于民事行为能力受限。

<a id="care03-sub-04"></a>

### 没有合适朋友时，从小额服务组合开始查

可以先向医院服务台、医务社工或当地社区询问陪护、陪诊、送餐、家政和临时照料有哪些正规资源，以及服务对象和条件。不要预设社区一定免费提供，也不要把平台上自称“专业陪护”的介绍直接当作资格。先确认服务主体、人员身份、具体任务、时间、费用和取消规则；医疗操作须由具备相应资格的人按规定完成。

对方临时不能来时，先联系预设替补或服务方，重新核对最关键的接送与照护。若治疗安排必须有人配合却未落实，主动联系医疗机构讨论可行安排，不隐瞒独自回家的事实。已经出现急症或现实危险时按急救流程处理，不等待朋友下班。支持计划中最有用的一行，往往是“这个人做不到时，下一步联系谁”。

恢复后与帮忙的人确认费用、物品和权限，归还借用物品，结束不再需要的定位或账号分享。把这次真正用到的联系方式留下，下次只需更新。一次得到帮助并不会产生无限的人情债，清楚地感谢、结算和结束安排，能让以后再次求助更自然。

## 8.4 联系人、委托代理和监护，分别解决不同问题

“以后我有事就找她”是一种信任表达，却还没有说明她可以做什么。想让朋友帮助接电话、领取报告、支付某项费用，或在你无法作决定时承担更长期职责，所需安排可能完全不同。先写具体任务，再去问接受文件的机构需要什么材料，避免签了一个很宽泛的“全权授权”却到处用不上。

<a id="care04-sub-01"></a>

### 联系人先解决通知与联络

| 安排 | 主要解决什么 | 不自动产生什么 |
| --- | --- | --- |
| 紧急联系人 | 接收通知、协助联络 | 监护权、取款权、全部医疗代签权 |
| 具体委托代理 | 在明确事项与权限内代办 | 超出授权的任意处置权 |
| 意定监护 | 达到法定启动条件后的监护职责 | 签署即全面接管、任意赠与财产 |
| 照护服务协议 | 约定生活或专业服务 | 当然的监护身份或继承权 |

登记前征得对方同意，说明哪些机构可能联系她、能联系的时段、备用人选和可以获知的信息。手机号改变后同步更新。联系人可转告病情、联系其他支持者或到场协助，但“紧急联系人”这个名称本身不会让她成为你的监护人，也不会自动产生代签全部医疗文件或处置资产的权利。

<a id="care04-sub-02"></a>

### 具体代理，要按事项限定权限

假设你住院期间需要朋友领取一份资料，先问保管机构：本人能否线上办理，若代办需什么授权、身份证明和原件。书面授权应写清代理人、代理事项、权限、期限，并由本人签名或盖章。[\[CARE02\]](../SOURCES.md#source-care02) 尽量与实际任务相称，说明是否允许转委托、是否涉及付款或签署文件；这里提供的是核对方向，不是一份通用有效模板。

可询问：“我希望由\_\_\_\_在\_\_\_\_期间代办\_\_\_\_，不包括\_\_\_\_。请确认贵机构接受的授权格式、身份核验及原件要求。”例如代取材料并不需要把全部银行账户和密码交给对方。机构不接受你自己写的格式时，索取其要求并核对是否超出所需权限；不明白的条款先咨询，不为图快签下范围无边界的文件。

<a id="care04-sub-03"></a>

### 意定监护是提前安排未来的职责

民法典允许具有完全民事行为能力的成年人，与愿意担任的个人或组织事先协商，以书面形式确定监护人，在自己丧失或者部分丧失民事行为能力时履行监护职责。[\[CARE02\]](../SOURCES.md#source-care02) 它不是从签字当天起自动让对方接管你的一切，也不是只要你住院、骨折或行动困难就自动启动。是否达到条件、如何证明与履行，应事先向专业人员问清。

民法典第三十三条要求书面形式，并没有把公证统一规定为所有此类安排的成立条件。[\[CARE02\]](../SOURCES.md#source-care02) 公证、律师协助或相关机构服务的作用、费用与办理条件应分别核实。不要因为看到别人办了某个版本，就以为所有医院、银行和服务机构都会不经核验直接接受；法律效力与具体业务办理仍有需要衔接的地方。

<a id="care04-sub-04"></a>

### 医疗决定也要单独确认

诊疗中的说明、同意以及紧急救治，受相应医疗法律规则约束。民法典对患者明确同意、特定情形下近亲属意见及紧急处置作有规定。[\[CARE02\]](../SOURCES.md#source-care02) 不能把“没有配偶”理解为不能治疗，也不能保证普通朋友凭一张联系人登记表就能代作所有决定。计划治疗前向医院说明真实支持情况，让所需手续提前变得可执行。

如果候选人不愿承担，感谢对方说明边界，改为她能承担的具体协助，另寻其他方案。没有适合的监护候选人时，可以先完成资料索引、短期支持和专业咨询；不要因焦虑把重大财产权限交给刚认识的人。重要文件要有人知道存放处，但完整证件、资产细节和密码不必人人共享。

<a id="care05"></a>

## 8.5 讨论长期监护与照护意愿，把监督和退出也写进去

愿意担任未来监护人，不等于已经准备好承担所有事务。讨论时可以先用具体情境试一试：需要持续支付照护费时谁整理账目？候选人搬去外地怎么办？两个人对住所和花费意见不一致时如何处理？越早发现能力与期待的差异，越容易调整，不必把询问这些问题理解成不信任。

<a id="care05-sub-01"></a>

### 选人时同时看意愿、能力和持续性

询问对方愿意承担哪些职责，是否能与医疗、银行和服务机构沟通，是否能保管和整理资料，出现利益冲突时如何处理。关系亲近很重要，但不是唯一条件。一个平日不愿讨论钱、经常失联或正在依赖你经济支持的人，未必适合管理重大财产；这需要具体评估，不必给对方贴道德标签。

如果考虑由组织提供相关服务，核对合法身份、实际承办人员、服务边界、费用、监督方式、投诉渠道及退出安排。宣传中的“养老管家”“终身托付”不等于特定法律资格或责任已经落实。先拿完整协议请独立专业人员审阅，不在营销活动现场一次性交出原始证件、房产资料或大额预付费用。

<a id="care05-sub-02"></a>

### 把希望怎样被照护说成可讨论的偏好

可以先写：希望优先考虑的居住地点、能接受的照护方式、日常作息、饮食和交流习惯、哪些亲友可获知情况，以及最希望保留的自主活动。标明哪些是强烈偏好，哪些可在医疗或现实条件变化时重新评估。照护偏好记录帮助他人理解你，不等于一份能够在任何情形下替代医疗决定或法律程序的文件。

民法典要求监护人依最有利于被监护人的原则履职，并最大程度尊重成年被监护人的真实意愿；对其能够独立处理的事务，不得干涉。[\[CARE02\]](../SOURCES.md#source-care02) 所以提前安排不是让以后“省事”的人任意决定，而是让你在能力变化时仍尽可能被听见。能表达时继续参与，不将年龄大、说话慢或不熟悉手机自动视为没有决定能力。

<a id="care05-sub-03"></a>

### 钱的管理需要可核对的流程

与专业人员讨论日常支出如何留凭证、大额事项如何审查、财产与个人账户如何区分、谁可在合法授权或监护范围内查看账目。可考虑由不同的人承担日常协助与定期核对，但具体权限必须合法明确，不能简单在家庭群写一句“互相监督”就认为已经有效。监护人处分财产受到法定职责限制，不因承担照护就可以把钱转成自己的财产。

假设安排中写“每月由\_\_\_\_向有相应权限的\_\_\_\_提供照护支出摘要，异常支出说明原因”，这是咨询时的讨论题，不是可直接照抄的法律条款。要进一步确认哪些信息可以披露、谁有权提出异议、紧急费用如何处理，以及候选人本人也是服务提供者或受赠人时怎样处理利益冲突。

<a id="care05-sub-04"></a>

### 提前问清不能继续履职时怎么办

候选人自己生病、迁居、关系变化或机构停止服务，都可能使原安排失效。把变更、解除、替补、文件交还和通知有关机构的流程带给律师或公证机构核对。并非所有个人设想都能仅靠一纸协议实现；尤其启动条件、争议处理和监护人变更，需要遵守法定规则，不能自行宣布生效。

每当发生重要变化，回看一次：人是否仍愿意，联系方式是否有效，资金和照护偏好是否改变，旧文件是否应更新。复核频率可按个人情况约定，不是法律统一规定的每年任务。平时把最终文件与讨论草稿分开存，告诉相关人哪一份是现行版本，避免未来翻出多份互相矛盾的文件。

<a id="care06"></a>

## 8.6 比较居家、社区与机构，先看它能接住哪些需要

“在家最自在”和“住机构最省心”都可能只说对了一半。选择应从实际照护缺口开始：白天有没有人、夜间是否需要协助、能否安全出门、医疗需求怎样衔接、本人愿不愿意，以及总费用能否持续。居家服务、社区支持与机构也可以组合，并非选一次以后永远不能调整。

<a id="care06-sub-01"></a>

### 为每种方案写出一天如何运转

居家方案要写送餐、清洁、洗浴协助、外出和夜间联络分别由谁承担；社区服务要确认开放时间、接送和服务对象；机构方案要问护理等级、可承担与不能承担的状况、夜班人员和转诊安排。能提供“康养”活动不等于有相应医疗能力，附近有医院也不等于夜间一定有人陪同转运。

假设某人白天需要两次生活协助、夜间暂不需要固定护理，可比较居家服务的两次到访加家人联络，与机构的整月照护。若之后需要频繁夜间帮助，原居家方案的可行性可能变化；应重新问服务方和医护，而不是只看月费是否仍比机构便宜。照护需求判断应结合专业评估，家属不能靠预算倒推“她应该还能自理”。

<a id="care06-sub-02"></a>

### 参观时让对方演示真实流程

先核对登记及备案信息、实际服务地址、经营主体与投诉渠道；有关信息可向所在地民政部门核实。养老机构的设立登记与备案各有规则，不宜只问有没有旧称的“养老许可证”。[\[CARE03\]](../SOURCES.md#source-care03) 证照和备案有助于核验身份，却不是所有服务质量和财务风险都已被保证的证明。

带着三种情境去问：“半夜需要如厕协助如何呼叫？”“老人突然不舒服时由谁判断、联系急救和通知联系人？”“现在的护理需要增加时怎样评估、谁解释费用？”观察工作人员是否能清楚回答，看实际房间、卫生间、活动区域和呼叫设备，而非只看样板间。尊重其他住户隐私，不擅自拍摄其病情或床位生活。

<a id="care06-sub-03"></a>

### 听介绍时追问具体服务，而非笼统等级

“二级护理”“全护理”等名称不一定在不同机构间完全对应。请列到日常协助项目、频率、夜间安排、哪些另收费、哪些不能承接。养老机构应建立入院评估，依据结果确定护理等级；情况变化需要重评，确定或变更等级应经老人或其代理人同意。[\[CARE03\]](../SOURCES.md#source-care03) 要求了解结果与调整理由，不能只接受每月费用突然增加。

试住可帮助了解作息、饮食和实际响应，但先核对是否提供试住、期间怎么收费、提前结束和转正式入住怎么办。与本人约定试住后讨论的几个问题：是否愿意留下、睡眠和饮食如何、需要帮助时能否获得响应、哪些隐私和习惯受到影响。试住不是保证未来所有班次与服务始终相同，入住后仍需持续沟通。

<a id="care06-sub-04"></a>

### 对方回避问题时，先把缺口列出来

若只回答“放心，我们专业”，可请其提供服务清单、协议和负责人员说明。关键照护需求不能确认，就不要仅为床位优惠匆忙付款。可以缩小候选范围、再看另一家，或先采用能覆盖当前需求的临时组合。已经发生明显照护失当或现实安全风险时，及时记录并向负责人、民政等相应渠道反映，紧急医疗情况先求助，不能等参观比较结束。

把最后选择写成一句理由：“这个方案目前覆盖\_\_\_\_，尚未覆盖\_\_\_\_，由\_\_\_\_补充，费用可维持到\_\_\_\_，遇到\_\_\_\_变化重新评估。”这样之后需要转换时，知道是哪一个条件改变，而不是把搬去机构或重新回家看成一次失败。

<a id="care07"></a>

## 8.7 养老协议与总费用，签之前先走一遍退出过程

看中一个方案后，先拿完整协议与收费清单回去阅读。签约主体、服务地点和收款方应能对应；品牌相同不意味着每家机构都由同一个法人承担责任。签署人是老人本人还是有相应权限的代理人，也要明确。不要让普通紧急联系人在不理解后果时顺手签成付款保证人。

<a id="care07-sub-01"></a>

### 先核对服务，再核对钱

列明房型、护理等级、具体照护项目、餐食、清洁、生活耗材、医疗与转诊、探访和隐私安排。费用逐项说明哪些包含在月费、哪些按实际发生，涨价或护理变化时如何通知和确认。养老机构管理办法要求服务协议明确照护等级、服务内容、收费、期限、解除及停止服务时的安置等事项。[\[CARE03\]](../SOURCES.md#source-care03)

下面是假设月度账，不是市场报价：床位与基础服务 2800 元、照护 2000 元、餐费 900 元，固定合计 5700 元；按实际发生估计耗材 250 元、陪诊交通 300 元，总预算约 6250 元。医疗费未包含，未来增加护理也未包含。与另一家“全包 6000 元”比较时，先问全包具体覆盖什么，不能只凭数字更小就下结论。

| 月度项目（教学假设） | 金额 | 需另问的内容 |
| --- | --- | --- |
| 床位与基础服务 | 2800元 | 具体包含项目 |
| 照护 | 2000元 | 评估及变化后的收费 |
| 餐费 | 900元 | 特殊饮食安排 |
| 耗材与陪诊交通估计 | 550元 | 按实际发生核对 |
| 合计预算 | 6250元 | 不含医疗及未来护理增加 |

如果还有一次性购置、押金和预付费，另列首次所需现金，不与月度支出混在一起。月费承担得起但预付后无法支付医疗和日常费用，也会造成困难。以本人可自由使用的资金核算，不把尚未得到同意的家人资助或尚未卖出的资产算成现钱。

<a id="care07-sub-02"></a>

### 用四种离开情形检查合同

请对方逐一说明：尚未入住想取消；试住后不合适；入住后因就医或照护需要变化而离开；机构停业、搬迁或不能继续提供所需服务。每种情形问谁通知谁、需要什么材料、费用如何结算、退还到哪里、什么时候到账，以及人和物品如何安全转移。把答案落在协议或可确认的书面补充里，不只听销售承诺。

可以问：“如果入住后需要贵机构无法提供的照护，何时告知我们？过渡期间由谁协助，房费和预付余额怎么结算？”另一句是：“请展示一份退费计算样例，注明已消费金额、合理扣费依据和剩余款项。”用虚构数字演算比“随时可以退”更容易看出问题，但最终仍要看实际合同和法律规定。

<a id="care07-sub-03"></a>

### 注意签字旁边的责任说明

“家属签字”可能被用于信息确认，也可能附带保证付款、赔偿或放弃责任等内容。逐项阅读，询问自己究竟以什么身份签署、承担多大范围和多久的责任。有争议或大额义务时让专业人员审阅。本人具有相应决定能力时，应让其直接参与，不能只因年龄或单身就让别人包办签约。

入住当天按清单交接物品、药品和已经确认的医嘱信息，核对联系人与异常通知方式。药物使用和管理要按医护及机构规范，不把一大袋混杂药物交给接待人员就算完成交接。个人贵重物品、证件、现金如需保管，写明数量、保管责任、领取与返还办法，索取凭证。

机构要求当场交钱才给看完整协议，或承诺与文本明显冲突时，先停止付款并核实。签约后发生分歧，保留协议版本、宣传承诺、费用明细、服务记录和书面沟通，提出明确整改或退费请求。协商不成可向所在地民政等相关渠道咨询；不同事项的处理路径与条件不同，不保证一次投诉即可解决全部合同争议。

<a id="care08"></a>

## 8.8 预付费优惠出现时，先算资金被占用的后果

一次预交一年、买会员卡享受优惠，可能让眼前月费显得更低。你需要同时问两个问题：这笔钱买到哪些确定服务；如果自己改变计划或机构无法履行，钱能怎样回来。服务机构的风险不能只靠家人“看起来很正规”的印象判断，也不能把银行存管四个字理解成所有款项都有人兜底。

<a id="care08-sub-01"></a>

### 先把收费名称翻译成实际用途

询问是养老服务费、押金，还是用于获取服务资格或优惠的会员费，各自金额、用途、保存方式和退费条件。要求与服务协议、公示标准和支付凭证对应。2024 年有关指导意见对预收费的收取、管理、使用与退费作了规定，并要求地方细化落实；不同收费项目不能仅靠换一个名称规避相应规则。[\[CARE04\]](../SOURCES.md#source-care04)

政策鼓励按月收费；具体采用预收费时仍要核对适用要求与所在地细则。不要因为别人曾经交过很大一笔，就认为本机构本方案同样合规。可以向监管民政部门询问其报送、公示和本地管理要求，再决定是否支付。对自己无法解释的费用，先请机构书面说明，而不是由销售在转账后补答案。

<a id="care08-sub-02"></a>

### 用一个假设比较看清优惠和占用

假设按月收费 6000 元，一年为 72000 元；预交一年享九五折，需一次支付 68400 元，名义节省 3600 元。省下的钱与一次拿出去的 68400 元同时存在。若三个月后需要搬离，不能自行按“没住九个月”猜返款数，应先看合法有效的协议与适用退费规则，要求对方演算并解释扣费依据。

再做一个更现实的问题：“交完后，我还有多少可动用资金支付医疗、转移住宿和日常生活？若退款延迟，我能维持多久？”把已锁定、存在变现限制或他人尚未同意提供的钱排除。可以选择金额更小、周期更短的方案；如果机构只提供高额预付，也可继续比较其他服务，不把限时优惠当成必须立刻决定的理由。

<a id="care08-sub-03"></a>

### 存管要核对账户和责任

2025 年存管工作指引进一步规定押金、会员费的专用账户及相关收退流程，并明确存管银行不对养老机构行为提供担保或信用背书。[\[CARE05\]](../SOURCES.md#source-care05) 因此应核对开户主体、收款信息和相关协议，避免把钱交给工作人员个人账号；但即使有真实存管，也不意味着照护质量、账户余额或退费纠纷都会由银行赔付。

对方说“某银行合作，绝对安全”时，可问：“银行实际承担哪一种职责？请提供与本笔收费有关的存管信息，说明账户、款项用途及退费流程。”自己通过已经核实的机构渠道核对，不只拨营销人员临时提供的电话号码。不向任何人提供支付验证码或让其远程操作个人账户。

<a id="care08-sub-04"></a>

### 退费时按金额、条件和流程提出请求

准备协议、发票或其他合法凭证、付款记录、服务起止日期、解除通知及费用计算，说明申请退哪一笔、原因与依据。指导意见对未入住和已入住后的退费分别作有规定，也限制不合理退费条款和以投资回报诱导预付。[\[CARE04\]](../SOURCES.md#source-care04) 争议金额和合同效力仍须依法判断，不把销售的“原则上能退”当成已获得确定返款。

如果对方以换新卡、再交一笔保证金或拉人购买作为退费前提，先停止新增付款，保存完整沟通并向相关监管或法律服务渠道求助。发现停业迹象时，除了追款，还要优先安排正在入住者的安全和连续照护。资金风险处理与服务转移可以并行，不能因为还在谈退费就让人留在已经无法提供必要服务的地方。

<a id="care09"></a>

## 8.9 财产与遗嘱，先确定自己真正拥有和想安排的是什么

谈身后安排，先从清单开始，不必先找一张“万能遗嘱模板”。写资产类别、权利归属、相关负债、证明文件在哪里，以及希望如何处理。房子有共有权人、账户里有代别人保管的钱、借款尚未还清，这些都会影响可处分的范围。不能只按银行卡余额或房产总价估计“全部遗产”。

<a id="care09-sub-01"></a>

### 把事实、意愿和法律文件分成三层

事实层记录房屋、存款、投资、保险、对外债权、借款和担保等，标明归属与凭证位置；意愿层写希望照顾谁、赠与谁、谁愿意协助执行；法律层再由专业人员帮助选择相应安排。保险受益人、共有财产份额和遗产处分不宜一概混在一起，应查看具体文件并咨询适用规则。

举一个虚构例子：你与他人共有一套房屋，不能因为自己居住其中，就把整套房都写成可单独处分。你借给朋友的款项，也需要合同、转账和还款记录说明，而不是只在清单中写“她欠我钱”。债务同样应如实列出，避免留下财产索引却隐去负担，让后续处理者误判实际情况。

<a id="care09-sub-02"></a>

### 未婚不代表没有法定继承人

民法典规定了法定继承顺序，第一顺序包括配偶、子女、父母，第二顺序包括兄弟姐妹、祖父母、外祖父母；具体还涉及适用条件、代位继承和其他规则。[\[CARE02\]](../SOURCES.md#source-care02) 因此“我没有配偶，所以一切自动归最好的朋友”不是可靠判断。希望财产给朋友或其他人，需要依法作出相应安排。

给法定继承人以外的人安排财产，可能涉及遗赠；民法典规定受遗赠人应在知道受遗赠后六十日内作出接受或放弃的表示，期满未表示视为放弃。[\[CARE02\]](../SOURCES.md#source-care02) 咨询时说明受益人的关系、联系方式和是否知道安排，问清怎样通知、如何留存表示以及期限如何认定；不要把文件藏得无人知道，又期待对方自然取得财产。

<a id="care09-sub-03"></a>

### 遗嘱形式不同，要求也不同

自书、代书、打印、录音录像和公证等形式有各自法定要求，见证人资格也有约束。[\[CARE02\]](../SOURCES.md#source-care02) 不能认为“手机打字后自己签一下”就等同于自书遗嘱，也不要请受益人随便当见证人。这里不提供可直接签署的完整模板，以免忽略能力、财产权属、必要保留份额及形式要求等关键条件。

最常混淆的是自书与打印：自书须本人亲笔书写、签名并注明年月日；打印遗嘱须有两个以上见证人在场，遗嘱人和见证人在每一页签名并注明年月日。继承人、受遗赠人以及与他们有利害关系的人等，不能担任见证人。[\[CARE02\]](../SOURCES.md#source-care02) 这些只是形式核对点，满足形式也不意味着其他效力条件当然满足；实际制作前仍需核对个人情况。

准备咨询时，带身份证明、家庭关系情况、主要财产与负债清单、已有遗嘱或赠与协议，以及你希望实现的安排。请专业人员解释哪种形式适合、如何保管、谁知道文件存在、怎样更新、是否需要执行人，以及执行人愿意承担什么职责。没有大额财产也可以整理，目的在于减少寻找和误解，不是达到某个资产门槛才有资格规划。

<a id="care09-sub-04"></a>

### 生活改变后，让文件保持一致

婚姻、子女、重要亲属情况、资产或意愿变化后，复核已有文件。修改遗嘱有相应规则，不在原件边角随手改几字就假定全部生效；多个版本的关系应请专业人员说明。把现行原件、旧版本和讨论草稿分开保管，并给可信任且适合的人留存放索引，不必公开全部分配细节。

别人催你转房、赠与或立遗嘱，尤其提出“先把财产给我才照顾你”时，先停下并寻求独立咨询。照护服务、监护职责与继承利益可以存在复杂联系，不能只凭亲近关系放弃核对。你能够自主决定时，可以重新考虑自己的安排；保护意愿也包括保留足够资金支持自己现在和未来的生活。

<a id="care10"></a>

## 8.10 留一份能找到资料的索引，做一次实际演练

完整安排不是把所有密码打印成一张纸交出去，而是让适当的人在需要时知道找什么、去哪里找、凭什么权限办理。先整理最关键的资料：身份与联系方式、就医和保险信息、照护偏好、代理或监护文件、财产负债索引、遗嘱存放线索，以及仍需支付的生活账单。

<a id="care10-sub-01"></a>

### 索引写位置和用途，秘密另行保护

例如可写：“常用医疗资料：家中\_\_\_\_文件夹；近期用药单：\_\_\_\_，更新于\_\_\_\_；正式委托文件：\_\_\_\_；房屋与贷款资料：\_\_\_\_；本人同意的联系人：\_\_\_\_；仍待核对：\_\_\_\_。”共享给接送朋友的版本可以只有医院、时间和联络方式；负责特定事务且有相应权限的人才获得完成任务所需的信息，不把完整资产清单转发给所有热心帮忙的人。

数字资料也分开看：照片和作品可以安排备份；账户内财产、收益、订阅和平台身份可能适用不同规则；账号本身与其中可继承的权益也不必然相同。民法典承认对数据、网络虚拟财产按相关规定保护，但具体平台操作和权利处理仍须逐项核实。[\[CARE02\]](../SOURCES.md#source-care02) 不把一份账号密码表描述成必然有效的“数字遗产继承方案”。

<a id="care10-sub-02"></a>

### 先查平台提供什么正式路径

在确有需要的平台查看官方帮助中是否有联系人、资料导出、身后处理或账户关闭流程，记录申请主体与材料。规则会变化，真正使用前再核实。不要要求朋友在你失去能力或去世后直接冒用你的身份、绕过验证或使用验证码登录金融账户。权限、证明与平台流程不能用“我以前把密码告诉过她”代替。

以下是一份可复制的索引骨架：本人姓名与必要身份核验资料位置：\_\_\_\_；紧急联系人及替补、已同意范围：\_\_\_\_；常用医院与医疗资料位置：\_\_\_\_；短期照护方案及服务电话：\_\_\_\_；代理、监护或其他正式文件位置：\_\_\_\_；财产与债务清单位置：\_\_\_\_；遗嘱等原件线索：\_\_\_\_；孩子、其他被照护者或宠物的临时安排：\_\_\_\_；最后更新日期：\_\_\_\_。

<a id="care10-sub-03"></a>

### 用一次假设情境检查它能不能用

与已同意的联系人约一个短时间，假设你临时住院、能沟通但无法回家。请对方只按索引回答：先联系谁，如何知道医院与住址，哪项日常事情需要接手，哪里能找到合法代办所需材料。无需真的登录账户或动用钱。找不到的内容当场补齐，权限不清的列为待咨询，而不是让朋友凭猜测处理。

再换一个情境：主要联系人这周出差，服务机构临时取消预约。看看替补是否真实存在、是否知道自己被列入、联系方式是否可用。若没有替补，就明确写“未落实”，优先补上最影响安全和基本生活的一项。安排不完整并不意味着你失败；把缺口写明，才有可能下一次解决。

<a id="care10-sub-04"></a>

### 只有自己一个人，也可以先完成最有用的部分

先整理资料位置、核实常用机构办理要求、保存社区和正规服务资源，不为凑满表格写入关系不可靠的人。没有人能承担某项长期职责时，向当地民政、社区、法律服务或相应专业机构咨询可行路径、条件和费用；不要承诺某个部门会在任何情形下自动接管全部生活。

每次真正使用后更新失效号码、已结束授权和旧服务合同，撤销不再必要的共享权限。文件保管方式要考虑遗失、设备损坏和他人未经同意访问，备份后实际试着打开一次。最后留下一个很小的下次行动，例如“向医院问清朋友代领材料要求”或“与候选人讨论愿意承担的范围”，让未来安排能逐步落地。
