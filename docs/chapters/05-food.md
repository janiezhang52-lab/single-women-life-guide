# 05 一个人也要吃好

[← 上一章：身体由自己照顾](04-health.md) · [总目录](../CONTENTS.md) · [来源与核实日期](../SOURCES.md) · [下一章：工作中的权益 →](06-work.md)

<a id="introduction"></a>

这一章从日常配餐开始，给出八份一人食，连同买菜、准备、烹调、保存、外卖和费用计算一起安排。关注蛋白质，是为了避免经常只吃零食、主食或一盘菜；主食、蔬果和适量脂肪同样需要。

食谱面向一般健康、非孕哺期成年女性。菜量可按食欲和活动调整；营养数值按主要食材估算，时间为步骤估计，尚未经过厨房实测。疾病、孕哺期或已有营养治疗方案时，不能直接套用本章的统一安排。

## 5.1 吃够蛋白质也要把整顿饭吃好

先选蛋白质来源：鸡蛋、奶、豆腐、鱼虾或瘦肉。再加主食和蔬菜。今天想吃面，就把虾仁或豆腐一起放进去；今天不想开火，就选适合直接食用的酸奶和即食燕麦。

这是一种方便记忆的配餐办法。要判断全天是否吃够，还要看每种食物的分量。蔬菜、水果、主食和适量油脂都有位置，蛋白质不能代替全部营养。[\[N02\]](../SOURCES.md#source-n02)

<a id="food00-sub-01"></a>

### 蛋白质吃到多少

2023 版膳食营养素参考摄入量发布时的专家介绍给出：65 岁以下成年女性每天推荐摄入 55 克蛋白质，65 岁及以上女性为 62 克。这些数值是健康人群的摄入参考，指全天各种食物中蛋白质的合计，不是肉的重量，也不是必须每天刚好达到的刻度。[\[N01\]](../SOURCES.md#source-n01)

本章食谱主要面向一般健康、非孕哺期成年女性。孕哺期、肾脏疾病或正在接受营养治疗的人，按自己的医疗与营养方案调整；本章不提供这些情况的统一用量。

<a id="food02"></a>

## 5.2 食材与标签

先知道常用食物大致提供多少蛋白质，再学会看自己买到的包装。下表是食物成分数据库的参考值，样本和品牌不同，实际成分也会不同。[\[N03\]](../SOURCES.md#source-n03)

| 食物和计算状态 | 常用分量 | 蛋白质约 |
| --- | --- | --- |
| 鸡蛋  生全蛋可食部 | 50 克  约 1 个 | 6.3 克 |
| 全脂牛奶 | 250 克 | 8.3 克 |
| 北豆腐 | 100 克 | 12.2 克 |
| 南豆腐 | 100 克 | 6.2 克 |
| 去皮鸡胸肉  生 | 100 克 | 22.5 克 |
| 虾仁  生可食部 | 100 克 | 20.7 克 |
| 大西洋三文鱼柳  生 | 100 克 | 20.5 克 |
| 普通酸奶  均值 | 200 克 | 5.0 克 |
| 燕麦片  干 | 40 克 | 4.9 克 |
| 挂面  干  均值 | 60 克 | 6.2 克 |
| 米饭  蒸熟  均值 | 150 克 | 3.9 克 |

<a id="food02-sub-01"></a>

### 标签上的数字怎么用

假设你买的豆腐标签写着“每 100 克含蛋白质 8 克”，这一餐用了 150 克，那么它提供的蛋白质约为 8 × 150 ÷ 100 = 12 克。这里的 8 克只是算术示例，用时换成手里产品的数字。

营养标签按每 100 毫升标示时，用毫升计算；按每 100 克标示时，用克计算。本章牛奶数据库的单位是克，所以食谱也按克核算，没有把两种单位直接混用。

<a id="food02-sub-02"></a>

### 这八份食谱的估算口径

蛋白质按所列蛋、奶、鱼虾、肉、豆腐和主食计算，结果取整；没有计入蔬菜、水果、调味料的少量蛋白质。它是便于比较的主要食材估算，不是成品检测值。所有肉和鱼虾按解冻、去骨去壳后的生可食部计，米饭按熟重，挂面和燕麦按干重。

做饭时间为步骤估计，未经过厨房实测；解冻和另煮米饭的时间已单独说明。食材替换、品牌改变或用量调整后，营养数字和时间都可能变化。

<a id="food03"></a>

## 5.3 两三天买一次菜就够用

出门前先看冰箱，选好接下来几顿会在家吃的饭。优先买能被两道菜共用的食材：一盒北豆腐可以做番茄豆腐锅和香菇烧豆腐，一把青菜可以配面，也可以配米饭。

<a id="food03-sub-01"></a>

### 按实际会吃的顿数采购

给每顿饭选一种主要蛋白质食材。接下来做鸡肉饭、虾仁面和豆腐饭，就按各自用量购买；遇到大包装，回家后先分装，暂时用不到的部分按标签要求冷冻。生鸡肉、鱼虾不要因为采购周期是两三天，就全部一直留在冷藏室。

蔬菜选一两种叶菜，再加番茄、胡萝卜等方便搭配的品种。水果选自己爱吃、能在新鲜时吃完的量。主食可备大米、挂面和燕麦，不必一次买齐很多“健康食材”。

<a id="food03-sub-02"></a>

### 小冰箱和没有冰箱时

只有小冷藏室，就缩短采购周期。冷藏格不等于能保持零下 18℃的冷冻室，不能按冷冻备餐方案长期放鸡肉和鱼虾。没有冰箱时，选当餐做完的生鲜；奶和其他包装食品只在标签允许、未开封的条件下常温保存。[\[N05\]](../SOURCES.md#source-n05)

<a id="food03-sub-03"></a>

### 先用现有厨具

有一个小锅、刀板和带盖容器，就能做面、豆腐锅和简单炒菜。生肉与即食食品要避免共用未经清洁的刀板。常做鸡肉、蒸鱼或复热饭菜时，食品温度计可以帮助确认食物中心是否熟透。[\[N04\]](../SOURCES.md#source-n04)

电饭煲版食谱需要设备本身支持蒸煮，配合说明书允许的蒸架和耐热容器。先确认这些条件，再决定是否需要买新厨具。

<a id="food03-sub-04"></a>

### 按自己会用掉的量算钱

比较大包装和小包装时，看可食用的实际份量。便宜的大包装如果总剩下一半，未必省钱。鸡蛋、豆腐、奶和自己喜欢的鱼肉都可以轮换，不必把每顿饭固定成昂贵食材。

也可以用一个小算式比较同类产品：一包价格 ÷ 这包提供的蛋白质克数 × 10，得到每 10 克蛋白质大致花多少钱。这个数字只帮助比较，口味、钙和铁等营养、盐分、保存条件也要一起看。

<a id="food03-sub-05"></a>

### 今天就做的一件事

从后面的八份饭里挑出两份，查看食材是否能共用，把缺少的东西写在手机上。每次采购先补这几样，再决定要不要尝试新菜。

<a id="foodprep"></a>

## 5.4 从买回食材到端上饭的一次完整演练

如果以前很少下厨，先练“番茄鸡蛋北豆腐锅配米饭”就够了。第一次不要同时挑战三道菜。读完整个配方，核对锅、刀板、食材与主食都在，再开火。以下过程说明先后次序，时间仍是估计，不把它当作必须在20分钟内完成的考试。

<a id="foodprep-sub-01"></a>

### 采购前先决定两顿实际会吃的饭

例如今晚做番茄豆腐锅，明晚做香菇烧豆腐，需要北豆腐合计250克；若只能买到400克一盒，就先看开封后的储存说明，决定剩下150克能否按时用完。不能就换小包装或改另一顿，而不是买回家后无限延长保存时间。主食按自己的食量准备，配方用量不是食量上限。

买回家先放好需要冷藏或冷冻的东西，再收拾干货。按预计使用时间分装生肉和鱼虾，给容器写日期。一次采购的所有东西不必在当天都洗切好；提前处理是否合适取决于食物与保存条件，临近做饭再洗切也很正常。生肉汁水与可直接吃的食品分开。[\[N04\]](../SOURCES.md#source-n04)[\[N05\]](../SOURCES.md#source-n05)

<a id="foodprep-sub-02"></a>

### 做之前把动作顺序排清楚

先准备米饭或确定已有米饭可安全复热，再洗番茄、切豆腐、打蛋。准备一个放厨余的小碗和一个放干净成品的碗，避免开火后才到处找。调料先放在顺手处，少量加入；要调整口味，等蛋液完全熟透后再尝，不尝生蛋混合液。

锅中出现轻微粘底时，先降低火力，再按菜肴情况少量加水并搅动；不要为了追求快，把火始终开到最大。若出现燃气异味、电器异常或起火，按住房章处理，不能把安全问题当成普通的做菜失误。电饭煲和微波炉也要按各自说明书使用容器和程序。

<a id="foodprep-sub-03"></a>

### 吃饭前后各做一件事

准备留下一餐的部分，用干净餐具先分到浅盒，按保存要求及时冷藏；不要让整锅在桌上陪着你吃完、聊天、收拾再决定。自己这一份也先确认有蛋白质食材、主食和蔬菜；还饿就补足适合自己的食物，不用为了遵守配方勉强停下。[\[N02\]](../SOURCES.md#source-n02)[\[N06\]](../SOURCES.md#source-n06)

吃完后洗净接触生食的用具，清洁台面，检查火源或电器已按正确方式关闭。记下这次最麻烦的环节。例如“米饭没提前准备”“番茄切太大不易软”“盐一次加多了”。下次只改这个环节，熟练来自重复，不要求每次都做新菜。

<a id="foodcost"></a>

## 5.5 买食材时把价格和实际用量一起算

“哪一种蛋白质最划算”不能只看一盒多少钱。包装大小、可食部分、最后能否吃完都会改变实际成本。下面是完全虚构的标签与售价，展示怎么计算，不代表市场价格或本章食物数据库的实测值。

<a id="foodcost-sub-01"></a>

### 用同一个口径比较

假设豆腐400克售价6元，标签每100克含蛋白质8克，则整盒含32克，每10克蛋白质的价格为6÷32×10，约1.88元。另一包鸡肉300克售价12元，假设标签每100克含22克蛋白质，整包含66克，每10克约1.82元。两者接近，但烹调、保存、口味和其他营养不同，不能只凭这一个数字宣布谁更好。

如果豆腐最终只吃了200克，其余因保存不当丢掉，那么6元实际只换来16克吃下去的蛋白质，每10克实际成本变为3.75元。减少浪费的方法可以是买小盒、和另一次用餐共用食材，或选择更容易保存的替代品；不要为了“省掉浪费”吃已经不安全的食物。

<a id="foodcost-sub-02"></a>

### 分开算这次付款和这一餐成本

假设一盒400克豆腐6元，本餐用100克，分摊成本1.5元；番茄本餐2元，鸡蛋1元，米饭与调味料合计估1元，则本餐食材成本约5.5元。但你到收银台可能要付完整一盒豆腐、整袋米和调料的钱。首次购置不能只准备单餐分摊成本，还要留意冰箱容量和后续是否用得完。

把外卖与做饭比较时，除食材外，还应考虑配送、交通、工具、燃料以及自己的时间与精力。上班很忙的一天选择外卖，不等于生活安排失败；如果外卖费开始挤压必要支出，可以先替换一两顿最容易做的饭，不用马上要求七天全部自己做。

<a id="foodcost-sub-03"></a>

### 采购记录只保留有用的字段

记录“买了多少、几次用完、剩下为何没吃、下次买多少”。如果总剩叶菜，就减量或选择能按时用完的搭配；如果每次临时缺蛋白质食材，就在补货清单中固定写鸡蛋、奶或适合自己的豆制品。改变一个反复出问题的购买习惯，往往比不断寻找所谓最优食材更实际。

## 5.6 早餐和免开火搭配

<a id="food04-sub-01"></a>

### 01  牛奶鸡蛋燕麦早餐

一人份  ·  主要食材蛋白质约 18 克  ·  约 12 至 15 分钟

工具：小锅和碗。

食材：牛奶 250 克、干燕麦片 30 克、鸡蛋 1 个（去壳约 50 克），另配洗净水果约 150 克。燕麦选择原味产品。

1. 鸡蛋冷水入锅，水开后调至保持轻沸。普通大小鸡蛋可先以约 10 分钟为参考；较大或刚从冰箱取出的蛋可能更久。剥开确认蛋白和蛋黄都已凝固，未熟则继续充分加热。

2. 燕麦按包装要求煮熟。另将牛奶倒入碗中，和煮好的燕麦混合；也可在燕麦快熟时加入牛奶，小火加热并搅拌。

3. 装碗，配水果。牛奶按个人喜好喝冷的或热的都可以；需冷藏的奶按标签保存。

替换：乳糖不耐受可换适合自己的无乳糖奶。若改用豆浆，按豆浆标签重算蛋白质，钙含量也要另看。

保存：燕麦和奶只做本餐份量。想提前煮鸡蛋，应及时冷藏；可以先只准备次日要吃的量。

<a id="food04-sub-02"></a>

### 02  免开火酸奶燕麦水果碗

一人份  ·  主要食材蛋白质约 15 克  ·  约 5 分钟

工具：碗和勺。

食材：原味酸奶 200 克、明确标注可直接食用的即食燕麦片 40 克、牛奶 150 克、水果约 150 克。

1. 先看燕麦标签。需要煮熟的普通燕麦不能直接套用这道做法。

2. 把酸奶与即食燕麦拌匀，加入洗净切好的水果，牛奶单独喝。按喜欢的软硬程度即拌即吃或短时间冷藏浸润。

3. 按本人的饥饿程度增加主食或其他食物。这碗的蛋白质只是一天的一部分。

替换：普通酸奶与高蛋白酸奶的成分差别可能很大，以实际标签为准。牛奶蛋白过敏者不能用无乳糖牛奶替代，应选择自己可耐受的其他搭配。

保存：冷藏食品取出后尽快吃完。没有冰箱时，只购买当餐吃完的份量，或选择按标签可常温保存且未开封的奶。

营养估算见“食材与标签”及来源 [\[N03\]](../SOURCES.md#source-n03)；烹调与保存参照 [\[N04\]](../SOURCES.md#source-n04) 至 [\[N07\]](../SOURCES.md#source-n07)。

<a id="food04-sub-03"></a>

### 第一次没做理想时怎样调整

燕麦太稠时可加入适合直接饮用的奶或水调整口感；太稀则下次减少液体，不需要为了这一碗额外加很多燕麦。若鸡蛋剥开仍有流动部分，继续充分加热。酸奶碗吃完很快饿，可以按食量增加主食或其他食物，不能把“有15克蛋白质”理解成这份一定足够自己吃饱。

<a id="food05"></a>

## 5.7 下班后的一锅饭菜

<a id="food05-sub-01"></a>

### 03  番茄鸡蛋北豆腐锅配米饭

一人份  ·  主要食材蛋白质约 22 克  ·  约 15 至 20 分钟，不含煮饭

工具：小锅和碗。

食材：北豆腐 100 克、鸡蛋 1 个（去壳约 50 克）、番茄 200 克、熟米饭 150 克，食用油约 5 克、水约 200 毫升，少量盐或酱油。

1. 洗净番茄后切块，豆腐切小块，鸡蛋打散。锅中加油，将番茄炒软。

2. 加水煮开，放入豆腐，小火煮约 5 分钟，让豆腐热透。倒入蛋液，继续加热至蛋液完全凝固，再少量调味。

3. 配现做米饭；若用冷藏或冷冻米饭，另行充分加热到中心至少 74℃。

替换：换南豆腐可以，但同样重量的蛋白质会变化。本章数据里，100 克北豆腐约 12.2 克，南豆腐约 6.2 克；市售品看包装。

保存：一盒豆腐可以用于两道菜。开封后按标签冷藏和食用，提前想好第二餐；别为了用完大包装勉强增加食量。

<a id="food05-sub-02"></a>

### 04  青菜虾仁面

一人份  ·  主要食材蛋白质约 23 克  ·  约 12 至 15 分钟，不含解冻

工具：小锅。

食材：虾仁 80 克（解冻沥水后的生重）、干挂面 60 克、青菜 200 克，清水、少量盐或酱油；姜丝按口味添加。

1. 冷冻虾仁提前在冰箱冷藏室内解冻；取出后去除不可食部分。青菜洗净。

2. 烧开水，先把虾仁煮至整体呈珠白色、不透明，捞到干净碗中。随后按包装时长煮面，加入青菜并煮熟。

3. 把虾仁放回面锅，继续加热至整锅热透，再少量调味。分开煮方便判断熟度，也不需要猜虾仁和面条谁先熟。

替换：不吃虾可改用鸡肉或豆腐。鸡肉要煮到中心至少 74℃；替换后的蛋白质按新食材计算。

保存：冷冻虾仁买回后按一餐一份保存。小冰箱没有真正冷冻室时，买当餐用量，按包装要求冷藏并及时做熟。

营养估算见“食材与标签”及来源 [\[N03\]](../SOURCES.md#source-n03)；烹调与保存参照 [\[N04\]](../SOURCES.md#source-n04) 至 [\[N07\]](../SOURCES.md#source-n07)。

<a id="food05-sub-03"></a>

### 第一次没做理想时怎样调整

豆腐碎掉主要影响外形，可以轻推代替翻炒；汤偏淡就在最后少量调味。虾仁久煮变硬时，下一次把面和虾分步处理，仍须先确保熟透。盐放多了可增加无盐食材或分出一部分稀释，不能靠放糖消除已经加入的盐。安全熟度与是否好吃要分别判断。

<a id="food06"></a>

## 5.8 鸡肉饭和电饭煲蒸鱼

<a id="food06-sub-01"></a>

### 05  香菇鸡肉青菜饭

一人份  ·  主要食材蛋白质约 22 克  ·  约 15 至 20 分钟，不含煮饭和解冻

工具：平底锅或小炒锅。

食材：去皮鸡胸肉 80 克（生重）、鲜香菇 100 克、青菜 150 克、熟米饭 150 克，食用油约 5 克、酱油少量、水约 50 毫升。

1. 先洗切蔬菜，再用专门处理生肉的刀板切鸡肉薄片。接触生肉后洗手并清洁用具。

2. 锅中加油，炒散鸡肉，加入香菇和少量水，盖锅焖煮。

3. 加入青菜，继续翻炒至熟。用食品温度计确认鸡肉中心至少达到 74℃，再调味，配米饭吃。

替换：鸡腿去皮去骨也能做，蛋白质估算需改用对应数据。肉不必选昂贵部位；先比较每份可食量和自己喜欢的口感。

保存：鸡肉买回后按 80 至 100 克分装；近期不做的及时冷冻。别把一大袋反复解冻，只取下一餐需要的一份。

<a id="food06-sub-02"></a>

### 06  电饭煲蒸鱼配米饭和青菜

一人份  ·  主要食材蛋白质约 20 克  ·  约 25 至 35 分钟，不含解冻和另煮米饭

工具：有蒸煮功能的电饭煲 蒸架 耐热浅盘。

食材：三文鱼柳 80 克（生重）、青菜 200 克、熟米饭 150 克，姜片和少量酱油。选择去骨鱼柳，食用前仍留意细刺。

1. 按电饭煲说明加入足量水、放好蒸架。鱼柳解冻后放入耐热浅盘，加姜片；使用蒸煮程序。

2. 蒸到鱼肉最厚处至少达到 63℃。时间受鱼块厚度和设备影响，程序结束或跳保温不能单独证明已经熟透。

3. 青菜另放合适容器蒸熟。米饭也需充分加热；取盘时用隔热手套，避免被蒸汽烫伤。

替换：可以换成当地容易买到的其他鱼柳，价格与口味合适即可。约 20 克蛋白质这一估算只对应列出的三文鱼和米饭分量。

保存：生鱼放密封容器，避免汁水接触即食食物。冻鱼优先冷藏解冻；没有蒸煮功能或合适蒸架，就改用普通蒸锅。

营养估算见“食材与标签”及来源 [\[N03\]](../SOURCES.md#source-n03)；烹调与保存参照 [\[N04\]](../SOURCES.md#source-n04) 至 [\[N07\]](../SOURCES.md#source-n07)。

<a id="food06-sub-03"></a>

### 第一次没做理想时怎样调整

鸡肉口感干，下一次可切得均匀一些、加少量水并缩短达到安全中心温度之后的额外加热；不能用故意未熟改善口感。鱼的厚度和设备不同，不按固定分钟数保证熟透。温度计探针放在最厚处，避开容器表面，使用后按说明清洁。[\[N04\]](../SOURCES.md#source-n04)

<a id="food07"></a>

## 5.9 两份豆腐饭

<a id="food07-sub-01"></a>

### 07  香菇烧北豆腐配米饭

一人份  ·  主要食材蛋白质约 22 克  ·  约 15 分钟，不含煮饭

工具：小锅。

食材：北豆腐 150 克、鲜香菇 100 克、青菜 150 克、熟米饭 150 克，食用油约 5 克、水约 100 毫升、少量酱油。

1. 豆腐切块，香菇切片，青菜洗净。锅中加油，先炒香菇。

2. 加入豆腐和水，轻轻推动，小火煮约 5 至 8 分钟，使豆腐热透。

3. 加入青菜继续煮熟，少量调味，配米饭。喜欢辣味可加少量辣椒。

替换：不喜欢香菇可换番茄、冬瓜或自己喜欢的蔬菜。豆腐种类替换会改变蛋白质和钙含量，按标签调整。

保存：适合与番茄豆腐锅共用一盒北豆腐。只有冷藏空间时，先买小盒；根据开封后保存说明安排下一餐。

<a id="food07-sub-02"></a>

### 08  电饭煲南豆腐蒸蛋饭

一人份  ·  主要食材蛋白质约 20 克  ·  约 25 至 35 分钟，不含另煮米饭

工具：有蒸煮功能的电饭煲 蒸架 耐热浅碗。

食材：南豆腐 150 克、鸡蛋 1 个（去壳约 50 克）、温水 70 毫升、熟米饭 150 克，另配蔬菜 200 克、少量酱油。

1. 鸡蛋打散，加温水搅匀。南豆腐切小块放入耐热浅碗，倒入蛋液。

2. 按设备说明加水、使用蒸架和蒸煮程序，将蛋液蒸至中心完全凝固，食品温度计确认中心至少达到 72℃，豆腐热透；不要只按固定分钟数出锅。

3. 另将蔬菜蒸熟，米饭充分加热，和蒸蛋一起吃。出锅后少量调味。

替换：内酯豆腐和南豆腐的实际成分可能不同，使用内酯豆腐时按包装重算。北豆腐口感更结实，也可替换。

保存：这是一人份现做菜，不建议为了省事把整周的蒸蛋一次做好。设备不支持蒸煮时用普通蒸锅。

营养估算见“食材与标签”及来源 [\[N03\]](../SOURCES.md#source-n03)；烹调与保存参照 [\[N04\]](../SOURCES.md#source-n04) 至 [\[N07\]](../SOURCES.md#source-n07)。

<a id="food07-sub-03"></a>

### 第一次没做理想时怎样调整

蒸蛋起蜂窝或豆腐不成形不一定是安全问题，可能与火力、液体比例和操作有关；下一次先保持配方比例，只调整一个环节。蒸到表面凝固但中心仍稀时应继续加热，蛋类混合料理可用温度计核对中心至少72℃。不要为了外形漂亮省略熟度检查。[\[N04\]](../SOURCES.md#source-n04)

<a id="food08"></a>

## 5.10 点外卖和调整搭配

<a id="food08-sub-01"></a>

### 点餐时先看得到食物

选套餐时，看图片和配料里有没有明确的鱼、肉、蛋或豆腐，再看主食和蔬菜是否齐全。只有“鸡肉风味”“浓汤”等名称，不能判断实际用了多少食材；一份鸡肉饭的蛋白质也不能只凭售价推算。

| 眼前这顿饭 | 可以怎样补充 |
| --- | --- |
| 一碗主要是面和汤的面条 | 加一份实际可见的鸡肉、虾仁或豆腐，再加蔬菜 |
| 一份蔬菜沙拉 | 加入豆类、蛋、鱼或肉，并按食量补主食 |
| 一份已有肉和米饭的套餐 | 看蔬菜分量是否合适；有需要再补，不自动加双份肉 |
| 便利店解决一餐 | 可选奶或酸奶、全熟蛋、主食和蔬果，按标签储存和食用 |
| 一顿饭已经吃得比较完整 | 正常安排下一餐，不必额外叠加高蛋白零食 |

<a id="food08-sub-02"></a>

### 喝奶不舒服时

乳糖不耐受者可以尝试适合自己的无乳糖奶，或根据耐受情况选择酸奶等发酵乳制品。酸奶并不一定没有乳糖。牛奶蛋白过敏与乳糖不耐受不同，无乳糖牛奶仍含牛奶蛋白。[\[N08\]](../SOURCES.md#source-n08)[\[N09\]](../SOURCES.md#source-n09)

选择豆浆时看蛋白质和钙的标签。不同浓度、是否强化营养，会改变它能提供的营养；“植物饮料”这一个名称不足以说明可以等量替代牛奶。

<a id="food08-sub-03"></a>

### 照顾钙和铁  也保留主食与蔬果

奶类和部分豆制品可以提供钙，但不同产品的钙含量差别很大。把奶类、豆制品和多样蔬菜安排进日常饮食，比只看蛋白质一栏更完整。[\[N02\]](../SOURCES.md#source-n02)[\[N08\]](../SOURCES.md#source-n08)

有月经的女性也应留意铁的摄入。选择瘦肉、鱼、豆类等多样食物，植物性含铁食物搭配富含维生素 C 的蔬果，有助于非血红素铁吸收。贫血不能只凭疲劳自行判断，也不靠多吃蛋白质替代检查或治疗。[\[N10\]](../SOURCES.md#source-n10)

蛋奶素读者可在可接受的食物中轮换奶、蛋和大豆制品。全素饮食还需要单独安排维生素 B12 等营养，本章的几份豆腐饭不能代表完整的全素营养方案。[\[N11\]](../SOURCES.md#source-n11)

<a id="food09"></a>

## 5.11 饭菜怎么保存和再加热

少量备餐可以省事。前提是食物做熟后及时分装、冷却和冷藏，取出后充分加热。冰箱低温只能减慢微生物生长，不能把已经保存不当的饭菜重新变安全。[\[N04\]](../SOURCES.md#source-n04)[\[N05\]](../SOURCES.md#source-n05)

<a id="food09-sub-01"></a>

### 先看温度  再看时间

冷藏室保持 4℃或以下，冷冻室保持零下 18℃或以下。需冷藏的食物，包括剩饭菜和外卖，应在烹调或购买后两小时内冷藏；环境高于约 32℃时缩短为一小时。超过相应时限就丢弃，不凭闻起来正常决定是否继续吃。[\[N04\]](../SOURCES.md#source-n04)[\[N05\]](../SOURCES.md#source-n05)

<a id="food09-sub-02"></a>

### 给明天留饭时  先分出来

用干净浅盒分成一餐份，尽快放入冰箱；不用等整锅在室温下完全凉透。盒上写好制作日期，生肉和鱼虾用不漏汁的容器，与熟食分开。[\[N04\]](../SOURCES.md#source-n04)[\[N06\]](../SOURCES.md#source-n06)

这里建议冷藏只留次日要吃的饭菜；超过次日才吃的份量，及时分装冷冻。这是便于执行的备餐选择。USDA 对一般熟食剩菜给出的冷藏期限为 3 至 4 天，前提是充分做熟、及时冷却、持续保持低温；它不是对任何一盒剩菜的无条件保质承诺。[\[N06\]](../SOURCES.md#source-n06)

<a id="food09-sub-03"></a>

### 米饭也要及时冷藏

煮好的米饭尽快分装，冷藏份安排次日吃完，更多的当日分装冷冻。室温放了一夜的米饭，不拿来炒饭补救：保存不当可能产生耐热毒素，再炒热也未必消除。[\[N07\]](../SOURCES.md#source-n07)

<a id="food09-sub-04"></a>

### 解冻只处理下一餐

鸡肉和鱼虾优先放在冰箱冷藏室内解冻，用容器接住汁水。生鸡肉、鱼虾的冷藏时间应短，通常在 1 至 2 天内做熟；提前计划解冻，解冻后尽快烹调；计划更晚吃的份量先继续冷冻，包装标示更短期限时按标签执行。熟食剩菜的 3 至 4 天规则不适用于生鸡肉和鱼虾。[\[N12\]](../SOURCES.md#source-n12)

赶时间用微波炉解冻，随后立即做熟。不要早上把冻肉放在厨房台面，晚上再回来处理。[\[N04\]](../SOURCES.md#source-n04)

<a id="food09-sub-05"></a>

### 吃多少  就取出多少再加热

剩饭菜中心要至少达到 74℃。微波加热时中途搅拌或翻动，按设备说明静置后再检查中心温度。食品温度计比“表面已经冒热气”更能帮助判断是否热透。[\[N04\]](../SOURCES.md#source-n04)[\[N06\]](../SOURCES.md#source-n06)

免开火食谱也要看标签：选择明确可以即食的食品；需要加热的预制食品按说明充分加热。包装完整、未过期，也不代表它可以任意在室温放置。[\[N04\]](../SOURCES.md#source-n04)[\[N05\]](../SOURCES.md#source-n05)

<a id="food09-sub-06"></a>

### 收拾厨房时顺手确认

剩余食物已经分装冷藏；明天用的冷冻食材已经移到冷藏室；台面和接触生肉的用具已经清洁。这样下一顿需要做的事就少一些。

<a id="foodbusy"></a>

## 5.12 没力气做饭时保留一套备用吃法

今天只剩五分钟，和今天完全没有厨房，是两种不同的情况。先看有哪些能安全直接吃的食物、能否使用微波炉，以及是否有冷藏条件，再选备用方式。不要为了坚持自己做饭，把晚餐拖到很晚仍然没有着落。

<a id="foodbusy-sub-01"></a>

### 有冷藏和简单加热条件

可以准备少量按标签可即食或加热的主食、奶或酸奶、全熟鸡蛋、豆制品与蔬果。选择组合时看实际食材和标签，尽量补齐主食、蛋白质来源与蔬菜水果。若是需要充分加热的包装食品，就按说明做，不能因为外观像熟食而直接吃。吃完仍饿，按个人需要增加食物。[\[N02\]](../SOURCES.md#source-n02)[\[N04\]](../SOURCES.md#source-n04)

工作日中午想带饭，先确认办公室有可靠冷藏条件，再决定运输和到达后的保存。不能把早上出门到中午就餐的整段时间都当作“还没开始放置”；保冷措施是否能持续维持温度需要确认。无法可靠保持低温时，改成现买现吃或其他适合条件的食品，不靠中午再加热补救已经失控的保存过程。[\[N04\]](../SOURCES.md#source-n04)[\[N05\]](../SOURCES.md#source-n05)

<a id="foodbusy-sub-02"></a>

### 没有厨房或冰箱

只购买当次能吃完的生鲜与冷藏食品。常温奶、罐装豆类等也只有在标签允许、包装完好且未开封时才能按常温条件储存；开封后的规则要另看。无法做完的原材料，不必因为“每斤更便宜”硬买大包装。把家附近可选的正规餐饮或便利食品记成两三种固定组合，会比每次饿着肚子重新搜索省力。

点餐时可以直接问：“这份里有多少实际的鸡肉或豆腐，能否加一份蔬菜，主食分开装？”对方不能提供准确克数时，就按看得到的食物搭配，不编造精确蛋白质数字。收到后发现明显异常、包装破损或怀疑保存不当，保留订单和相关照片并联系商家或平台，不以尝一口来验证安全。

<a id="foodbusy-sub-03"></a>

### 别把蛋白质变成新的压力

先回看最近几个普通日子，每餐是否经常缺少蛋、奶、豆、鱼肉等来源，再补最容易漏的一餐。不需要每天称完所有饭菜，也不因为某一餐吃得少就立刻叠加很多零食或补剂。若已有医生或营养师给出的个人计划，以那个计划为准；食欲、体重或进食能力明显变化时，安排评估而不是只追一个克数。

| 想吃肉配米饭 | 05 香菇鸡肉青菜饭 | 22 克 |
| 想吃一碗面 | 04 青菜虾仁面 | 23 克 |
| 想吃豆腐配米饭 | 07 香菇烧北豆腐配米饭 | 22 克 |
| 想用电饭煲蒸菜 | 08 南豆腐蒸蛋饭 | 20 克 |

主食分量用于展示配方和核算，不是食量上限。没有统一的“小饭量女性”模板；活动多、容易饿或体重非自愿下降时，应重新评估全天摄入。

### 六种配方各做一次的基础用量

| 类别 | 六种配方各做一次的用量 |
| --- | --- |
| 奶和蛋 | 牛奶 400 克、原味酸奶 200 克、鸡蛋 2 个 |
| 肉和豆腐 | 鸡胸肉 80 克、虾仁 80 克、北豆腐 150 克、南豆腐 150 克 |
| 主食 | 燕麦共 70 克，其中 40 克需可直接食用；干挂面 60 克；熟米饭共 450 克 |
| 蔬菜与水果 | 鲜香菇 200 克、青菜或其他蔬菜共 700 克、水果至少 300 克，另按日常需要补足 |
| 家中调料 | 食用油、少量盐或酱油、按喜好准备姜等 |

这张清单只合计六份基础配方，未包括你额外吃的主食、奶、水果等。采购时按真正会做的份数增减；450 克熟米饭不等于 450 克生米，需按自家出饭量换算。
